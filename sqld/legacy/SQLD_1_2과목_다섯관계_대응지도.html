관계 판정 규칙

Type of는 문제·개념의 하위 종류, Instance of는 구체적 사례, Part of는 전체 과정의 실제 구성 요소, Cause of는 원인에 따른 문제 발생과 개입 후 개선, Data → Claim은 관측·검사 결과가 확보되었을 때의 판단을 뜻합니다.

첨부 4개 교정 문서의 개념을 바탕으로 재구성한 학습용 관계 그래프입니다. 사례는 설명을 위한 가상 상황입니다. 효과는 실제 실험으로 검증한 결과가 아니며, Data는 실제 실행 데이터가 아니라 앞으로 확보할 검증 자료의 후보를 표시합니다. 검증 항목은 실행해야 할 시험·관측을 제안합니다. 서로 다른 원인들이 같은 문제를 낳을 수 있고, 하나의 SQL 명령도 잘못 사용하면 새로운 문제가 발생할 수 있습니다.
