# 1차 구현 제외: 인공신경망 계열

## 제외 대상

- 기본 인공신경망(퍼셉트론/MLP) 학습
- CNN
- RNN
- LSTM
- GAN
- 딥러닝 역전파(backpropagation) 직접 구현

## 제외 사유

1. 이번 1차 구현의 목표는 "SQL로 데이터를 준비하고 Python/R로 학습한 뒤 SQL로 검산한다"는
   흐름을 20개 확정 기법(PCA~데이터 전처리)에 대해 먼저 견고하게 세우는 것이다.
2. 신경망 계열은 학습 반복(epoch), 가중치 초기화, 활성함수, 손실함수 시각화 등
   SQL/DB 연계보다 프레임워크(예: TensorFlow, PyTorch) 의존도가 높아 이 저장소의
   "SQL 중심 실기 준비" 성격과 결이 다르다.
3. 지금까지 확보한 원본 자료(`_원본 자료/`, `빅분기로 sql*.pdf`, `빅분기로 sql 예상문제.pdf`)에서
   신경망 계열의 실제 출제·구현 근거를 아직 확인하지 못했다.

## 영구 제외가 아님

이는 **1차 구현 범위에서의 보류**이지 영구 제외가 아니다. 다음 조건이 확인되면 이 폴더를
`22-인공신경망`(가칭)으로 승격하고 별도 검토를 시작한다.

- [ ] 원본 자료 또는 실기 복원자료에서 신경망 계열 실제 출제 근거 확인
- [ ] 빅데이터분석기사 실기 최신 출제기준에 신경망 관련 문항 포함 여부 확인
- [ ] SQL 준비 단계(예: 정규화된 학습 데이터, 배치 인덱스 테이블)와 Python 학습 단계를
      다른 확정 기법들과 동일한 3층 구조로 분리할 수 있는지 확인

## 재검토 시 참고할 역할 분담(초안)

| 층 | SQL | Python/R |
|---|---|---|
| 데이터 준비 | 정규화된 입력 테이블, 학습/검증 분할 플래그, 배치 인덱스 | - |
| 모델 학습 | - | 신경망 구조 정의·학습·예측 |
| 검산 | 예측값·손실 이력을 테이블로 저장 후 SQL로 재조회·집계 | - |

이 초안은 `05-회귀분석`, `07-SVM`, `09-랜덤포레스트` 등 기존 지도학습 기법과 동일한
패턴을 따르므로, 재검토가 시작되면 해당 폴더들을 템플릿으로 재사용할 수 있다.
