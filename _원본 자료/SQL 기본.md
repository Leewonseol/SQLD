# SQL 기본

## SELECT문

### 1. 전체 문법 구조

#### 작성 순서

- SELECT
    - → FROM
    - → WHERE
    - → GROUP BY
    - → HAVING
    - → ORDER BY

#### 논리적 실행 순서

- FROM
    - → JOIN / ON
    - → WHERE
    - → GROUP BY
    - → HAVING
    - → SELECT
    - → ORDER BY

### 2. SELECT 절

#### 기능

- 테이블에서 출력할 열 지정
- 특정 열 조회
- 여러 열 조회
- 쉼표로 여러 열 구분

#### 전체 열 조회

- *
    - 테이블에 정의된 모든 열 출력
    - 열 순서는 테이블 정의 순서
    - 불필요한 열까지 조회할 수 있어 실무에서는 명시 권장

#### 중복 처리

- DISTINCT
    - 조회 결과의 중복 제거
    - 열 하나이면 해당 열 값 기준
    - 열 여러 개이면 열 조합 전체 기준
- ALL
    - 중복을 제거하지 않고 전체 출력
    - 기본값
    - 보통 생략

#### ALIAS

- 기능
    - 출력 열에 임시 이름 부여
    - 실제 열 이름은 변경되지 않음
- 작성법
    - 열 AS 별칭
    - 열 별칭
- 이름 규칙
    - 문자로 시작
    - 숫자나 특수문자로 시작 불가
    - SQL 예약어 사용 불가
    - _, $, # 사용 가능
    - 공백·특수문자 포함 시 큰따옴표 사용
- Oracle 출력 규칙
    - 큰따옴표 없음 → 대문자로 출력
    - 큰따옴표 있음 → 대소문자 그대로 유지

#### 산술 연산

- 열 + 리터럴
- 열 - 리터럴
- 열 * 리터럴
- 열 / 리터럴
- 열과 열 사이 연산
- 각 행마다 반복 수행
- 연산에 NULL 포함 시 결과도 NULL

#### 연결 연산

- 문자열을 이어 붙임
- Oracle: ||
- SQL Server: +
- NULL 연결 처리 방식은 DBMS별 차이

### 3. 자료형과 리터럴

#### 리터럴

- 연산 결과가 아닌 값 자체
- 숫자 리터럴
- 문자 리터럴
- 날짜 리터럴

#### 자료형

- 열에 저장할 값의 종류 규정
- 값의 범위, 길이, 연산 가능 여부 결정

#### Oracle 주요 자료형

- VARCHAR2(n)
    - 문자형, 최대 n바이트
- NUMBER
    - 숫자형
- DATE
    - 날짜형

### 4. 공통 표현 도구

#### 함수의 개념

- 입력값을 받음
- 특정 연산 수행
- 결과값 반환

#### 함수의 출처

- 내장형 함수
    - DBMS가 미리 제공
- 사용자 정의 함수
    - 사용자가 직접 정의

#### 단일행 함수

- 한 행을 입력
- 한 행당 결과 하나 반환

#### 문자형 함수

- UPPER(문자열)
    - 소문자 → 대문자
- LOWER(문자열)
    - 대문자 → 소문자
- CONCAT(문자열1, 문자열2)
    - 두 문자열 연결
    - 세 개 이상은 중첩 또는 연결 연산자 사용
- SUBSTR(문자열, 시작 위치, 개수)
    - 문자열 일부 추출
    - 시작 위치 생략 불가
    - 개수 생략 시 끝까지
    - 음수 위치는 뒤에서 계산
- ASCII(문자)
    - 문자 → ASCII 코드
- CHR(숫자) / CHAR(숫자)
    - ASCII 코드 → 문자
- LENGTH(문자열) / LEN(문자열)
    - 문자열 길이
- LTRIM
    - 왼쪽 공백 또는 지정 문자 제거
    - SQL Server는 공백만 제거
- RTRIM
    - 오른쪽 공백 또는 지정 문자 제거
    - SQL Server는 공백만 제거
- TRIM
    - LEADING
    - TRAILING
    - BOTH
    - 생략 시 BOTH
    - 기본적으로 공백 제거
- REPLACE(문자열, 기존 문자, 변경 문자)
    - 특정 문자열 치환

#### 숫자형 함수

- ABS(숫자)
    - 절댓값
- SIGN(숫자)
    - 양수 → 1
    - 음수 → -1
    - 0 → 0
- MOD(숫자1, 숫자2)
    - 나머지
- CEIL(숫자)
    - 올림
- FLOOR(숫자)
    - 내림
- ROUND(숫자, 자릿수)
    - 반올림
    - 양수 자릿수 → 소수점 오른쪽
    - 음수 자릿수 → 정수부 왼쪽
- TRUNC(숫자, 자릿수)
    - 지정 자릿수 이하 버림
    - 양수 자릿수 → 소수점 오른쪽
    - 음수 자릿수 → 정수부 왼쪽
- POWER(밑, 지수)
    - 거듭제곱

#### 날짜형 함수

- SYSDATE / GETDATE()
    - 현재 날짜와 시간
- EXTRACT(단위 FROM 날짜)
    - 연·월·일 등 추출
- DATEPART(단위, 날짜)
    - SQL Server의 날짜 요소 추출
- Oracle 날짜 연산
    - 날짜 + 1 → 하루 뒤
    - 날짜 + 1/24 → 한 시간 뒤
    - 날짜 + 1/24/60 → 1분 뒤
    - 날짜 + 1/24/60/60 → 1초 뒤

#### 형변환 함수

- 명시적 형변환
    - 사용자가 직접 변환 지정
    - TO_CHAR
        - 날짜·숫자 → 문자
        - 포맷 지정 가능
    - TO_DATE
        - 문자 → 날짜
        - 문자 형식과 포맷 일치 필요
    - TO_NUMBER
        - 문자 → 숫자
    - CAST
        - SQL Server 형변환
    - CONVERT
        - SQL Server 형변환
        - 스타일 코드 지정 가능
- 암시적 형변환
    - DBMS가 자동 변환
    - 숫자와 문자 비교 시 숫자 기준 변환
    - 변환 불가능한 문자는 오류

#### NULL 함수

- NVL(값1, 값2) / ISNULL(값1, 값2)
    - 값1이 NULL이면 값2 반환
- NULLIF(값1, 값2)
    - 같으면 NULL
    - 다르면 값1
- COALESCE(값1, 값2, …)
    - 첫 번째 NULL이 아닌 값 반환

#### 조건 표현식

- CASE
    - CASE로 시작, END로 종료
    - WHEN / THEN
    - ELSE 생략 시 NULL
    - SIMPLE CASE
        - 기준값과 각 WHEN 값 비교
    - SEARCHED CASE
        - 각 WHEN에 독립 조건식 사용
- DECODE
    - Oracle 전용
    - 기준값과 조건값을 =로 비교
    - SIMPLE CASE와 유사
    - 부등호·범위 조건 불가
    - 출력값들의 자료형 일치 필요

### 5. FROM 절

#### 기본 기능

- 데이터를 가져올 테이블 지정

#### 여러 테이블 지정

- 쉼표로 2개 이상 테이블 나열 가능
- 조건이 없으면 모든 가능한 조합 생성
- 결과 행 수 = 각 테이블 행 수의 곱

#### 테이블 별칭

- 긴 테이블 이름을 짧게 대체
- 테이블 별칭에는 AS 사용하지 않음
- 동일한 열 이름의 소속 구분
- 테이블명.열명 또는 별칭.열명
- 별칭 선언 후 다른 절에서도 별칭 사용

#### JOIN

- 기본 개념
    - 여러 테이블의 데이터를 한 번에 조회
    - 정규화로 분리된 정보를 다시 결합
    - 조인 조건으로 관련 행 연결
- 실행 원리
    - 테이블 간 가능한 모든 조합 생성
    - 카티션 곱
    - 조인 조건으로 관련 행 필터링
    - 일반 조건으로 추가 필터링
- 조인 조건
    - 테이블 간 관계 조건
    - 일반적으로 PK–FK 열 사용
    - 테이블 N개 조인 시 최소 N−1개 조건 필요
- 일반 조건
    - 조인 결과에서 추가로 행 필터링
- 구문형 조인
    - FROM에 테이블 쉼표 나열
    - WHERE에 조인 조건 작성
- 순수 관계 연산자
    - 선택 σ
    - 투영 π
    - 조인 ⋈
- 등가 조인
    - = 연산자 사용
    - PK–FK 관계에서 일반적
- 비등가 조인
    - = 이외 비교 연산자
    - <, >, <=, >=
    - BETWEEN
    - 특정 값이 범위에 속하는지 비교
- INNER JOIN
    - 조인 조건에 일치하는 행만 반환
    - 불일치 행 제외
- OUTER JOIN
    - 불일치 행도 포함
    - 매칭되지 않는 반대편 열은 NULL
    - LEFT OUTER JOIN
        - 왼쪽 테이블 전체 유지
    - RIGHT OUTER JOIN
        - 오른쪽 테이블 전체 유지
    - FULL OUTER JOIN
        - 양쪽 전체 유지
        - LEFT와 RIGHT 결과의 합집합
- ANSI JOIN
    - JOIN을 FROM에서 명시
    - ON
        - 조인 조건 지정
        - 임의의 열 및 비교식 사용 가능
        - 일반 조건과 분리 가능
    - USING
        - 동일 이름 공통 열 한 번만 명시
        - 공통 열 기준 등가 조인
        - USING 열에 테이블 별칭 사용 불가
        - 제약이 많아 ON을 더 많이 사용
        - SQL Server 미지원
    - NATURAL JOIN
        - 동일 이름의 모든 공통 열 자동 사용
        - ON·USING 생략
        - 별칭 사용 제약
        - 의도하지 않은 열까지 조건이 될 수 있음
        - SQL Server 미지원
- CARTESIAN JOIN
    - 조인 조건 없이 모든 조합 생성
    - FROM A, B
    - 행 수 = A행 × B행
- CROSS JOIN
    - ANSI 방식의 카티션 곱
    - 모든 가능한 행 조합
    - ON 사용 불가
- Oracle 구문형 OUTER JOIN
    - (+) 기호 사용
    - 데이터가 부족한 쪽에 (+)
    - (+)가 없는 쪽 행은 모두 유지
    - 한 비교식 양쪽에 동시에 사용 불가
    - 일반 조건에 (+) 누락 시 INNER JOIN처럼 될 수 있음
    - ANSI에서는 OUTER JOIN과 ON으로 변환

### 6. WHERE 절

#### 기능

- 행 단위 필터링
- 조건이 TRUE인 행만 통과
- FALSE와 UNKNOWN 제외
- GROUP BY 이전 실행

#### 비교 연산자

- =
- !=
- <>
- ^=
- >
- <
- >=
- <=

#### 논리 연산자

- AND
    - 모든 조건이 TRUE일 때 TRUE
- OR
    - 하나 이상 TRUE이면 TRUE

#### 부정 연산자

- NOT
- !=
- <>
- ^=

#### NULL 조건

- NULL은 값이 비어 있는 상태
- = NULL 비교 불가
- IS NULL
- IS NOT NULL

#### IN

- 여러 값 중 하나와 같은지 비교
- 여러 OR 조건의 축약
- NOT IN
- NOT IN 목록에 NULL 포함 시 전체 결과 UNKNOWN 주의

#### BETWEEN

- 범위 비교
- A BETWEEN X AND Y
- A >= X AND A <= Y
- 양쪽 경계 포함
- 작은 값이 앞, 큰 값이 뒤
- NOT BETWEEN

#### LIKE

- 문자열 패턴 비교
- % : 0개 이상의 문자
- _ : 정확히 한 문자
- 대소문자 처리 DBMS별 차이
- NOT LIKE

#### 연산자 우선순위

- 1순위: 괄호 ()
- 2순위: 비교 연산자
    - =, >, <, >=, <=
- 2순위: SQL 연산자
    - IN, BETWEEN, LIKE
- 2순위: NULL 연산자
    - IS NULL, IS NOT NULL
- 3순위: NOT
- 4순위: AND
- 5순위: OR

#### 날짜 조건

- TO_DATE 활용
    - 문자 → 날짜
    - 특정 기간 범위 조회
- TO_CHAR 활용
    - 날짜 → 문자
    - 연·월·일·시간 단위 비교
- 경계값
    - >= 시작 시각
    - <= 종료 시각
    - < 다음 경계
    - <를 쓰면 정확한 상한 시각은 제외

### 7. GROUP BY

#### ① GROUP BY의 기능

- 특정 열을 기준으로 같은 값끼리 그룹화
- 그룹별 합계·평균·개수 등 산출
- 실제 출력 행 수가 그룹 수만큼 감소
- WHERE 이후 실행
- SELECT 이전 실행
- 열 기준 그룹화
- 함수가 포함된 표현식 기준 그룹화 가능

#### GROUP BY 사용 규칙

- SELECT에서 사용 가능한 항목
    - GROUP BY에 명시한 열
    - GROUP BY에 명시한 표현식
    - 집계 함수
- 그룹화되지 않은 일반 열은 SELECT에서 사용 불가

#### ② GROUP BY와 함께 쓰이는 집계 함수

- 다중행 함수
    - 여러 행을 입력
    - 그룹당 결과 하나
- COUNT(*)
    - 모든 행 계산
    - NULL 포함
    - 모든 자료형 가능
- COUNT(열)
    - 해당 열이 NULL인 행 제외
    - 모든 자료형 가능
- COUNT(1), COUNT(0)
    - 상수는 NULL이 아니므로 COUNT(*)와 같은 결과
- SUM(열)
    - 합계
    - 숫자형만 가능
    - NULL 제외
- AVG(열)
    - 평균
    - 숫자형만 가능
    - NULL 제외
    - NULL을 분모에도 포함하지 않음
- MAX(열)
    - 최댓값
    - 숫자·문자·날짜 가능
    - NULL 제외
- MIN(열)
    - 최솟값
    - 숫자·문자·날짜 가능
    - NULL 제외
- DISTINCT
    - COUNT(DISTINCT 열)로 중복 제거 후 집계
- GROUP BY 없는 집계
    - 전체 테이블을 하나의 그룹으로 간주
- 공집합 처리
    - 일반 SELECT → 0행
    - COUNT → 0을 가진 1행
    - 나머지 집계 함수 → NULL을 가진 1행

#### ③ HAVING 절

- GROUP BY로 만들어진 그룹 필터링
- GROUP BY 이후 실행
- SELECT 이전 실행
- 집계 함수 결과를 조건으로 사용 가능
- GROUP BY 열·표현식 사용 가능
- 그룹화되지 않은 일반 열 사용 불가
- WHERE와 비교
    - WHERE
        - 그룹화 전
        - 개별 행 필터링
        - 집계 함수 조건 사용 불가
    - HAVING
        - 그룹화 후
        - 그룹 필터링
        - 집계 함수 조건 사용 가능

### 8. ORDER BY

#### 기능

- 최종 출력 결과 정렬
- 논리적 실행 순서상 마지막
- 생략 시 행 순서 보장 안 됨

#### 정렬 방향

- ASC
    - 오름차순
    - 기본값, 생략 가능
- DESC
    - 내림차순

#### 다중 열 정렬

- 왼쪽에 적은 기준부터 적용
- 첫 번째 기준값이 같을 때 다음 기준 적용
- 각 열마다 ASC·DESC 별도 지정 가능

#### 사용할 수 있는 정렬 기준

- 일반 열 이름
- SELECT 열 순서 번호
    - SELECT 목록의 위치
    - 열 개수보다 큰 번호 사용 불가
    - 가독성이 낮아 열명·별칭 권장
- 열 이름과 순서 번호 혼용
- SELECT에서 정의한 별칭
    - ORDER BY가 SELECT보다 나중에 실행되므로 가능
- CASE 표현식
    - 값별 정렬 우선순위 직접 지정
    - CASE 결과가 정렬 기준이 됨
    - 실제 출력값은 변경되지 않음

#### NULL 정렬

- Oracle
    - ASC → NULL 마지막
    - DESC → NULL 처음
    - NULLS FIRST
    - NULLS LAST
- SQL Server
    - ASC → NULL 처음
    - DESC → NULL 마지막
