# M01-Q28-O4 — 완전한 계층 전개(A,B,C)

## 문제 맥락

[[M01-Q28]]은 EMP(A/NULL,B/A,C/B)에서 START WITH MGR IS NULL CONNECT BY PRIOR ENAME=MGR의 실행 결과를 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 계층형 질의 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- [[계층형 질의]]는 START WITH(MGR IS NULL → A)에서 시작해 CONNECT BY PRIOR ENAME=MGR로 A→B(MGR=A)→C(MGR=B) 순서로 재귀적으로 전개된다.

## Option Text

A,B,C 순서로 출력된 결과

## Contextual Proposition

이 쿼리의 실행 결과는 A,B,C 순서로 출력된다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ④)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. START WITH MGR IS NULL이 A를 루트로 지정함을 확인한다.
2. CONNECT BY PRIOR ENAME=MGR을 적용해 A를 상위로 갖는 B, B를 상위로 갖는 C를 순서대로 연결한다(원본에 없어 PDF 해설에 의존).
3. 전개 결과가 A→B→C 순서임을 확인한다.
4. 따라서 이 선지가 정답이라고 판단한다.

## 올바른 명제

CONNECT BY PRIOR ENAME=MGR은 루트 A에서 시작해 B, C까지 순서대로 전개해 A,B,C를 출력한다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q28-O1]]: A만 출력은 전개 범위가 부족한 오답이다.
- [[M01-Q28-O2]]: A,B만 출력도 전개 범위가 부족한 오답이다.
- [[M01-Q28-O3]]: C,B,A(역순)는 전개 순서를 잘못 서술한 오답이다.
- 이 선지만 전개 범위와 순서를 모두 정확히 반영한다.
