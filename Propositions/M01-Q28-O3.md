# M01-Q28-O3 — 전개 순서를 반대로 서술한 오답(C,B,A)

## 문제 맥락

[[M01-Q28]]은 EMP(A/NULL,B/A,C/B)에서 START WITH MGR IS NULL CONNECT BY PRIOR ENAME=MGR의 실행 결과를 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 계층형 질의 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- [[계층형 질의]]는 START WITH로 지정한 루트(A)부터 상위에서 하위 순서로 전개되므로, 하위(C)부터 나열하는 이 선지는 전개 순서를 반대로 서술했다.

## Option Text

C,B,A 순서로 출력된 결과

## Contextual Proposition

이 쿼리의 실행 결과는 C,B,A 순서로 출력된다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. START WITH MGR IS NULL이 A를 루트(최상위)로 지정함을 확인한다.
2. 계층형 질의는 루트부터 하위로 전개되는 순서(A→B→C)를 따름을 적용한다(원본에 없어 PDF 해설에 의존).
3. 이 선지가 반대 순서(C→B→A)로 서술했음을 비교한다.
4. 따라서 이 선지는 오답이라고 판단한다.

## 올바른 명제

계층형 질의는 루트(A)부터 하위(B,C) 순서로 전개되어 A,B,C 순서로 출력된다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q28-O1]]: A만 출력은 전개 범위 자체가 부족한 오답이다.
- [[M01-Q28-O2]]: A,B만 출력도 전개 범위가 부족한 오답이다.
- [[M01-Q28-O4]]: A,B,C가 완전한 계층 전개 결과이며 공식 정답이다.
- 이 선지는 범위(A,B,C 모두 포함)는 맞지만 순서가 반대인 오답이다.
