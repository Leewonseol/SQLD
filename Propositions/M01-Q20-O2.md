# M01-Q20-O2 — WHERE절의 집계 함수 사용 불가

## 문제 맥락

[[M01-Q20]]은 WHERE절에 SUM(SAL)>1000을 사용해 오류가 발생하는 이유를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#6. WHERE 절]] → WHERE는 GROUP BY 이전 실행, [[SQL 기본#7. GROUP BY]] → ③ HAVING 절(WHERE는 집계 함수 조건 사용 불가, HAVING은 가능)

## 이 선지가 시험하는 개념 관계

- [[WHERE]]는 [[GROUP BY]] 이전에 개별 행을 필터링하는 절이라 [[집계 함수]] 결과를 아직 계산하기 전이므로, WHERE절에서 집계 함수를 조건으로 쓸 수 없다.

## Option Text

WHERE절에서 집계함수 사용불가

## Contextual Proposition

이 쿼리의 오류 원인은 WHERE절에서 집계 함수를 사용할 수 없기 때문이다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ②)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. 쿼리 실행 순서상 WHERE가 GROUP BY(및 집계)보다 먼저 실행됨을 확인한다.
2. 집계 함수는 그룹화 이후에나 의미를 가지므로 WHERE 시점에는 사용할 수 없음을 원본(HAVING 비교표)에서 확인한다.
3. 집계 함수 조건은 HAVING절에서 사용해야 함을 대조한다.
4. 따라서 이 선지가 오류의 실제 원인이라고 판단한다.

## 올바른 명제

집계 함수는 WHERE절에서 사용할 수 없으며, 집계 결과에 조건을 걸려면 HAVING절을 사용해야 한다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q20-O1]]: GROUP BY절 자체는 문제가 없어 오답이다.
- [[M01-Q20-O3]]: SUM 문법 자체는 정상이라 오답이다.
- [[M01-Q20-O4]]: NULL 존재 여부는 이 오류와 무관해 오답이다.
- 이 선지만 WHERE와 HAVING의 실행 순서·용도 차이라는 정확한 원인을 짚는다.
