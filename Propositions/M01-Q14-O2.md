# M01-Q14-O2 — INCLUDE NULLS는 PIVOT 전용이 아님

## 문제 맥락

[[M01-Q14]]는 UNPIVOT 시 NULL 처리에 대한 설명으로 옳은 것을 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 PIVOT·UNPIVOT 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- INCLUDE NULLS/EXCLUDE NULLS 옵션은 [[PIVOT·UNPIVOT]] 양쪽 모두에서 사용될 수 있는 개념으로, PIVOT에서만 쓰인다는 서술은 근거가 없다.

## Option Text

INCLUDE NULLS 옵션은 PIVOT에서만 사용 가능하다.

## Contextual Proposition

INCLUDE NULLS 옵션은 PIVOT에서만 사용할 수 있다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. INCLUDE NULLS/EXCLUDE NULLS가 어느 연산에 적용되는 옵션인지 확인한다(원본에 없어 PDF 해설에 의존).
2. 해설이 EXCLUDE NULLS를 UNPIVOT의 옵션으로 다루고 있어, 이 옵션이 PIVOT 전용이 아님을 확인한다.
3. "PIVOT에서만"이라는 제한이 근거 없이 과도한 단정임을 판단한다.
4. 따라서 이 선지는 옳지 않다고 판단한다.

## 올바른 명제

INCLUDE NULLS·EXCLUDE NULLS는 PIVOT·UNPIVOT 모두에서 사용될 수 있는 NULL 처리 옵션이다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q14-O1]]: EXCLUDE NULLS의 동작을 "치환"으로 잘못 서술한 오답이다.
- [[M01-Q14-O3]]: UNPIVOT의 기본값을 잘못 서술한 오답이다.
- [[M01-Q14-O4]]: EXCLUDE NULLS의 실제 동작을 정확히 서술한 공식 정답이다.
- 이 선지는 옵션의 적용 범위를 잘못 한정한 오답이다.
