# M01-Q22-O4 — NOT IN(NULL)의 UNKNOWN 결과

## 문제 맥락

[[M01-Q22]]는 TBL(1/100,2/200,3/NULL,4/NULL)에 대한 네 쿼리 중 결과가 다른 하나를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#6. WHERE 절]] → IN("NOT IN 목록에 NULL 포함 시 전체 결과 UNKNOWN 주의")

## 이 선지가 시험하는 개념 관계

- [[IN·NOT IN]]에서 NOT IN 목록에 [[NULL]]이 포함되면 비교 결과가 UNKNOWN이 되어 조건을 만족하는 행이 없어지고, 결과 자체가 NULL(공집합의 SUM)이 된다.

## Option Text

SELECT SUM(COL2) FROM TBL WHERE COL2 NOT IN(NULL)

## Contextual Proposition

이 쿼리의 결과는 나머지 세 쿼리와 다르다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ④)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. NOT IN(NULL) 조건에서 목록 자체가 NULL임을 확인한다.
2. 원본 규칙("NOT IN 목록에 NULL 포함 시 전체 결과 UNKNOWN")을 적용한다.
3. 모든 행이 조건을 만족하지 못해(UNKNOWN) 결과 집합이 공집합이 되고, SUM은 NULL을 반환함을 확인한다.
4. O1·O2·O3(모두 300)과 다른 결과이므로 이 선지가 정답이라고 판단한다.

## 올바른 명제

NOT IN(NULL)은 목록에 NULL이 있어 모든 비교가 UNKNOWN이 되고, 결과 집합이 공집합이 되어 SUM은 NULL을 반환한다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q22-O1]]: 조건 없는 SUM은 300을 반환해 이 선지와 결과가 다르다.
- [[M01-Q22-O2]]: BETWEEN 조건도 300을 반환해 이 선지와 결과가 다르다.
- [[M01-Q22-O3]]: IS NOT NULL 조건도 300을 반환해 이 선지와 결과가 다르다.
- 이 선지만 NOT IN과 NULL의 상호작용으로 전혀 다른 결과(NULL)를 만든다.
