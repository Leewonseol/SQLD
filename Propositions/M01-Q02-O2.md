# M01-Q02-O2 — 인덱스와 개념적 모델링의 구분

## 문제 맥락

[[M01-Q02]]는 개념적 데이터 모델링의 특징으로 옳은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[데이터 모델링#6. 데이터 모델링 3단계]] → 물리적 데이터 모델링(인덱스·파티셔닝 등 성능 고려)

## 이 선지가 시험하는 개념 관계

- 인덱스 등 성능 요소 반영은 [[데이터 모델링 3단계]] 중 물리적 데이터 모델링의 특징이지 개념적 데이터 모델링의 특징이 아니다.

## Option Text

인덱스 등의 성능 요소를 반영한다.

## Contextual Proposition

개념적 데이터 모델링은 인덱스 등의 성능 요소를 반영한다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. 문제가 묻는 대상이 "개념적" 데이터 모델링임을 식별한다.
2. 선지 내용(인덱스 등 성능 요소)이 어느 단계의 특징인지 식별한다.
3. 성능 요소 반영은 물리적 모델링 단계의 특징임을 비교한다.
4. 따라서 이 선지는 옳지 않다고 판단한다.

## 올바른 명제

인덱스 등의 성능 요소를 반영하는 것은 물리적 데이터 모델링의 특징이다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q02-O1]]: 물리적 저장 구조 포함도 물리적 모델링 특징이라는 점에서 이 선지와 같은 오답 범주다.
- [[M01-Q02-O3]]: 사용자 관점의 전체 구조 표현이 개념적 모델링의 실제 특징이며 공식 정답이다.
- [[M01-Q02-O4]]: 정규화는 논리적 모델링 단계의 특징이라는 점에서 또 다른 오답 범주다.
- 이 선지는 O1과 함께 물리적 모델링 특징을 다룬다는 공통점이 있다.
