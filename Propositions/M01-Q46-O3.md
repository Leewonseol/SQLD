# M01-Q46-O3 — TRUNCATE는 DELETE보다 빠름

## 문제 맥락

[[M01-Q46]]은 TRUNCATE 명령의 특징으로 옳지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 관리 구문#삭제 명령 비교]] → TRUNCATE: DDL, ROLLBACK 불가(UNDO 로그 없음)

## 이 선지가 시험하는 개념 관계

- [[TRUNCATE]]는 UNDO 로그를 남기지 않아 UNDO 로그를 남기는 [[DELETE]]보다 성능이 빠르다.

## Option Text

DELETE보다 성능이 빠르다.

## Contextual Proposition

TRUNCATE는 DELETE보다 성능이 빠르다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. TRUNCATE와 DELETE의 로그 처리 방식을 원본에서 확인한다.
2. TRUNCATE는 UNDO 로그를 남기지 않아 DELETE보다 빠름을 확인한다.
3. 틀린 내용이 없음을 확인한다.
4. 따라서 "옳지 않은 것"에 해당하지 않는다고 판단한다.

## 올바른 명제

TRUNCATE는 UNDO 로그를 남기지 않아 DELETE보다 성능이 빠르다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q46-O1]]: 모든 데이터 삭제는 옳은 설명으로 오답(정답 아님)이다.
- [[M01-Q46-O2]]: ROLLBACK 복구 가능은 실제로 불가능해 공식 정답이다.
- [[M01-Q46-O4]]: 테이블 구조 유지 설명도 옳아 오답이다.
- 이 선지는 O1·O4와 함께 TRUNCATE의 정상적인 특징을 서술한다.
