# M01-Q21-O2 — ROLLUP(계층적)과 GROUPING SETS(나열)

## 문제 맥락

[[M01-Q21]]은 그룹함수(ROLLUP/CUBE/GROUPING SETS)에 대해 올바른 설명을 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 ROLLUP·CUBE·GROUPING SETS 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- [[그룹함수 확장]] 중 ROLLUP은 계층적 집계를 수행하고, GROUPING SETS는 사용자가 원하는 집계 수준을 직접 나열할 수 있게 한다.

## Option Text

ROLLUP은 계층적 집계 출력하고 GROUPING SETS는 원하는 집계 나열가능하다.

## Contextual Proposition

ROLLUP은 계층적 집계를 출력하고 GROUPING SETS는 원하는 집계를 나열할 수 있다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ②)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. ROLLUP의 동작(계층적 집계)을 확인한다(원본에 없어 PDF 해설에 의존).
2. GROUPING SETS의 동작(원하는 집계 나열)도 확인한다.
3. 두 서술 모두 해설과 일치함을 비교한다.
4. 따라서 이 선지가 정답이라고 판단한다.

## 올바른 명제

ROLLUP은 계층적 집계를, GROUPING SETS는 지정한 집계 수준만 나열해 산출한다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q21-O1]]: ROLLUP·CUBE 역할을 반대로 서술한 오답이다.
- [[M01-Q21-O3]]: CUBE가 전체 그룹 집계 불가라는 주장도 틀린 오답이다.
- [[M01-Q21-O4]]: ROLLUP이 CPU 연산량이 가장 많다는 주장도 틀린 오답이다.
- 이 선지만 세 그룹함수의 실제 동작을 정확히 서술한다.
