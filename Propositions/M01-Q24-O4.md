# M01-Q24-O4 — TOP WITH TIES는 유효한 문법(오류 아님)

## 문제 맥락

[[M01-Q24]]는 TB_SCORE(90,85,85,80,75)에서 TOP(2) WITH TIES 실행 결과의 행 수를 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 TOP WITH TIES 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- TOP(n) WITH TIES는 [[윈도우 함수]] 계열에서 SQL Server가 지원하는 유효한 문법이며, ORDER BY와 함께 사용되는 한 오류를 발생시키지 않는다.

## Option Text

오류발생

## Contextual Proposition

TOP(2) WITH TIES 쿼리는 오류가 발생한다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. TOP(n) WITH TIES 문법이 유효한지 확인한다(원본에 없어 PDF 해설/일반 지식에 의존).
2. WITH TIES는 ORDER BY가 함께 있을 때 사용 가능한 SQL Server 문법임을 확인한다.
3. 쿼리에 ORDER BY SCORE DESC가 포함되어 있어 조건을 만족함을 비교한다.
4. 따라서 오류가 발생하지 않는다고 판단한다.

## 올바른 명제

TOP(2) WITH TIES는 ORDER BY와 함께 사용되어 정상적으로 실행되며 3행을 반환한다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q24-O1]]: 3행이 WITH TIES 규칙을 올바르게 적용한 공식 정답이다.
- [[M01-Q24-O2]]: 2행은 WITH TIES 효과를 무시한 오답이다.
- [[M01-Q24-O3]]: 1행은 TOP의 n 값을 혼동한 오답이다.
- 이 선지는 문법 자체의 유효성을 부정한 근본적 오답이다.
