# M01-Q41-O4 — ORDER BY절에서 서브쿼리 직접 사용 불가

## 문제 맥락

[[M01-Q41]]은 서브쿼리에 대한 설명으로 옳지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 서브쿼리 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- [[서브쿼리]]는 SELECT/FROM/WHERE절과 달리 [[ORDER BY]]절에서는 직접 사용할 수 없다.

## Option Text

ORDER BY절에서 사용가능하다.

## Contextual Proposition

서브쿼리는 ORDER BY절에서 사용할 수 있다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ④)
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. 서브쿼리가 사용될 수 있는 절의 목록(SELECT/FROM/WHERE/HAVING 등)을 원본 부재 상태에서 PDF 해설로 확인한다.
2. ORDER BY절이 이 목록에 포함되지 않음을 확인한다.
3. ORDER BY는 이미 계산된 결과를 정렬하는 절이라 서브쿼리를 직접 넣는 것이 일반적으로 지원되지 않음을 비교한다.
4. 따라서 이 선지는 옳지 않으며 공식 정답이라고 판단한다.

## 올바른 명제

서브쿼리는 SELECT/FROM/WHERE/HAVING절에서는 사용 가능하지만 ORDER BY절에서는 직접 사용할 수 없다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q41-O1]]: SELECT절 사용은 옳아 오답(정답 아님)이다.
- [[M01-Q41-O2]]: FROM절 사용도 옳아 오답이다.
- [[M01-Q41-O3]]: WHERE절 사용도 옳아 오답이다.
- 이 선지만 서브쿼리 사용 불가 절을 정확히 지목한다.
