# M01-Q37-O3 — LENGTH는 공백도 문자로 계산

## 문제 맥락

[[M01-Q37]]은 SQL 함수 사용에 대한 설명으로 옳지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[문자형 함수]] → LENGTH(문자열)/LEN(문자열): 문자열 길이

## 이 선지가 시험하는 개념 관계

- [[문자형 함수]] LENGTH('SQ L')은 공백도 하나의 문자로 계산하므로 'S','Q',' ','L' 총 4글자가 되어 4를 반환한다.

## Option Text

LENGTH('SQ L')의 결과는 4이다.

## Contextual Proposition

LENGTH('SQ L')의 결과는 4다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. 'SQ L'의 글자를 하나씩 센다(S, Q, 공백, L).
2. LENGTH가 공백도 문자로 계산한다는 규칙을 원본에서 확인한다.
3. 총 4글자임을 계산한다.
4. 따라서 이 선지는 옳은 설명이며 "옳지 않은 것"에 해당하지 않는다고 판단한다.

## 올바른 명제

LENGTH('SQ L')은 공백을 포함해 4를 반환한다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q37-O1]]: NVL의 정의는 옳아 오답(정답 아님)이다.
- [[M01-Q37-O2]]: ROUND(123.456,2)=123.5라는 계산이 틀려 공식 정답이다.
- [[M01-Q37-O4]]: MAX가 NULL을 제외한다는 설명도 옳아 오답이다.
- 이 선지는 O1·O4와 함께 정상적인 함수 동작을 서술한다.
