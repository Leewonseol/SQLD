# M01-Q07-O2 — FK의 NULL 허용 여부

## 문제 맥락

[[M01-Q07]]은 외래키(FK)에 대한 설명으로 옳지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 FK의 NULL 허용 여부에 대한 규칙 자체가 없음(PK만 "NULL X"로 명시됨)

## 이 선지가 시험하는 개념 관계

- [[FK]] 컬럼은 [[PK]]와 달리 [[NULL]]을 허용할 수 있다는 규칙이 있으나, 이는 원본 어디에도 명시되어 있지 않다.

## Option Text

외래키 컬럼은 NULL 값을 가질 수 있다.

## Contextual Proposition

외래키 컬럼은 NULL 값을 가질 수 있다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. FK의 NULL 허용 여부를 원본에서 찾는다(없음을 확인).
2. PK는 NULL 불가라는 규칙과 대조해, FK는 별도 NOT NULL 제약이 없는 한 NULL을 가질 수 있음을 일반 규칙으로 판단한다.
3. 이 서술이 틀린 내용이 아님을 확인한다.
4. 따라서 "옳지 않은 것"에 해당하지 않는다고 판단한다.

## 올바른 명제

외래키 컬럼은 별도의 NOT NULL 제약이 없는 한 NULL 값을 가질 수 있다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q07-O1]]: PK·UK 참조 규칙을 다루며, 이 선지보다 원본에 더 가까운 근거(참조 무결성 언급)가 있다.
- [[M01-Q07-O3]]: 참조 무결성 보장은 원본에 직접 명시되어 있어 가장 명확한 오답(정답 아님)이다.
- [[M01-Q07-O4]]: 부모에 없는 값 사용 가능은 참조 무결성에 정면으로 위배되어 공식 정답이다.
- 이 선지는 PK와 FK를 NULL 허용 여부로 대조하는 역할을 한다.
