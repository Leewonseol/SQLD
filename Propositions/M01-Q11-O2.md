# M01-Q11-O2 — SUM 결과를 0으로 오인하는 오답

## 문제 맥락

[[M01-Q11]]은 GROUP BY 없이 SUM(AMOUNT)을 실행했을 때의 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#7. GROUP BY]] → ② 집계 함수(SUM(열): NULL 제외)

## 이 선지가 시험하는 개념 관계

- [[집계 함수]] SUM은 NULL이 하나라도 있으면 결과가 0이 되는 것이 아니라, NULL을 제외한 나머지 값을 합산한다.

## Option Text

0

## Contextual Proposition

SELECT SUM(AMOUNT) FROM TB_SALE;의 실행 결과는 0이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. SUM에 NULL이 포함된 값들이 입력됨을 확인한다.
2. SUM이 NULL을 만나면 전체 결과가 0이 된다는 가정이 맞는지 검토한다.
3. 원본 규칙("SUM은 NULL 제외")에 따르면 이 가정은 틀렸음을 확인한다.
4. 따라서 결과는 0이 아니라고 판단한다.

## 올바른 명제

SUM(AMOUNT)은 NULL을 무시하고 100+200=300을 반환하며 0이 되지 않는다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q11-O1]]: 300이 NULL 제외 합산 규칙을 올바르게 적용한 공식 정답이다.
- [[M01-Q11-O3]]: NULL은 SUM이 NULL을 전파한다고 잘못 가정한 오답이다.
- [[M01-Q11-O4]]: 200은 A의 값을 누락한 계산 오류 오답이다.
- 이 선지는 O3과 함께 "NULL이 있으면 집계 자체가 무효화된다"는 오해에서 비롯된 오답이다.
