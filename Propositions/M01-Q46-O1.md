# M01-Q46-O1 — TRUNCATE는 모든 데이터를 삭제함

## 문제 맥락

[[M01-Q46]]은 TRUNCATE 명령의 특징으로 옳지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 관리 구문#TRUNCATE]] → 테이블의 모든 행 삭제(WHERE 불가)

## 이 선지가 시험하는 개념 관계

- [[TRUNCATE]]는 WHERE 조건 없이 테이블의 모든 데이터를 삭제한다는 것이 원본에 명시되어 있다.

## Option Text

테이블의 모든 데이터를 삭제한다.

## Contextual Proposition

TRUNCATE는 테이블의 모든 데이터를 삭제한다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. TRUNCATE의 정의를 원본에서 확인한다.
2. "테이블의 모든 행 삭제"라는 서술과 이 선지가 일치함을 확인한다.
3. 틀린 내용이 없음을 확인한다.
4. 따라서 "옳지 않은 것"에 해당하지 않는다고 판단한다.

## 올바른 명제

TRUNCATE는 WHERE 조건 없이 테이블의 모든 데이터를 삭제한다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q46-O2]]: ROLLBACK 복구 가능은 실제로 불가능해 공식 정답이다.
- [[M01-Q46-O3]]: DELETE보다 빠르다는 설명도 옳아 오답(정답 아님)이다.
- [[M01-Q46-O4]]: 테이블 구조 유지 설명도 옳아 오답이다.
- 이 선지는 O3·O4와 함께 TRUNCATE의 정상적인 특징을 서술한다.
