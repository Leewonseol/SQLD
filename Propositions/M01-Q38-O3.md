# M01-Q38-O3 — NVL과 SUM의 올바른 결합(930)

## 문제 맥락

[[M01-Q38]]은 TEST(COL1: 10,NULL,20)에서 SELECT SUM(NVL(COL1,900)) FROM TEST;의 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#4. 공통 표현 도구]] → NULL 함수(NVL), [[SQL 기본#7. GROUP BY]] → SUM(열)

## 이 선지가 시험하는 개념 관계

- [[NULL]] 함수 NVL(COL1,900)이 NULL을 900으로 대체한 뒤(10,900,20), [[집계 함수]] SUM이 이를 모두 합산해 930을 반환한다.

## Option Text

930

## Contextual Proposition

SELECT SUM(NVL(COL1,900)) FROM TEST;의 실행 결과는 930이다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ③)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. NVL(COL1,900)을 각 행(10, NULL, 20)에 적용해 (10, 900, 20)을 얻는다.
2. SUM이 이 세 값을 모두 합산함을 적용한다.
3. 10+900+20=930을 계산한다.
4. 따라서 이 선지가 정답이라고 판단한다.

## 올바른 명제

NVL(COL1,900) 적용 후 SUM은 10+900+20=930이다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q38-O1]]: 30은 NVL 대체 자체를 빠뜨린 오답이다.
- [[M01-Q38-O2]]: NULL은 SUM이 NULL을 무시하지 않는다고 잘못 가정한 오답이다.
- [[M01-Q38-O4]]: 900은 대체값만 반영하고 나머지 값을 누락한 오답이다.
- 이 선지만 NVL 대체와 SUM 합산을 모두 정확히 적용했다.
