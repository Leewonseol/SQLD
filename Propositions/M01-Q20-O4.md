# M01-Q20-O4 — NULL 존재 여부는 이 오류와 무관

## 문제 맥락

[[M01-Q20]]은 WHERE절에 SUM(SAL)>1000을 사용해 오류가 발생하는 이유를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#7. GROUP BY]] → ② 집계 함수(SUM(열): NULL 제외, 문법 오류와 무관)

## 이 선지가 시험하는 개념 관계

- [[NULL]] 값의 존재 여부는 [[집계 함수]] SUM의 계산 결과에는 영향을 주지만, [[WHERE]]절에서 집계 함수를 쓸 수 없다는 문법적 오류와는 무관하다.

## Option Text

SAL컬럼에 NULL있으면 오류발생

## Contextual Proposition

이 쿼리의 오류 원인은 SAL 컬럼에 NULL이 있기 때문이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. SAL 컬럼에 NULL이 있을 때 SUM이 어떻게 동작하는지 확인한다(NULL 제외 후 계산, 오류 아님).
2. 이 문제의 오류가 데이터 값(NULL 존재)이 아니라 쿼리 구조(WHERE절 집계 함수 사용)에서 비롯됨을 확인한다.
3. NULL 존재 자체는 정상적으로 처리되며 오류를 유발하지 않음을 비교한다.
4. 따라서 이 선지는 오류의 원인을 잘못 짚었다고 판단한다.

## 올바른 명제

SAL 컬럼의 NULL 존재는 SUM 계산에서 정상적으로 제외될 뿐 오류를 유발하지 않으며, 실제 오류 원인은 WHERE절의 집계 함수 사용이다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q20-O1]]: GROUP BY절 자체는 문제가 없어 같은 오답 범주다.
- [[M01-Q20-O2]]: WHERE절 집계 함수 사용 불가가 실제 오류 원인이며 공식 정답이다.
- [[M01-Q20-O3]]: SUM 문법 자체는 정상이라 같은 오답 범주다.
- 이 선지는 데이터 값의 문제(NULL)와 쿼리 구조의 문제(WHERE 사용 위치)를 혼동한 오답이다.
