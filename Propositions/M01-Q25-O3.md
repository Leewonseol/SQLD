# M01-Q25-O3 — 숫자 패턴의 정확한 추출(123)

## 문제 맥락

[[M01-Q25]]는 SELECT REGEXP_SUBSTR('abc123xyz','[0-9]+') FROM DUAL;의 결과를 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 정규표현식 함수 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- [[정규표현식 함수]] REGEXP_SUBSTR은 패턴 [0-9]+(숫자 1개 이상 연속)과 정확히 일치하는 부분만 추출하므로 '123'을 반환한다.

## Option Text

123

## Contextual Proposition

REGEXP_SUBSTR('abc123xyz','[0-9]+')의 결과는 123이다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ③)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. 문자열 'abc123xyz'를 앞에서부터 탐색한다.
2. 패턴 [0-9]+가 숫자 1개 이상 연속되는 부분과 매칭됨을 적용한다.
3. '1','2','3'까지 연속 매칭되고 그 다음 'x'에서 매칭이 종료됨을 확인한다.
4. 따라서 '123'이 추출되어 이 선지가 정답이라고 판단한다.

## 올바른 명제

REGEXP_SUBSTR('abc123xyz','[0-9]+')는 숫자가 연속되는 '123'을 반환한다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q25-O1]]: abc는 숫자가 아닌 부분을 추출한 오답이다.
- [[M01-Q25-O2]]: abcxyz도 숫자가 아닌 부분을 추출한 오답이다.
- [[M01-Q25-O4]]: 123xyz는 숫자 뒤 문자까지 포함해 패턴 범위를 초과한 오답이다.
- 이 선지만 패턴이 정확히 지정한 숫자 연속 구간과 일치한다.
