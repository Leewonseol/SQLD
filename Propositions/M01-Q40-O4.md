# M01-Q40-O4 — ROLLBACK을 반영하지 않은 오답(3행)

## 문제 맥락

[[M01-Q40]]은 INSERT A → INSERT B → DELETE(A) → CREATE TABLE DEPT → INSERT C → ROLLBACK 순서 실행 후 EMP의 행 수를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 관리 구문#ROLLBACK]] → 트랜잭션 변경 내용 취소, [[SQL 관리 구문#AUTO COMMIT]] → DDL 자동 커밋

## 이 선지가 시험하는 개념 관계

- 이 선지(3행)는 [[ROLLBACK]]이 전혀 적용되지 않아 INSERT C까지 모두 반영된 것으로 계산한 것이며, 실제로는 C를 삽입한 [[Transaction]]이 ROLLBACK으로 취소된다.

## Option Text

3

## Contextual Proposition

일련의 SQL 실행 후 EMP 테이블의 행 수는 3이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. DELETE(A) 이후 (B) 상태, CREATE TABLE(DDL)로 이 상태가 확정됨을 확인한다.
2. INSERT C로 (B,C) 상태가 됨을 확인한다.
3. ROLLBACK이 C를 삽입한 트랜잭션을 취소해 (B)만 남음을 적용한다(원본에 이 실전 절차는 없어 AUTO COMMIT/ROLLBACK 규칙으로 추론).
4. 이 선지(3행)가 ROLLBACK을 반영하지 않고 C까지 포함했음을 비교해 오답이라고 판단한다.

## 올바른 명제

ROLLBACK이 C 삽입 트랜잭션을 취소해 최종 행 수는 3이 아니라 1(B만)이다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q40-O1]]: 0은 ROLLBACK이 전체를 되돌린다고 오판한 오답이다.
- [[M01-Q40-O2]]: 1(B만 남음)이 DDL 자동 커밋과 ROLLBACK 범위를 정확히 추적한 공식 정답이다.
- [[M01-Q40-O3]]: 2는 DELETE 단계를 누락한 오답이다.
- 이 선지는 O1과 정반대로 ROLLBACK 효과 자체를 누락한 오답이다.
