# M01-Q11-O3 — SUM 결과를 NULL로 오인하는 오답

## 문제 맥락

[[M01-Q11]]은 GROUP BY 없이 SUM(AMOUNT)을 실행했을 때의 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#7. GROUP BY]] → ② 집계 함수(SUM(열): NULL 제외)

## 이 선지가 시험하는 개념 관계

- [[집계 함수]] SUM은 NULL을 만나도 결과 전체가 NULL로 전파되지 않고, NULL이 아닌 값들만 골라 합산한다.

## Option Text

NULL

## Contextual Proposition

SELECT SUM(AMOUNT) FROM TB_SALE;의 실행 결과는 NULL이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. 산술 연산에서는 NULL이 포함되면 결과가 NULL이 된다는 규칙(SELECT절 산술 연산)을 떠올린다.
2. 이 규칙이 개별 값 간의 산술 연산에 적용되는 것이지, 집계 함수 SUM에는 적용되지 않음을 구분한다.
3. 원본 규칙("SUM은 NULL 제외")에 따라 SUM은 NULL을 건너뛰고 계산함을 확인한다.
4. 따라서 결과는 NULL이 아니라고 판단한다.

## 올바른 명제

SUM은 산술 연산과 달리 NULL을 제외하고 계산하므로 결과가 NULL이 되지 않는다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q11-O1]]: 300이 NULL 제외 합산 규칙을 올바르게 적용한 공식 정답이다.
- [[M01-Q11-O2]]: 0은 SUM이 NULL을 만나면 무효화된다고 잘못 가정한 오답이다.
- [[M01-Q11-O4]]: 200은 A의 값을 누락한 계산 오류 오답이다.
- 이 선지는 개별 행 산술 연산의 NULL 규칙을 집계 함수에 잘못 적용한 대표적 함정이다.
