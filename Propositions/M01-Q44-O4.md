# M01-Q44-O4 — 부분적으로만 회수된 것으로 오판한 오답

## 문제 맥락

[[M01-Q44]]는 DBA→USER1→USER2→USER3로 WITH GRANT OPTION을 통해 전이된 권한 중 DBA가 USER1의 권한을 REVOKE했을 때 남는 권한 상태를 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 DCL(GRANT/REVOKE/WITH GRANT OPTION) 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- [[DCL]]의 연쇄 회수 규칙에 따르면 USER2·USER3의 권한도 모두 회수되어야 하는데, 이 선지는 UPDATE 권한만 회수되고 SELECT 권한은 남는다고 서술한다.

## Option Text

USER1 권한없음 / USER2: SELECT / USER3: SELECT

## Contextual Proposition

DBA가 USER1의 권한을 REVOKE하면 USER2·USER3는 SELECT 권한만 남는다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. 권한 전이 경로와 연쇄 회수 규칙을 확인한다(원본에 없어 PDF 해설에 의존).
2. 연쇄 회수는 특정 권한 종류(SELECT/UPDATE)를 구분하지 않고 전이된 권한 전체를 회수함을 적용한다.
3. 이 선지가 SELECT만 예외적으로 남긴 것이 규칙과 어긋남을 비교한다.
4. 따라서 이 선지는 오답이라고 판단한다.

## 올바른 명제

연쇄 회수는 권한 종류를 구분하지 않고 전이된 권한 전체를 회수하므로 USER2·USER3의 SELECT 권한도 함께 없어진다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q44-O1]]: 세 사용자 모두 권한 없음이 연쇄 회수를 정확히 반영한 공식 정답이다.
- [[M01-Q44-O2]]: USER3만 SELECT 유지는 이 선지와 유사하게 부분 회수로 오판한 오답이다.
- [[M01-Q44-O3]]: USER2·USER3가 권한을 유지한다는 주장은 연쇄 회수를 전혀 반영하지 않은 오답이다.
- 이 선지는 O2와 함께 연쇄 회수를 특정 권한만 남기는 것으로 축소한 오답이다.
