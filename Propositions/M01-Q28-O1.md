# M01-Q28-O1 — 루트(A)만 출력한 불완전한 전개

## 문제 맥락

[[M01-Q28]]은 EMP(A/NULL,B/A,C/B)에서 START WITH MGR IS NULL CONNECT BY PRIOR ENAME=MGR의 실행 결과를 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 계층형 질의 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- [[계층형 질의]]는 START WITH로 지정한 루트(A)에서 시작해 CONNECT BY PRIOR로 하위 계층(B,C)까지 재귀적으로 전개해야 하는데, 이 선지는 루트만 출력해 전개가 멈춘 결과다.

## Option Text

A만 출력된 결과

## Contextual Proposition

이 쿼리의 실행 결과는 A만 출력된다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. START WITH MGR IS NULL이 A를 루트로 지정함을 확인한다.
2. CONNECT BY PRIOR ENAME=MGR이 A를 상위로 갖는 B, B를 상위로 갖는 C까지 재귀적으로 전개함을 적용한다(원본에 없어 PDF 해설에 의존).
3. 전개가 A에서 멈추지 않고 B,C까지 이어져야 함을 비교한다.
4. 따라서 A만 출력되는 것은 전개가 불완전한 오답이라고 판단한다.

## 올바른 명제

계층형 질의는 A→B→C로 모두 전개되어 A,B,C가 출력되어야 한다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q28-O2]]: A,B만 출력은 C까지 전개하지 못한 오답이다.
- [[M01-Q28-O3]]: C,B,A(역순)는 전개 순서를 잘못 서술한 오답이다.
- [[M01-Q28-O4]]: A,B,C가 완전한 계층 전개 결과이며 공식 정답이다.
- 이 선지는 전개가 가장 적게 이루어진 오답이다.
