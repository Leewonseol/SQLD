# M01-Q19-O4 — COUNT(*)와 COUNT(열)의 혼동(3)

## 문제 맥락

[[M01-Q19]]는 T1 LEFT OUTER JOIN T2 결과에서 COUNT(T2.COL1)의 값을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#7. GROUP BY]] → COUNT(*): NULL 포함 / COUNT(열): NULL 제외

## 이 선지가 시험하는 개념 관계

- [[COUNT]](*)는 [[NULL]]을 포함해 전체 행 수(3행)를 세지만, 이 문제는 COUNT(T2.COL1)(열 기준)이므로 NULL을 제외해야 한다는 점에서 이 선지는 두 COUNT 방식을 혼동한 결과다.

## Option Text

3

## Contextual Proposition

SELECT COUNT(T2.COL1) FROM T1 LEFT OUTER JOIN T2 ON(...);의 실행 결과는 3이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. LEFT OUTER JOIN 결과가 총 3행(1,NULL),(2,2),(3,3)임을 확인한다.
2. COUNT(*)라면 3행 모두 세지만, 이 문제는 COUNT(T2.COL1)(열 기준)임을 확인한다.
3. COUNT(열)은 NULL인 행(1,NULL)을 제외해야 함을 비교한다.
4. 따라서 3은 COUNT(*)와 COUNT(열)을 혼동한 오답이라고 판단한다.

## 올바른 명제

COUNT(T2.COL1)은 NULL을 제외해 2를 반환하며, 전체 행 수(3)와는 다르다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q19-O1]]: 0은 조인 결과 자체를 잘못 이해한 오답이다.
- [[M01-Q19-O2]]: 1은 값 하나를 누락한 계산 오류 오답이다.
- [[M01-Q19-O3]]: 2가 NULL 제외 COUNT를 올바르게 적용한 공식 정답이다.
- 이 선지는 COUNT(*)와 COUNT(열)의 차이를 가장 직접적으로 시험하는 함정이다.
