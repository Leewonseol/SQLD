# M01-Q37-O4 — MAX는 NULL을 제외하고 계산

## 문제 맥락

[[M01-Q37]]은 SQL 함수 사용에 대한 설명으로 옳지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#7. GROUP BY]] → MAX(열): 최댓값, NULL 제외

## 이 선지가 시험하는 개념 관계

- [[집계 함수]] MAX는 [[NULL]]을 제외하고 나머지 값 중 최댓값을 계산한다는 것이 원본에 명시되어 있다.

## Option Text

MAX(SAL)함수는 NULL값을 제외하고 최댓값을 계산한다.

## Contextual Proposition

MAX(SAL) 함수는 NULL 값을 제외하고 최댓값을 계산한다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. MAX 함수의 NULL 처리 규칙을 원본에서 확인한다.
2. "NULL 제외"라는 원본 서술과 이 선지가 일치함을 확인한다.
3. 틀린 내용이 없음을 확인한다.
4. 따라서 "옳지 않은 것"에 해당하지 않는다고 판단한다.

## 올바른 명제

MAX(SAL)은 NULL을 제외하고 나머지 값 중 최댓값을 반환한다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q37-O1]]: NVL의 정의는 옳아 오답(정답 아님)이다.
- [[M01-Q37-O2]]: ROUND(123.456,2)=123.5라는 계산이 틀려 공식 정답이다.
- [[M01-Q37-O3]]: LENGTH('SQ L')=4라는 설명도 옳아 오답이다.
- 이 선지는 O1·O3과 함께 정상적인 함수 동작을 서술한다.
