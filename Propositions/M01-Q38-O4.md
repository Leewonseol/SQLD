# M01-Q38-O4 — 대체값만 반영한 오답(900)

## 문제 맥락

[[M01-Q38]]은 TEST(COL1: 10,NULL,20)에서 SELECT SUM(NVL(COL1,900)) FROM TEST;의 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#4. 공통 표현 도구]] → NULL 함수(NVL), [[SQL 기본#7. GROUP BY]] → SUM(열)

## 이 선지가 시험하는 개념 관계

- NVL(COL1,900)은 NULL인 행에만 900을 대체하고 나머지 행(10, 20)은 원래 값을 유지하는데, 이 선지(900)는 대체값만 남기고 나머지 값을 누락했다.

## Option Text

900

## Contextual Proposition

SELECT SUM(NVL(COL1,900)) FROM TEST;의 실행 결과는 900이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. NVL(COL1,900)이 각 행(10, NULL, 20)에 적용된 결과(10, 900, 20)를 확인한다.
2. 이 선지(900)가 대체값만 남기고 10과 20을 누락했음을 확인한다.
3. SUM은 세 값을 모두 합산해야 함을 비교한다.
4. 따라서 이 선지는 계산 누락 오답이라고 판단한다.

## 올바른 명제

NVL 적용 후 SUM은 대체값(900)뿐 아니라 나머지 값(10,20)도 모두 합산해 930이 된다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q38-O1]]: 30은 NVL 대체 자체를 빠뜨린 오답이다.
- [[M01-Q38-O2]]: NULL은 SUM이 NULL을 무시하지 않는다고 잘못 가정한 오답이다.
- [[M01-Q38-O3]]: 930이 NVL과 SUM을 올바르게 결합한 공식 정답이다.
- 이 선지는 O1과 반대로 원래 값(10,20)을 빠뜨린 오답이다.
