# M01-Q36-O4 — 정렬 방향이 다른 유일한 쿼리(1,2 DESC)

## 문제 맥락

[[M01-Q36]]은 네 가지 ORDER BY 작성 방식 중 결과가 다른 하나를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#8. ORDER BY]] → 다중 열 정렬(각 열마다 ASC·DESC 별도 지정 가능)

## 이 선지가 시험하는 개념 관계

- [[ORDER BY]] 1,2 DESC는 1번 열(ENAME)이 ASC(기본값), 2번 열(SAL)만 DESC로 지정되어, 나머지 세 쿼리(ENAME DESC, SAL ASC)와 정렬 방향이 반대다.

## Option Text

SELECT ENAME,SAL FROM EMP ORDER BY 1,2 DESC

## Contextual Proposition

이 쿼리의 정렬 결과는 나머지 세 쿼리와 다르다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ④)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. ORDER BY 1,2 DESC에서 DESC가 몇 번째 열에 적용되는지 확인한다.
2. DESC는 바로 앞의 열(2번, SAL)에만 적용되고 1번 열(ENAME)은 기본값 ASC임을 원본 규칙("각 열마다 ASC·DESC 별도 지정 가능")으로 확인한다.
3. 나머지 세 쿼리(ENAME DESC, SAL ASC)와 정렬 방향이 반대(ENAME ASC, SAL DESC)임을 비교한다.
4. 따라서 이 쿼리만 결과가 다르며 이 선지가 정답이라고 판단한다.

## 올바른 명제

ORDER BY 1,2 DESC는 ENAME 오름차순, SAL 내림차순으로 정렬되어 나머지 세 쿼리(ENAME 내림차순, SAL 오름차순)와 결과가 다르다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q36-O1]]: 별칭 사용 쿼리는 O2·O3과 결과가 같아 오답(정답 아님)이다.
- [[M01-Q36-O2]]: 순서번호 사용 쿼리도 O1·O3과 결과가 같아 오답이다.
- [[M01-Q36-O3]]: 열 이름 사용 쿼리도 O1·O2와 결과가 같아 오답이다.
- 이 선지만 DESC가 적용되는 열이 달라 정렬 방향 자체가 반대다.
