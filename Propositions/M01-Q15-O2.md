# M01-Q15-O2 — 문자열 사전식 내림차순 정렬(D,C,A,B)

## 문제 맥락

[[M01-Q15]]는 문자형 COL2를 기준으로 ORDER BY DESC 정렬했을 때 COL1의 출력 순서를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#8. ORDER BY]] → 정렬 방향(DESC), [[자료형]] → 문자열 사전식 비교 규칙은 명시되어 있지 않음

## 이 선지가 시험하는 개념 관계

- COL2가 [[자료형]]상 문자열(VARCHAR2)이므로, [[ORDER BY]] DESC는 숫자 크기가 아니라 문자열 사전식 비교로 정렬한다.

## Option Text

D,C,A,B

## Contextual Proposition

COL2 기준 내림차순 정렬 시 COL1의 출력 순서는 D,C,A,B다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ②)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. 각 COL1의 COL2 값(A=100, B=99, C=900, D=1000)을 확인한다.
2. COL2가 문자형임을 확인하고, 문자열 사전식 비교('1'<'9') 규칙을 적용한다(원본에 이 규칙 없어 별도 추론 필요).
3. 사전식 비교로 내림차순 정렬하면 '99'(B) > '900'(C) > '1000'(D) > '100'(A) 순서가 아니라, 첫 글자 기준으로 '9'로 시작하는 '99','900'이 '1'로 시작하는 '1000','100'보다 크므로 D,C,A,B 순서가 됨을 계산한다.
4. 따라서 이 선지가 정답이라고 판단한다.

## 올바른 명제

COL2를 문자열 사전식으로 내림차순 정렬하면 COL1의 순서는 D,C,A,B다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q15-O1]]: B,C,D,A는 사전식 비교 규칙을 적용하지 않은 오답이다.
- [[M01-Q15-O3]]: B,A,C,D도 사전식 비교와 맞지 않는 오답이다.
- [[M01-Q15-O4]]: D,C,B,A는 숫자 크기 기준으로 계산해 A와 B의 순서가 뒤바뀐 오답이다.
- 이 선지만 문자열 사전식 비교와 DESC 방향을 정확히 결합했다.
