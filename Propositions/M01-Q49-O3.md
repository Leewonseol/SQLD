# M01-Q49-O3 — COUNT(*)와 COUNT(열)을 혼동한 오답(10)

## 문제 맥락

[[M01-Q49]]는 TBL(VAL: 10,20,30,NULL)에서 SELECT SUM(VAL)/COUNT(*) FROM TBL;의 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#7. GROUP BY]] → COUNT(*): NULL 포함(전체 행수 4) vs COUNT(열): NULL 제외(3)

## 이 선지가 시험하는 개념 관계

- 이 선지(10)는 분모를 [[COUNT]](*)(4) 대신 COUNT(VAL)(NULL 제외 3)로 계산한 것으로 보이며(60/6이 아닌 60/... 값이 10이 되려면 다른 계산 경로가 필요), [[집계 함수]]의 NULL 처리 방식을 혼동한 오답이다.

## Option Text

10

## Contextual Proposition

SELECT SUM(VAL)/COUNT(*) FROM TBL;의 실행 결과는 10이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. SUM(VAL)=60, COUNT(*)=4를 각각 계산한다.
2. 60/4=15이지 10이 아님을 확인한다.
3. 이 선지가 COUNT(*)와 COUNT(열)의 NULL 처리 차이, 또는 다른 분모를 혼동했을 가능성을 검토한다.
4. 따라서 이 선지는 계산이 틀린 오답이라고 판단한다.

## 올바른 명제

COUNT(*)는 NULL을 포함한 전체 행수(4)를 반환하며, 이를 기준으로 SUM(VAL)/COUNT(*)는 15가 되어야 한다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q49-O1]]: 20도 정확한 계산 근거가 불분명한 오답이다.
- [[M01-Q49-O2]]: 15가 SUM과 COUNT(*)를 정확히 결합한 공식 정답이다.
- [[M01-Q49-O4]]: NULL은 SUM이 계산 자체가 불가능하다고 잘못 가정한 오답이다.
- 이 선지는 COUNT(*)와 COUNT(열)의 NULL 처리 차이를 혼동시키는 함정으로 보인다.
