# M01-Q13-O1 — NVL 결과를 NULL로 오인하는 오답

## 문제 맥락

[[M01-Q13]]은 EMP에서 ENAME='B'인 행의 NVL(SAL,0) 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#4. 공통 표현 도구]] → NULL 함수(NVL(값1, 값2): 값1이 NULL이면 값2 반환)

## 이 선지가 시험하는 개념 관계

- [[NULL]] 함수 NVL은 첫 인자가 NULL일 때 대체값을 반환하므로 결과가 NULL로 남지 않는다.

## Option Text

NULL

## Contextual Proposition

SELECT NVL(SAL,0) FROM EMP WHERE ENAME='B';의 실행 결과는 NULL이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. B의 SAL 값이 NULL임을 확인한다.
2. NVL(값1, 값2) 규칙(값1이 NULL이면 값2 반환)을 적용한다.
3. NVL(NULL, 0)의 결과가 0이지 NULL이 아님을 확인한다.
4. 따라서 이 선지는 틀렸다고 판단한다.

## 올바른 명제

NVL(SAL,0)은 SAL이 NULL일 때 0을 반환하므로 결과는 NULL이 아니라 0이다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q13-O2]]: 0이 NVL 규칙을 올바르게 적용한 공식 정답이다.
- [[M01-Q13-O3]]: 1000은 C의 값과 혼동한 오답이다.
- [[M01-Q13-O4]]: 5000은 A의 값과 혼동한 오답이다.
- 이 선지는 NVL의 대체 기능 자체를 적용하지 않은 오답이다.
