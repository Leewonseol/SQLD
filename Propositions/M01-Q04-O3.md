# M01-Q04-O3 — 정규화 관점(존재하지 않는 관점)

## 문제 맥락

[[M01-Q04]]는 모델링 관점으로 올바르지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[데이터 모델링#3. 관점]] → 데이터/프로세스/상관 관점 3가지만 명시, "정규화 관점"은 없음

## 이 선지가 시험하는 개념 관계

- [[데이터 모델링 관점]]은 데이터·프로세스·상관 3가지뿐이며, [[정규화]]는 별개의 개념(논리적 모델링 단계에서 수행하는 작업)이지 관점이 아니다.

## Option Text

정규화 관점

## Contextual Proposition

정규화 관점은 모델링 관점으로 올바르지 않다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ③)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. 원본에 명시된 3관점(데이터/프로세스/상관)을 확인한다.
2. 선지(정규화 관점)가 이 목록에 포함되는지 확인한다.
3. 포함되지 않으며, 정규화는 관점이 아니라 정규화 자체가 별도 개념임을 확인한다.
4. 따라서 "올바르지 않은 것"에 해당해 공식 정답이라고 판단한다.

## 올바른 명제

모델링 관점은 데이터 관점, 프로세스 관점, 상관 관점 3가지뿐이며 정규화 관점은 존재하지 않는다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q04-O1]]: 데이터 관점은 실제 존재하는 관점으로 오답이다.
- [[M01-Q04-O2]]: 상관 관점도 실제 존재하는 관점으로 오답이다.
- [[M01-Q04-O4]]: 프로세스 관점도 실제 존재하는 관점으로 오답이다.
- 이 선지만 원본에 없는 개념(정규화)을 관점인 것처럼 제시하는 함정이다.
