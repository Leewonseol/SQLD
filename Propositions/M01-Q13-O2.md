# M01-Q13-O2 — NVL(SAL,0)의 올바른 결과(0)

## 문제 맥락

[[M01-Q13]]은 EMP에서 ENAME='B'인 행의 NVL(SAL,0) 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#4. 공통 표현 도구]] → NULL 함수(NVL(값1, 값2): 값1이 NULL이면 값2 반환)

## 이 선지가 시험하는 개념 관계

- B의 SAL이 [[NULL]]이므로 NVL 함수가 두 번째 인자(0)를 대신 반환한다.

## Option Text

0

## Contextual Proposition

SELECT NVL(SAL,0) FROM EMP WHERE ENAME='B';의 실행 결과는 0이다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ②)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. B의 SAL 값이 NULL임을 확인한다.
2. NVL(값1, 값2) 규칙(값1이 NULL이면 값2 반환)을 적용한다.
3. NVL(NULL, 0)의 결과가 0임을 확인한다.
4. 따라서 이 선지가 정답이라고 판단한다.

## 올바른 명제

NVL(SAL,0)은 SAL이 NULL일 때 0을 반환한다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q13-O1]]: NULL은 NVL의 대체 기능을 적용하지 않은 오답이다.
- [[M01-Q13-O3]]: 1000은 C의 값과 혼동한 오답이다.
- [[M01-Q13-O4]]: 5000은 A의 값과 혼동한 오답이다.
- 이 선지만 NVL의 대체 규칙과 조건(ENAME='B')을 정확히 결합했다.
