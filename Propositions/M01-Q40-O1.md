# M01-Q40-O1 — 전체 롤백으로 오인한 오답(0행)

## 문제 맥락

[[M01-Q40]]은 INSERT A → INSERT B → DELETE(A) → CREATE TABLE DEPT → INSERT C → ROLLBACK 순서 실행 후 EMP의 행 수를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 관리 구문#AUTO COMMIT]] → Oracle: DDL 실행 시 자동 COMMIT, [[SQL 관리 구문#ROLLBACK]] → 마지막 COMMIT 시점으로 복구

## 이 선지가 시험하는 개념 관계

- 이 선지(0행)는 ROLLBACK이 트랜잭션 전체를 처음부터 되돌린다고 가정한 것이며, 실제로는 [[DDL]](CREATE TABLE)이 그 이전 변경을 [[AUTO COMMIT]]으로 이미 확정시킨다.

## Option Text

0

## Contextual Proposition

일련의 SQL 실행 후 EMP 테이블의 행 수는 0이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. INSERT A, INSERT B로 (A,B)가 삽입됨을 확인한다.
2. DELETE(A)로 A가 삭제되어 (B)만 남음을 확인한다.
3. CREATE TABLE DEPT(DDL)이 Oracle에서 자동 COMMIT을 유발해 그 이전까지의 변경(B 존재)이 확정됨을 적용한다(원본에 이 실전 절차는 없어 AUTO COMMIT 규칙으로 추론).
4. 이후 INSERT C, ROLLBACK은 새 트랜잭션(C 삽입)만 취소하므로 B는 남아있어 0행이 아니라고 판단한다.

## 올바른 명제

CREATE TABLE(DDL)이 그 이전 변경을 자동 확정시켜 B가 남으므로 최종 행 수는 1(B)이다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q40-O2]]: 1(B만 남음)이 DDL 자동 커밋과 ROLLBACK 범위를 정확히 추적한 공식 정답이다.
- [[M01-Q40-O3]]: 2는 A가 삭제되지 않았다고 오판한 오답이다.
- [[M01-Q40-O4]]: 3은 ROLLBACK이 전혀 적용되지 않았다고 오판한 오답이다.
- 이 선지는 DDL의 자동 커밋 효과를 무시하고 전체가 취소된다고 본 오답이다.
