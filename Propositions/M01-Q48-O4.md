# M01-Q48-O4 — SQL Server ALTER COLUMN은 한 번에 한 컬럼만 변경

## 문제 맥락

[[M01-Q48]]은 테이블 컬럼 변경 문법으로 올바르지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 관리 구문#ALTER]] → 자료형·속성 변경: SQL Server(ALTER COLUMN) — 다중 컬럼 동시 변경 가능 여부는 원본에 명시 없음

## 이 선지가 시험하는 개념 관계

- SQL Server [[ALTER]] COLUMN은 한 번에 한 컬럼만 변경할 수 있으며, Oracle MODIFY처럼 괄호로 여러 컬럼을 묶는 문법은 존재하지 않는다(선지 근거, 원본에는 명시되어 있지 않음).

## Option Text

ALTER TABLE EMP ALTER COLUMN(COL1 VARCHAR(20),COL2 VARCHAR(20));

## Contextual Proposition

이 문법은 컬럼을 변경하는 올바르지 않은 문법이다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ④)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. VARCHAR(VARCHAR2 아님) 표기로 SQL Server 문법임을 식별한다.
2. ALTER COLUMN(...) 괄호 안에 여러 컬럼(COL1, COL2)을 묶으려 시도했음을 확인한다.
3. PDF 해설에 따르면 SQL Server ALTER COLUMN은 한 번에 한 컬럼만 변경 가능하며 괄호로 묶는 문법이 없음을 적용한다(원본에는 이 세부 규칙이 없음).
4. 따라서 이 문법은 존재하지 않아 옳지 않으며 공식 정답이라고 판단한다.

## 올바른 명제

SQL Server ALTER COLUMN은 한 번에 한 컬럼만 변경할 수 있으며, 여러 컬럼을 괄호로 묶는 문법은 존재하지 않는다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q48-O1]]: Oracle MODIFY 단일 컬럼 변경은 옳은 문법으로 오답(정답 아님)이다.
- [[M01-Q48-O2]]: SQL Server ALTER COLUMN 단일 컬럼 변경도 옳다.
- [[M01-Q48-O3]]: Oracle MODIFY로 여러 컬럼을 묶는 문법은 실제로 가능해 오답이다.
- 이 선지만 SQL Server에 존재하지 않는 다중 컬럼 묶음 문법을 전제로 한 오답이다.
