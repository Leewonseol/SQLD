# M01-Q32-O1 — = NULL은 비교 불가

## 문제 맥락

[[M01-Q32]]는 SQL에서 NULL 비교가 옳은 방식을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#6. WHERE 절]] → NULL 조건(= NULL 비교 불가, IS NULL/IS NOT NULL 사용)

## 이 선지가 시험하는 개념 관계

- [[NULL]]은 = 연산자로 비교할 수 없으므로 WHERE COL=NULL은 항상 아무 행도 반환하지 않는다.

## Option Text

WHERE COL=NULL

## Contextual Proposition

WHERE COL=NULL은 NULL을 비교하는 옳은 방식이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. NULL의 비교 규칙(= 연산자 사용 불가)을 원본에서 확인한다.
2. COL=NULL이 이 규칙을 위반함을 확인한다.
3. 이 방식은 항상 UNKNOWN을 반환해 의도한 결과를 얻지 못함을 비교한다.
4. 따라서 이 선지는 옳지 않다고 판단한다.

## 올바른 명제

NULL은 = 연산자로 비교할 수 없으며 IS NULL을 사용해야 한다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q32-O2]]: != NULL도 같은 이유로 틀린 오답이다.
- [[M01-Q32-O3]]: IS NULL이 올바른 비교 방식이며 공식 정답이다.
- [[M01-Q32-O4]]: ==NULL은 SQL 문법 자체가 아닌 오답이다.
- 이 선지는 O2와 함께 일반 비교 연산자를 NULL에 잘못 적용한 오답이다.
