# M01-Q49-O4 — SUM이 NULL 때문에 무효화된다고 오판한 오답

## 문제 맥락

[[M01-Q49]]는 TBL(VAL: 10,20,30,NULL)에서 SELECT SUM(VAL)/COUNT(*) FROM TBL;의 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#7. GROUP BY]] → SUM(열): NULL 제외(NULL이 있어도 나머지 값은 정상 합산됨)

## 이 선지가 시험하는 개념 관계

- [[집계 함수]] SUM은 [[NULL]]이 하나 있다고 해서 전체 결과가 NULL이 되는 것이 아니라, NULL을 제외한 나머지 값을 정상적으로 합산한다.

## Option Text

NULL

## Contextual Proposition

SELECT SUM(VAL)/COUNT(*) FROM TBL;의 실행 결과는 NULL이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. VAL에 NULL이 하나 포함되어 있음을 확인한다.
2. SUM이 NULL을 무시하고 나머지 값(10,20,30)을 합산한다는 규칙을 원본에서 확인한다.
3. COUNT(*)도 NULL과 무관하게 정상적으로 4를 반환함을 확인한다.
4. 따라서 SUM(VAL)/COUNT(*)는 15로 계산되며 NULL이 아니라고 판단한다.

## 올바른 명제

SUM(VAL)은 NULL을 제외하고 정상 계산되어 결과가 NULL이 되지 않으며, 최종 결과는 15다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q49-O1]]: 20도 정확한 계산 근거가 불분명한 오답이다.
- [[M01-Q49-O2]]: 15가 SUM과 COUNT(*)를 정확히 결합한 공식 정답이다.
- [[M01-Q49-O3]]: 10은 COUNT(*)와 COUNT(열)을 혼동한 오답으로 보인다.
- 이 선지는 NULL의 존재가 집계 전체를 무효화한다고 오해한 오답이다.
