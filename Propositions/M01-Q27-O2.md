# M01-Q27-O2 — LEFT OUTER JOIN의 정확한 특징

## 문제 맥락

[[M01-Q27]]은 LEFT OUTER JOIN의 특징으로 옳은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#5. FROM 절]] → JOIN(OUTER JOIN: 불일치 행 포함, 매칭되지 않는 반대편 열은 NULL, LEFT OUTER JOIN: 왼쪽 테이블 전체 유지)

## 이 선지가 시험하는 개념 관계

- [[OUTER JOIN]] 중 LEFT OUTER JOIN은 왼쪽 테이블을 기준으로 조인하며, 조건에 불일치하는 오른쪽 테이블의 열은 [[NULL]]로 채워진다.

## Option Text

왼쪽테이블 기준으로 조인, 조건 불일치시 오른쪽테이블에 NULL채워출력

## Contextual Proposition

LEFT OUTER JOIN은 왼쪽 테이블 기준으로 조인하며, 조건 불일치 시 오른쪽 테이블 값을 NULL로 채워 출력한다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ②)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. LEFT OUTER JOIN의 정의(왼쪽 테이블 전체 유지)를 원본에서 확인한다.
2. 불일치 시 반대편(오른쪽) 열이 NULL로 채워진다는 규칙도 확인한다.
3. 이 선지가 두 규칙을 모두 정확히 서술함을 비교한다.
4. 따라서 이 선지가 정답이라고 판단한다.

## 올바른 명제

LEFT OUTER JOIN은 왼쪽 테이블 전체를 유지하고, 불일치하는 오른쪽 테이블 값은 NULL로 채운다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q27-O1]]: 양쪽 일치만 조회는 INNER JOIN의 특징을 잘못 적용한 오답이다.
- [[M01-Q27-O3]]: 오른쪽 테이블 기준은 RIGHT OUTER JOIN의 특징이라 오답이다.
- [[M01-Q27-O4]]: NULL 포함 행 제외는 OUTER JOIN의 취지와 반대되는 오답이다.
- 이 선지만 LEFT OUTER JOIN 고유의 기준 테이블과 NULL 채움 규칙을 정확히 서술한다.
