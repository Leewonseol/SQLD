# M01-Q09-O3 — Barker 표기법의 식별자 # 기호

## 문제 맥락

[[M01-Q09]]는 IE·Barker 표기법에 대한 설명으로 올바르지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 IE·Barker 표기법 자체에 대한 서술이 없음(식별자 표기 기호 공백)

## 이 선지가 시험하는 개념 관계

- Barker 표기법은 [[식별자]]를 #기호 표시한다는 것이 이 선지의 내용이며, 이는 원본에는 없지만 PDF 해설에서 부정되지 않은(즉 참으로 처리된) 서술이다.

## Option Text

Barker 표기방식은 식별자를 # 기호를 붙여 표현한다.

## Contextual Proposition

Barker 표기방식은 식별자를 #기호 표현한다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. Barker 표기법의 식별자 표현 방식을 확인한다(원본에 규칙 없음, PDF 해설도 이 선지를 직접 다루지 않음).
2. PDF 해설이 오직 O1(NOT NULL 확인 가능 여부)만 틀렸다고 지목함을 확인한다.
3. 이 선지가 해설에서 오답으로 지목되지 않았으므로 옳은 서술로 처리한다.
4. 따라서 이 선지는 "옳지 않은 것"에 해당하지 않는다고 판단한다.

## 올바른 명제

Barker 표기법은 식별자를 #기호 표현한다(이 선지 자체가 이미 올바른 명제로 처리됨).

## 같은 문제의 다른 선지와 비교

- [[M01-Q09-O1]]: NOT NULL 확인 가능 여부를 다루며 유일하게 틀린 공식 정답이다.
- [[M01-Q09-O2]]: 카디널리티 공통 표현도 옳은 설명으로 같은 범주다.
- [[M01-Q09-O4]]: IE의 엔터티 내부 선 구분도 옳은 설명으로 같은 범주다.
- 이 선지는 O2·O4와 함께 두 표기법의 실제 표기 규칙을 서술한다.
