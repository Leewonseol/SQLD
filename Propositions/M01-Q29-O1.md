# M01-Q29-O1 — COUNT(*)는 NULL도 포함

## 문제 맥락

[[M01-Q29]]는 집계 함수의 특성으로 옳지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#7. GROUP BY]] → COUNT(*): 모든 행 계산, NULL 포함

## 이 선지가 시험하는 개념 관계

- [[COUNT]](*)는 [[NULL]] 여부와 무관하게 모든 행을 계산하는 것이 원본에 명시된 규칙이다.

## Option Text

NULL값은 COUNT(*)에 포함된다.

## Contextual Proposition

NULL 값은 COUNT(*)에 포함된다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. COUNT(*)의 규칙(모든 행 계산, NULL 포함)을 원본에서 확인한다.
2. 이 선지가 그 규칙과 정확히 일치함을 확인한다.
3. 틀린 내용이 없음을 확인한다.
4. 따라서 "옳지 않은 것"에 해당하지 않는다고 판단한다.

## 올바른 명제

COUNT(*)는 NULL을 포함해 모든 행을 계산한다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q29-O2]]: COUNT(컬럼)이 NULL을 제외한다는 설명도 옳아 오답(정답 아님)이다.
- [[M01-Q29-O3]]: SUM이 NULL을 무시한다는 설명도 옳아 오답이다.
- [[M01-Q29-O4]]: AVG가 NULL을 포함해 전체 행수로 나눈다는 주장은 틀려 공식 정답이다.
- 이 선지는 O2·O3과 함께 집계 함수의 정상적인 NULL 처리 규칙을 서술한다.
