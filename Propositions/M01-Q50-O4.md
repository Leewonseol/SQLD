# M01-Q50-O4 — LIKE는 정규표현식이 아니며 자릿수 검증 불가

## 문제 맥락

[[M01-Q50]]은 010-0000-0000 형식의 휴대폰 번호만 조회하는 올바른 쿼리를 고르는 문제다.

## 기존 마인드맵 연결

- SQL 기본.md — 6. WHERE 절(LIKE: %는 0개 이상의 문자, 자릿수 제한 없음)

## 이 선지가 시험하는 개념 관계

- LIKE의 %는 0개 이상의 모든 문자를 의미해 자릿수를 전혀 제한하지 않으므로, 정규표현식 기반 자릿수 검증이 필요한 이 문제의 목적과 맞지 않는다.

## Option Text

SELECT * FROM USERS WHERE PHONE LIKE '010-%-%';

## Contextual Proposition

이 쿼리는 010-0000-0000 형식의 번호만 정확히 조회한다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. LIKE의 % 와일드카드가 0개 이상의 임의 문자와 매칭됨을 원본에서 확인한다.
2. %가 자릿수를 전혀 제한하지 않음을 확인한다.
3. 010-1-2 같은 형식이 다른 번호도 이 패턴에 매칭될 수 있음을 비교한다.
4. 따라서 "정확히 4자리 형식만" 조회하려는 목적에 맞지 않는다고 판단한다.

## 올바른 명제

LIKE는 자릿수를 검증할 수 없으며, 정확한 자릿수 검증에는 REGEXP_LIKE와 {4} 같은 정규표현식 수량자가 필요하다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q50-O1]]: ^010-[0-9]{4}-[0-9]{4}$가 자릿수를 정확히 고정한 공식 정답이다.
- [[M01-Q50-O2]]: \d{3}는 자릿수 지정은 했으나 값이 틀린 오답이다.
- [[M01-Q50-O3]]: [0-9]+도 자릿수 제한이 느슨한 오답이다.
- 이 선지는 네 선지 중 자릿수 검증력이 가장 약한 오답이다.
