# M01-Q11-O4 — 일부 값 누락으로 인한 오답(200)

## 문제 맥락

[[M01-Q11]]은 GROUP BY 없이 SUM(AMOUNT)을 실행했을 때의 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#7. GROUP BY]] → ② 집계 함수(SUM(열): NULL 제외)

## 이 선지가 시험하는 개념 관계

- [[집계 함수]] SUM은 NULL이 아닌 모든 값(100과 200 둘 다)을 합산해야 하며, 그중 하나만 남기는 것은 계산 누락이다.

## Option Text

200

## Contextual Proposition

SELECT SUM(AMOUNT) FROM TB_SALE;의 실행 결과는 200이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. AMOUNT의 NULL이 아닌 값들(100, 200)을 모두 확인한다.
2. 200만 남기는 것이 A(100)의 값을 누락한 계산임을 확인한다.
3. 올바른 합산은 100과 200을 모두 더한 300임을 비교한다.
4. 따라서 200은 계산 오류이며 정답이 아니라고 판단한다.

## 올바른 명제

SUM(AMOUNT)은 NULL이 아닌 모든 값(100, 200)을 합산해 300을 반환한다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q11-O1]]: 300이 NULL 제외 합산 규칙을 올바르게 적용한 공식 정답이다.
- [[M01-Q11-O2]]: 0은 SUM이 무효화된다고 잘못 가정한 오답이다.
- [[M01-Q11-O3]]: NULL은 SUM이 NULL을 전파한다고 잘못 가정한 오답이다.
- 이 선지는 O2·O3과 달리 NULL 처리 자체는 맞지만 값 하나를 빠뜨린 계산 오류다.
