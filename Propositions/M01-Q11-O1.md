# M01-Q11-O1 — SUM의 NULL 제외 합산(300)

## 문제 맥락

[[M01-Q11]]은 GROUP BY 없이 SUM(AMOUNT)을 실행했을 때의 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#7. GROUP BY]] → ② 집계 함수(SUM(열): 합계, NULL 제외), GROUP BY 없는 집계는 테이블 전체를 하나의 그룹으로 봄

## 이 선지가 시험하는 개념 관계

- [[집계 함수]] SUM은 [[NULL]]을 무시하고 나머지 값만 합산하므로, 100(A)+NULL(B, 무시)+200(C)=300이 된다.

## Option Text

300

## Contextual Proposition

SELECT SUM(AMOUNT) FROM TB_SALE;의 실행 결과는 300이다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ①)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. GROUP BY가 없으므로 테이블 전체가 하나의 그룹으로 처리됨을 확인한다.
2. AMOUNT 값(100, NULL, 200)을 확인한다.
3. SUM은 NULL을 무시하고 합산하는 규칙을 적용한다(100+200=300).
4. 따라서 결과는 300이라고 판단한다.

## 올바른 명제

SUM(AMOUNT)은 NULL을 제외하고 100+200을 합산해 300을 반환한다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q11-O2]]: 0은 SUM이 NULL을 만나면 전체가 0이 된다고 잘못 가정한 오답이다.
- [[M01-Q11-O3]]: NULL은 SUM이 NULL을 무시하지 않는다고 잘못 가정한 오답이다.
- [[M01-Q11-O4]]: 200은 A의 값(100)을 누락한 계산 오류 오답이다.
- 이 선지만 NULL 제외 합산 규칙을 정확히 적용한 결과다.
