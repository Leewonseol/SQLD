# M01-Q15-O4 — 숫자 크기 기준으로 오인한 정렬(D,C,B,A)

## 문제 맥락

[[M01-Q15]]는 문자형 COL2를 기준으로 ORDER BY DESC 정렬했을 때 COL1의 출력 순서를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#8. ORDER BY]] → 정렬 방향(DESC), [[자료형]] → 문자열 사전식 비교 규칙은 명시되어 있지 않음

## 이 선지가 시험하는 개념 관계

- 이 선지의 순서(D,C,B,A)는 COL2를 숫자값(100,99,900,1000)으로 보고 크기 순 내림차순 정렬한 결과이며, [[자료형]]이 문자열이라는 점을 반영하지 않았다.

## Option Text

D,C,B,A

## Contextual Proposition

COL2 기준 내림차순 정렬 시 COL1의 출력 순서는 D,C,B,A다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. 각 COL1의 COL2 값(A=100, B=99, C=900, D=1000)을 확인한다.
2. 이 선지의 순서가 숫자값 크기 기준 내림차순(1000>900>100>99, 즉 D,C,A,B가 아닌 D,C,B,A)과 일치하는지 대조한다.
3. COL2가 실제로는 문자형이므로 사전식 비교가 적용되어야 함을 확인한다.
4. 따라서 이 선지는 자료형을 숫자로 오인한 오답이라고 판단한다.

## 올바른 명제

COL2는 문자형이므로 숫자 크기가 아니라 사전식 비교로 정렬해야 하며, 올바른 순서는 D,C,A,B다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q15-O1]]: B,C,D,A도 사전식 비교 규칙과 맞지 않는 오답이다.
- [[M01-Q15-O2]]: D,C,A,B가 사전식 비교를 정확히 적용한 공식 정답이다.
- [[M01-Q15-O3]]: B,A,C,D는 방향(오름차순)까지 혼동한 오답이다.
- 이 선지는 정렬 방향(DESC)은 맞지만 자료형(문자열 vs 숫자) 판단에서 O2와 갈린다.
