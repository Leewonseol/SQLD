# M01-Q48-O3 — Oracle MODIFY의 다중 컬럼 동시 변경

## 문제 맥락

[[M01-Q48]]은 테이블 컬럼 변경 문법으로 올바르지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 관리 구문#ALTER]] → 자료형·속성 변경: Oracle(MODIFY) — 여러 컬럼 동시 변경 가능 여부는 원본에 명시 없음

## 이 선지가 시험하는 개념 관계

- Oracle [[ALTER]] MODIFY는 괄호 안에 여러 컬럼을 나열해 한 번에 변경할 수 있다는 특징이 있다(선지 근거, 원본에는 명시되어 있지 않음).

## Option Text

ALTER TABLE EMP MODIFY(COL1 VARCHAR2(20),COL2 VARCHAR2(20));

## Contextual Proposition

이 문법은 컬럼을 변경하는 올바르지 않은 문법이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. VARCHAR2 자료형 표기로 Oracle 문법임을 식별한다.
2. MODIFY(...) 괄호 안에 여러 컬럼(COL1, COL2)이 나열되어 있음을 확인한다.
3. PDF 해설에 따르면 Oracle MODIFY는 여러 컬럼을 한 번에 변경할 수 있음을 적용한다(원본에는 이 세부 규칙이 없음).
4. 따라서 이 문법은 올바르며 "올바르지 않은 것"에 해당하지 않는다고 판단한다.

## 올바른 명제

Oracle MODIFY는 괄호 안에 여러 컬럼을 나열해 한 번에 변경할 수 있다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q48-O1]]: Oracle MODIFY 단일 컬럼 변경도 올바른 문법이라 오답(정답 아님)이다.
- [[M01-Q48-O2]]: SQL Server ALTER COLUMN 단일 컬럼 변경도 올바르다.
- [[M01-Q48-O4]]: SQL Server ALTER COLUMN으로 여러 컬럼을 묶는 문법은 존재하지 않아 공식 정답이다.
- 이 선지는 O4와 정확히 대조되는 "다중 컬럼 변경이 실제로 가능한 DBMS(Oracle)" 사례다.
