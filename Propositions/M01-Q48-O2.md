# M01-Q48-O2 — SQL Server ALTER COLUMN 단일 컬럼 변경 문법

## 문제 맥락

[[M01-Q48]]은 테이블 컬럼 변경 문법으로 올바르지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 관리 구문#ALTER]] → 자료형·속성 변경: SQL Server(ALTER COLUMN)

## 이 선지가 시험하는 개념 관계

- [[ALTER]] TABLE ... ALTER COLUMN은 SQL Server에서 컬럼의 자료형(VARCHAR)을 변경하는 정상 문법이다.

## Option Text

ALTER TABLE EMP ALTER COLUMN COL1 VARCHAR(20);

## Contextual Proposition

이 문법은 컬럼을 변경하는 올바르지 않은 문법이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. VARCHAR(괄호 안 20, VARCHAR2 아님) 표기로 SQL Server 문법임을 식별한다.
2. SQL Server에서 컬럼 변경은 ALTER COLUMN을 사용한다는 것을 원본에서 확인한다.
3. 문법 구조(ALTER TABLE ... ALTER COLUMN 컬럼 자료형)가 정상임을 확인한다.
4. 따라서 이 문법은 올바르며 "올바르지 않은 것"에 해당하지 않는다고 판단한다.

## 올바른 명제

ALTER TABLE EMP ALTER COLUMN COL1 VARCHAR(20)는 SQL Server의 올바른 컬럼 변경 문법이다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q48-O1]]: Oracle MODIFY 단일 컬럼 변경도 올바른 문법이라 오답(정답 아님)이다.
- [[M01-Q48-O3]]: Oracle MODIFY로 여러 컬럼을 묶는 문법도 올바르다.
- [[M01-Q48-O4]]: SQL Server ALTER COLUMN으로 여러 컬럼을 묶는 문법은 존재하지 않아 공식 정답이다.
- 이 선지는 O1·O3과 함께 DBMS별로 실제 지원되는 문법을 서술한다.
