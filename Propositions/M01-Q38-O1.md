# M01-Q38-O1 — NVL 대체값을 반영하지 않은 오답(30)

## 문제 맥락

[[M01-Q38]]은 TEST(COL1: 10,NULL,20)에서 SELECT SUM(NVL(COL1,900)) FROM TEST;의 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#4. 공통 표현 도구]] → NULL 함수(NVL(값1, 값2): 값1이 NULL이면 값2 반환), [[SQL 기본#7. GROUP BY]] → SUM(열)

## 이 선지가 시험하는 개념 관계

- [[NULL]] 함수 NVL(COL1,900)이 NULL을 900으로 먼저 대체한 뒤 [[집계 함수]] SUM이 합산해야 하는데, 이 선지(30)는 NVL 대체 없이 원래 값(10, 20)만 합산한 결과다.

## Option Text

30

## Contextual Proposition

SELECT SUM(NVL(COL1,900)) FROM TEST;의 실행 결과는 30이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. NVL(COL1,900)이 각 행에 적용된 결과(10,900,20)를 계산한다.
2. 이 선지의 값(30)이 NVL 적용 전 원래 값(10+20=30)과 같음을 확인한다.
3. NVL 대체(NULL→900)를 반영하지 않았음을 비교한다.
4. 따라서 이 선지는 오답이라고 판단한다.

## 올바른 명제

NVL(COL1,900) 적용 후 SUM은 10+900+20=930이다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q38-O2]]: NULL은 SUM이 NULL을 무시하지 않는다고 잘못 가정한 오답이다.
- [[M01-Q38-O3]]: 930이 NVL과 SUM을 올바르게 결합한 공식 정답이다.
- [[M01-Q38-O4]]: 900은 대체값만 반영하고 나머지 값을 누락한 오답이다.
- 이 선지는 NVL 함수 적용 자체를 빠뜨린 오답이다.
