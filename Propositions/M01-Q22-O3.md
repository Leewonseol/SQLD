# M01-Q22-O3 — IS NOT NULL 조건의 결과(300)

## 문제 맥락

[[M01-Q22]]는 TBL(1/100,2/200,3/NULL,4/NULL)에 대한 네 쿼리 중 결과가 다른 하나를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#6. WHERE 절]] → NULL 조건(IS NOT NULL)

## 이 선지가 시험하는 개념 관계

- WHERE COL2 IS NOT NULL은 [[NULL]]이 아닌 행(100,200)만 남겨, [[집계 함수]] SUM 결과가 O1·O2와 동일하게 300이 된다.

## Option Text

SELECT SUM(COL2) FROM TBL WHERE COL2 IS NOT NULL

## Contextual Proposition

이 쿼리의 결과는 나머지 세 쿼리와 다르다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. IS NOT NULL 조건이 NULL이 아닌 행(100,200)만 남김을 확인한다.
2. SUM(100,200)=300임을 계산한다.
3. O1·O2와 결과가 같음을 비교한다.
4. 따라서 이 쿼리는 "결과가 다른 것"에 해당하지 않는다고 판단한다.

## 올바른 명제

이 쿼리는 300을 반환하며 O1·O2와 결과가 같다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q22-O1]]: 조건 없는 SUM도 300을 반환해 이 선지와 같은 결과다.
- [[M01-Q22-O2]]: BETWEEN 조건도 300을 반환해 이 선지와 같은 결과다.
- [[M01-Q22-O4]]: NOT IN(NULL)은 NULL을 반환해 유일하게 다른 결과이며 공식 정답이다.
- 이 선지는 O1·O2와 함께 정상적으로 300을 반환하는 그룹에 속한다.
