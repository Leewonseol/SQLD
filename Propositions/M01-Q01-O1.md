# M01-Q01-O1 — PK의 NULL 저장과 개체 무결성

## 문제 맥락

[[M01-Q01]]은 개체 무결성을 위반하는 경우를 고르는 문제이며, 핵심 판별 기준은 PK의 유일성·NOT NULL 규칙 위반 여부다.

## 기존 마인드맵 연결

- [[데이터 모델링#식별자]] → 주식별자 특징(존재성: NULL 불가)
- [[SQL 관리 구문#CREATE]] → 제약조건(PRIMARY KEY: 중복 X, NULL X)

## 이 선지가 시험하는 개념 관계

- [[PK]]는 [[NULL]]을 허용하지 않으며, 이는 [[개체 무결성]]의 핵심 규칙이다.
- 기본키 컬럼에 NULL을 저장하는 행위는 이 규칙을 직접 위반하는 사례다.

## Option Text

기본키 컬럼에 NULL을 저장한 경우

## Contextual Proposition

기본키 컬럼에 NULL을 저장하는 것은 개체 무결성을 위반한다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ①)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. 문제에서 묻는 개체 무결성이 PK의 유일성·NULL 금지 규칙임을 식별한다.
2. 선지가 설명하는 상황(PK 컬럼에 NULL 저장)이 이 규칙 중 무엇을 건드리는지 식별한다.
3. NULL 저장이 "존재성(NOT NULL)" 규칙을 직접 어긴다는 것을 확인한다.
4. 따라서 이 선지는 개체 무결성 위반 사례이며 공식 정답과 일치한다고 판단한다.

## 올바른 명제

기본키 컬럼에 NULL을 저장하는 것은 개체 무결성(PK의 존재성 규칙)을 위반한다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q01-O2]]: FK가 부모 값을 참조하는 정상 동작을 다루며, PK 규칙과 무관해 위반이 아니다.
- [[M01-Q01-O3]]: CHECK 제약조건을 다루며, PK 유일성과 무관해 위반이 아니다.
- [[M01-Q01-O4]]: UNIQUE 제약조건을 다루며, NULL을 허용한다는 점에서 PK와 구분되어 위반이 아니다.
- 네 선지 중 오직 이 선지만 PK 자체의 NULL 금지 규칙을 직접 어긴다.
