# M01-Q16-O3 — REGEXP_INSTR의 위치 반환

## 문제 맥락

[[M01-Q16]]은 Oracle 정규표현식 함수 사용에 대한 설명으로 옳지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 정규표현식 함수 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- [[정규표현식 함수]] 중 REGEXP_INSTR는 패턴이 일치하는 문자열의 위치를 반환하는 함수다.

## Option Text

REGEXP_INSTR은 패턴이 일치하는 문자열 위치를 반환한다.

## Contextual Proposition

REGEXP_INSTR은 패턴이 일치하는 문자열의 위치를 반환한다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. REGEXP_INSTR의 용도를 확인한다(원본에 없어 PDF 해설/일반 지식에 의존).
2. 패턴이 일치하는 위치를 반환하는 기능이 맞음을 확인한다.
3. 다른 오답(O4)과 달리 이 선지에 오류가 없음을 비교한다.
4. 따라서 이 선지는 "옳지 않은 것"에 해당하지 않는다고 판단한다.

## 올바른 명제

REGEXP_INSTR은 패턴이 일치하는 문자열의 위치를 반환하는 함수다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q16-O1]]: REGEXP_LIKE의 WHERE절 사용 설명도 옳아 오답(정답 아님)이다.
- [[M01-Q16-O2]]: REGEXP_REPLACE의 패턴 치환 설명도 옳아 오답이다.
- [[M01-Q16-O4]]: REGEXP_COUNT가 Oracle 미지원이라는 주장은 사실과 달라 공식 정답이다.
- 이 선지는 O1·O2와 함께 정규표현식 함수군의 정상적인 기능을 서술한다.
