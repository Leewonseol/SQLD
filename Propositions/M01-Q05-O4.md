# M01-Q05-O4 — Event Entity(사건 엔터티)는 유형 분류

## 문제 맥락

[[M01-Q05]]는 발생 시점에 따른 엔터티 분류가 아닌 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[데이터 모델링#9. 구성요소]] → 엔터티(유형 분류: 유형/개념/사건 vs 발생 시점 분류: 기본/중심/행위)

## 이 선지가 시험하는 개념 관계

- [[엔터티 분류]]는 유형 분류(유형/개념/사건)와 발생 시점 분류(기본/중심/행위)라는 서로 다른 두 기준을 가지며, Event(사건) Entity는 유형 분류에 속하지 발생 시점 분류에는 속하지 않는다.

## Option Text

Event Entity

## Contextual Proposition

Event Entity는 발생 시점에 따른 엔터티 분류가 아니다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ④)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. 원본에서 유형 분류(유형/개념/사건)와 발생 시점 분류(기본/중심/행위)가 서로 다른 목록임을 확인한다.
2. Event(사건) Entity가 어느 목록에 속하는지 대조한다.
3. Event Entity는 유형 분류의 "사건"에 해당하며 발생 시점 분류에는 없음을 확인한다.
4. 따라서 이 선지가 "아닌 것"에 해당해 공식 정답이라고 판단한다.

## 올바른 명제

Event(사건) Entity는 유형 분류에 속하며, 발생 시점 분류(기본/중심/행위)에는 포함되지 않는다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q05-O1]]: Fundamental Entity는 발생 시점 분류에 포함되어 오답이다.
- [[M01-Q05-O2]]: Main Entity도 발생 시점 분류에 포함되어 오답이다.
- [[M01-Q05-O3]]: Active Entity도 발생 시점 분류에 포함되어 오답이다.
- 이 선지만 다른 분류 기준(유형 분류)에 속한 항목을 발생 시점 분류인 것처럼 제시해 혼동을 유도한다.
