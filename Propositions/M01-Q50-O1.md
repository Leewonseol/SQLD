# M01-Q50-O1 — 정확한 4자리-4자리 패턴(^010-[0-9]{4}-[0-9]{4}$)

## 문제 맥락

[[M01-Q50]]은 010-0000-0000 형식의 휴대폰 번호만 조회하는 올바른 쿼리를 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 정규표현식 함수 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- [[정규표현식 함수]] REGEXP_LIKE에서 ^는 문자열 시작, $는 문자열 끝, {4}는 정확히 4자리를 의미하므로, 이 패턴은 010으로 시작해 4자리-4자리 숫자로 끝나는 전체 문자열만 정확히 매칭한다.

## Option Text

SELECT * FROM USERS WHERE REGEXP_LIKE(PHONE,'^010-[0-9]{4}-[0-9]{4}$');

## Contextual Proposition

이 쿼리는 010-0000-0000 형식의 번호만 정확히 조회한다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ①)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. 패턴의 각 요소(^, 010-, [0-9]{4}, -, [0-9]{4}, $)를 확인한다(원본에 없어 정규표현식 일반 지식으로 판단).
2. ^와 $가 문자열 전체를 매칭 범위로 고정함을 확인한다.
3. {4}가 정확히 4자리 숫자만 허용함을 확인한다.
4. 따라서 010-XXXX-XXXX 형식만 정확히 매칭되어 이 선지가 정답이라고 판단한다.

## 올바른 명제

^010-[0-9]{4}-[0-9]{4}$ 패턴은 010-으로 시작해 4자리-4자리 숫자로 끝나는 전체 문자열만 매칭한다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q50-O2]]: \d{3}는 3자리만 허용해 실제 4자리 국번(예: 1234)과 불일치하는 오답이다.
- [[M01-Q50-O3]]: [0-9]+는 자릿수 제한이 없어 형식이 다른 번호도 매칭되는 오답이다.
- [[M01-Q50-O4]]: LIKE '010-%-%'는 자릿수를 전혀 검증하지 않는 오답이다.
- 이 선지만 자릿수와 전체 문자열 범위를 정확히 고정한다.
