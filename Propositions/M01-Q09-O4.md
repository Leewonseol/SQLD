# M01-Q09-O4 — IE 표기법의 엔터티 내부 속성 구분선

## 문제 맥락

[[M01-Q09]]는 IE·Barker 표기법에 대한 설명으로 올바르지 않은 것을 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 IE·Barker 표기법 자체에 대한 서술이 없음(엔터티 내부 속성 구분 표기 공백)

## 이 선지가 시험하는 개념 관계

- IE 표기법은 [[엔터티]] 박스 내부에서 [[식별자]] 속성과 일반(비식별자) 속성을 선으로 구분해 표현한다. "엔터티 내의 선"이라는 표현은 엔터티와 엔터티 사이의 관계선이 아니라 엔터티 내부의 속성 구분선을 가리키는 것으로 해석된다. 다만 인쇄된 해설이 이 선지를 직접 설명하지 않아 완전히 확정된 근거는 아니다.

## Option Text

IE 표기방식은 식별자와 비식별자를 각각 엔터티 내의 선으로 구분하여 표현한다.

## Contextual Proposition

IE 표기방식은 엔터티 내부에서 식별자 속성과 비식별자 속성을 선으로 구분해 표현한다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. 선지 원문의 "엔터티 내의 선"이라는 표현이 무엇을 가리키는지 확인한다.
2. 관계선(엔터티 사이)이 아니라 엔터티 박스 내부의 속성 구분선(식별자 속성 vs 일반 속성)을 가리킨다고 해석한다.
3. PDF 해설이 이 선지를 직접 다루지 않으므로, 해설에서 오답으로 지목되지 않은 점을 근거로 참으로 처리한다.
4. 따라서 이 선지는 "옳지 않은 것"에 해당하지 않는다고 잠정 판단하되, 재확인이 필요함을 표시한다.

## 올바른 명제

IE 표기법은 엔터티 내부에서 식별자 속성과 비식별자 속성을 선으로 구분해 표현한다(재확인 필요).

## 같은 문제의 다른 선지와 비교

- [[M01-Q09-O1]]: NOT NULL 확인 가능 여부를 다루며 유일하게 틀린 공식 정답이다.
- [[M01-Q09-O2]]: 카디널리티 공통 표현도 옳은 설명으로 같은 범주다.
- [[M01-Q09-O3]]: Barker의 #기호 (식별자 표현)도 옳은 설명으로 같은 범주다.
- 이 선지는 [[식별 관계]]·[[비식별 관계]](관계 유형)가 아니라 엔터티 내부의 속성 구분을 다룬다는 점에서 O3(식별자 표기)과 성격이 가깝다.
