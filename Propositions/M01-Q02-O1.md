# M01-Q02-O1 — 물리적 저장 구조와 개념적 모델링의 구분

## 문제 맥락

[[M01-Q02]]는 개념적 데이터 모델링의 특징으로 옳은 것을 고르는 문제이며, 3단계 모델링의 특징을 구분하는 것이 핵심이다.

## 기존 마인드맵 연결

- [[데이터 모델링#6. 데이터 모델링 3단계]] → 물리적 데이터 모델링(저장 방식 결정)

## 이 선지가 시험하는 개념 관계

- 물리적 저장 구조 결정은 [[데이터 모델링 3단계]] 중 물리적 데이터 모델링의 특징이지 개념적 데이터 모델링의 특징이 아니다.

## Option Text

물리적 저장 구조를 포함한다.

## Contextual Proposition

개념적 데이터 모델링은 물리적 저장 구조를 포함한다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. 문제가 묻는 대상이 "개념적" 데이터 모델링임을 식별한다.
2. 선지 내용(물리적 저장 구조)이 어느 단계의 특징인지 식별한다.
3. 저장 구조는 물리적 모델링 단계의 특징이므로 개념적 모델링과 일치하지 않음을 비교한다.
4. 따라서 이 선지는 옳지 않다고 판단한다.

## 올바른 명제

물리적 저장 구조를 포함하는 것은 물리적 데이터 모델링의 특징이다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q02-O2]]: 인덱스 등 성능 요소도 물리적 모델링 특징이라는 점에서 이 선지와 같은 오답 범주다.
- [[M01-Q02-O3]]: 사용자 관점의 전체 구조 표현이 개념적 모델링의 실제 특징이며 공식 정답이다.
- [[M01-Q02-O4]]: 정규화는 논리적 모델링 단계의 특징이라는 점에서 또 다른 오답 범주다.
- 이 선지는 O2와 함께 "물리적 모델링 특징을 개념적 모델링으로 오인시키는" 함정이다.
