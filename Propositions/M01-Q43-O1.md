# M01-Q43-O1 — 다중행 서브쿼리는 = 연산자를 사용할 수 없음

## 문제 맥락

[[M01-Q43]]은 서브쿼리 관련 옳은 문장을 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 서브쿼리 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- 다중행 [[서브쿼리]]는 여러 행을 반환하므로 단일행 비교 연산자(=)가 아니라 IN, ANY, ALL 같은 다중행 연산자와 함께 사용해야 한다.

## Option Text

다중행 서브쿼리는 =연산자로 사용한다.

## Contextual Proposition

다중행 서브쿼리는 = 연산자와 함께 사용한다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. 다중행 서브쿼리가 여러 행을 반환할 수 있음을 확인한다.
2. = 연산자는 단일 값과만 비교 가능한 단일행 연산자임을 확인한다(원본에 없어 일반 SQL 지식으로 판단).
3. 다중행 결과에 = 연산자를 사용하면 오류가 발생함을 비교한다.
4. 따라서 이 선지는 틀렸다고 판단한다.

## 올바른 명제

다중행 서브쿼리는 IN, ANY, ALL 같은 다중행 연산자와 함께 사용해야 한다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q43-O2]]: 서브쿼리가 SELECT절에서만 사용 가능하다는 주장도 틀린 오답이다.
- [[M01-Q43-O3]]: EXISTS가 존재 여부만 판단한다는 설명이 옳아 공식 정답이다.
- [[M01-Q43-O4]]: 결과가 여러 행이면 오류가 안 난다는 주장도 틀린 오답이다.
- 이 선지는 단일행/다중행 서브쿼리의 연산자 규칙을 혼동시키는 함정이다.
