# M01-Q02-O3 — 사용자 관점과 개념적 모델링

## 문제 맥락

[[M01-Q02]]는 개념적 데이터 모델링의 특징으로 옳은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[데이터 모델링#6. 데이터 모델링 3단계]] → 개념적 데이터 모델링(가장 높은 추상화 수준, 업무 중심)

## 이 선지가 시험하는 개념 관계

- 개념적 데이터 모델링은 [[데이터 모델링 3단계]] 중 가장 높은 추상화 수준에서 사용자(업무) 관점의 전체 구조를 표현하는 단계다.

## Option Text

사용자 관점에서 전체적인 데이터 구조를 표현한다.

## Contextual Proposition

개념적 데이터 모델링은 사용자 관점에서 전체적인 데이터 구조를 표현한다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ③)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. 문제가 묻는 대상이 "개념적" 데이터 모델링임을 식별한다.
2. 선지 내용(사용자 관점, 전체 구조 표현)이 원본의 "업무 중심, 가장 높은 추상화 수준" 서술과 일치하는지 확인한다.
3. 물리적·논리적 모델링의 특징(저장구조, 인덱스, 정규화)과 겹치지 않음을 비교한다.
4. 따라서 이 선지가 개념적 모델링의 특징으로 옳다고 판단한다.

## 올바른 명제

개념적 데이터 모델링은 사용자 관점에서 전체적인 데이터 구조를 표현한다(원본 표현과 일치).

## 같은 문제의 다른 선지와 비교

- [[M01-Q02-O1]]: 물리적 저장 구조 포함은 물리적 모델링 특징으로 오답이다.
- [[M01-Q02-O2]]: 인덱스 등 성능 요소도 물리적 모델링 특징으로 오답이다.
- [[M01-Q02-O4]]: 정규화는 논리적 모델링 특징으로 오답이다.
- 이 선지만 개념적 모델링 고유의 특징을 정확히 서술한다.
