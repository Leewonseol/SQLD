# M01-Q40-O3 — DELETE를 반영하지 않은 오답(2행)

## 문제 맥락

[[M01-Q40]]은 INSERT A → INSERT B → DELETE(A) → CREATE TABLE DEPT → INSERT C → ROLLBACK 순서 실행 후 EMP의 행 수를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 관리 구문#DELETE]] → 특정 행 삭제, [[SQL 관리 구문#AUTO COMMIT]] → DDL 자동 커밋

## 이 선지가 시험하는 개념 관계

- 이 선지(2행)는 [[DELETE]](A)가 실행되지 않았다고 가정한 것으로 보이며, 실제로는 DELETE(A) 이후 B만 남고 그 상태가 [[DDL]]의 [[AUTO COMMIT]]으로 확정된다.

## Option Text

2

## Contextual Proposition

일련의 SQL 실행 후 EMP 테이블의 행 수는 2다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. INSERT A, INSERT B로 (A,B) 상태가 됨을 확인한다.
2. DELETE(A) 실행으로 A가 삭제되어 (B)만 남음을 확인한다.
3. 이 선지(2행)가 DELETE(A) 실행을 반영하지 않았음을 비교한다.
4. 따라서 이 선지는 오답이라고 판단한다.

## 올바른 명제

DELETE(A) 이후 (B)만 남고, DDL 자동 커밋으로 이 상태가 확정되어 최종 행 수는 1이다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q40-O1]]: 0은 ROLLBACK이 전체를 되돌린다고 오판한 오답이다.
- [[M01-Q40-O2]]: 1(B만 남음)이 DDL 자동 커밋과 ROLLBACK 범위를 정확히 추적한 공식 정답이다.
- [[M01-Q40-O4]]: 3은 ROLLBACK이 전혀 적용되지 않았다고 오판한 오답이다.
- 이 선지는 DELETE 단계 자체를 누락한 오답이다.
