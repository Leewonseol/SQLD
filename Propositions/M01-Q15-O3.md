# M01-Q15-O3 — 잘못된 정렬 순서(B,A,C,D)

## 문제 맥락

[[M01-Q15]]는 문자형 COL2를 기준으로 ORDER BY DESC 정렬했을 때 COL1의 출력 순서를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#8. ORDER BY]] → 정렬 방향(DESC), [[자료형]] → 문자열 사전식 비교 규칙은 명시되어 있지 않음

## 이 선지가 시험하는 개념 관계

- 이 선지의 순서(B,A,C,D)는 [[자료형]]을 숫자로 오인하고 오름차순으로 정렬한 것에 가까워 [[ORDER BY]] DESC의 방향과도 맞지 않는다.

## Option Text

B,A,C,D

## Contextual Proposition

COL2 기준 내림차순 정렬 시 COL1의 출력 순서는 B,A,C,D다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. 각 COL1의 COL2 값(A=100, B=99, C=900, D=1000)을 확인한다.
2. 이 선지의 순서가 숫자 크기 기준 오름차순(99<100<900<1000)에 더 가까움을 확인한다.
3. 문제는 DESC(내림차순)이며 문자열 사전식 비교가 적용되어야 함을 비교한다.
4. 따라서 이 선지는 정렬 기준과 방향을 모두 잘못 적용한 오답이라고 판단한다.

## 올바른 명제

COL2 기준 내림차순 사전식 정렬 결과 COL1의 순서는 D,C,A,B다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q15-O1]]: B,C,D,A도 사전식 비교 규칙과 맞지 않는 오답이다.
- [[M01-Q15-O2]]: D,C,A,B가 사전식 비교를 정확히 적용한 공식 정답이다.
- [[M01-Q15-O4]]: D,C,B,A는 숫자 크기 기준 내림차순으로 계산한 오답이다.
- 이 선지는 O4와 달리 오름차순에 가까운 순서를 제시해 방향 자체를 혼동한 것으로 보인다.
