# M01-Q19-O1 — COUNT(T2.COL1) 결과를 0으로 오인

## 문제 맥락

[[M01-Q19]]는 T1 LEFT OUTER JOIN T2 결과에서 COUNT(T2.COL1)의 값을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#5. FROM 절]] → OUTER JOIN(LEFT OUTER JOIN: 왼쪽 테이블 전체 유지), [[SQL 기본#7. GROUP BY]] → COUNT(열): NULL 제외

## 이 선지가 시험하는 개념 관계

- [[OUTER JOIN]] 결과에서 매칭되지 않는 열은 [[NULL]]로 채워지고, [[COUNT]](열)은 NULL을 제외하고 세므로 결과가 0이 될 수 없다.

## Option Text

0

## Contextual Proposition

SELECT COUNT(T2.COL1) FROM T1 LEFT OUTER JOIN T2 ON(...);의 실행 결과는 0이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. T1(1,2,3)과 T2(2,3,4)를 LEFT OUTER JOIN하면 (1,NULL),(2,2),(3,3)이 됨을 확인한다.
2. COUNT(T2.COL1)이 NULL을 제외하고 셈을 적용한다.
3. NULL이 아닌 값(2,3) 2개가 있음을 확인한다.
4. 따라서 결과는 0이 아니라고 판단한다.

## 올바른 명제

COUNT(T2.COL1)은 NULL이 아닌 값(2,3)만 세어 2를 반환한다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q19-O2]]: 1은 매칭된 행 중 하나만 계산한 오답이다.
- [[M01-Q19-O3]]: 2가 NULL 제외 COUNT를 올바르게 적용한 공식 정답이다.
- [[M01-Q19-O4]]: 3은 COUNT(*)처럼 NULL도 포함해 계산한 오답이다.
- 이 선지는 조인 결과 자체를 0행으로 오인한 근본적인 오답이다.
