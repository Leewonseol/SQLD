# M01-Q14-O4 — EXCLUDE NULLS는 측정치 NULL 행 제외

## 문제 맥락

[[M01-Q14]]는 UNPIVOT 시 NULL 처리에 대한 설명으로 옳은 것을 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 PIVOT·UNPIVOT 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- [[PIVOT·UNPIVOT]]의 EXCLUDE NULLS 옵션은 측정치(값)가 [[NULL]]인 행을 결과에서 제외하는 기능이다.

## Option Text

EXCLUDE NULLS 사용하면 측정치 NULL인 행 결과에서 제거된다.

## Contextual Proposition

EXCLUDE NULLS를 사용하면 측정치가 NULL인 행이 결과에서 제거된다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ④)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. EXCLUDE NULLS 옵션의 동작 방식을 PDF 해설로 확인한다(원본에는 없음).
2. 해설이 "측정치가 NULL인 경우 해당 행을 결과에서 제외"라고 명시함을 확인한다.
3. 이 선지가 해설과 정확히 일치함을 확인한다.
4. 따라서 이 선지가 정답이라고 판단한다.

## 올바른 명제

EXCLUDE NULLS를 사용하면 측정치가 NULL인 행이 UNPIVOT 결과에서 제외된다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q14-O1]]: EXCLUDE NULLS의 동작을 "치환"으로 잘못 서술한 오답이다.
- [[M01-Q14-O2]]: INCLUDE NULLS가 PIVOT 전용이라는 근거 없는 오답이다.
- [[M01-Q14-O3]]: UNPIVOT의 기본값을 근거 없이 단정한 오답이다.
- 이 선지만 EXCLUDE NULLS의 실제 동작(행 제외)을 정확히 서술한다.
