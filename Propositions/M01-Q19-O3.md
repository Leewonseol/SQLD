# M01-Q19-O3 — COUNT(T2.COL1)의 올바른 결과(2)

## 문제 맥락

[[M01-Q19]]는 T1 LEFT OUTER JOIN T2 결과에서 COUNT(T2.COL1)의 값을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#5. FROM 절]] → OUTER JOIN(LEFT OUTER JOIN: 왼쪽 테이블 전체 유지, 불일치 시 NULL), [[SQL 기본#7. GROUP BY]] → COUNT(열): NULL 제외

## 이 선지가 시험하는 개념 관계

- [[OUTER JOIN]] 결과 (1,NULL),(2,2),(3,3) 중 T2.COL1의 [[NULL]] 아닌 값은 2개이며, [[COUNT]](열)은 이 2개만 센다.

## Option Text

2

## Contextual Proposition

SELECT COUNT(T2.COL1) FROM T1 LEFT OUTER JOIN T2 ON(...);의 실행 결과는 2다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ③)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. T1(1,2,3)과 T2(2,3,4)를 T1 기준 LEFT OUTER JOIN하면 (1,NULL),(2,2),(3,3)이 됨을 계산한다.
2. COUNT(T2.COL1)이 NULL을 제외하고 셈을 적용한다.
3. NULL이 아닌 값(2,3) 2개를 확인한다.
4. 따라서 결과는 2라고 판단한다.

## 올바른 명제

LEFT OUTER JOIN 결과에서 COUNT(T2.COL1)은 NULL을 제외한 2개(2,3)를 세어 2를 반환한다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q19-O1]]: 0은 조인 결과 자체를 잘못 이해한 오답이다.
- [[M01-Q19-O2]]: 1은 값 하나를 누락한 계산 오류 오답이다.
- [[M01-Q19-O4]]: 3은 NULL까지 포함해 계산한 오답(COUNT(*)와 혼동)이다.
- 이 선지만 LEFT OUTER JOIN의 NULL 채움과 COUNT(열)의 NULL 제외 규칙을 정확히 결합했다.
