# M01-Q38-O2 — SUM 결과를 NULL로 오인하는 오답

## 문제 맥락

[[M01-Q38]]은 TEST(COL1: 10,NULL,20)에서 SELECT SUM(NVL(COL1,900)) FROM TEST;의 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#4. 공통 표현 도구]] → NULL 함수(NVL), [[SQL 기본#7. GROUP BY]] → SUM(열): NULL 제외

## 이 선지가 시험하는 개념 관계

- NVL(COL1,900)이 이미 NULL을 900으로 대체했으므로, [[집계 함수]] SUM 대상에는 [[NULL]]이 남아있지 않아 결과가 NULL이 될 수 없다.

## Option Text

NULL

## Contextual Proposition

SELECT SUM(NVL(COL1,900)) FROM TEST;의 실행 결과는 NULL이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. NVL(COL1,900)이 각 행에서 NULL을 900으로 대체함을 확인한다.
2. 대체 후 값(10,900,20)에는 NULL이 없음을 확인한다.
3. SUM 대상에 NULL이 없으므로 결과가 NULL이 될 이유가 없음을 비교한다.
4. 따라서 이 선지는 오답이라고 판단한다.

## 올바른 명제

NVL로 NULL을 900으로 대체한 뒤 SUM하면 결과는 930이며 NULL이 될 수 없다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q38-O1]]: 30은 NVL 대체 자체를 빠뜨린 오답이다.
- [[M01-Q38-O3]]: 930이 NVL과 SUM을 올바르게 결합한 공식 정답이다.
- [[M01-Q38-O4]]: 900은 대체값만 반영하고 나머지 값을 누락한 오답이다.
- 이 선지는 NVL이 이미 NULL을 제거했다는 사실을 간과한 오답이다.
