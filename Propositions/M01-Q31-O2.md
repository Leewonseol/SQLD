# M01-Q31-O2 — 집계 결과 필터링은 HAVING의 역할

## 문제 맥락

[[M01-Q31]]은 WHERE절과 HAVING절 차이로 옳은 것을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#7. GROUP BY]] → ③ HAVING 절(WHERE: 집계 함수 조건 사용 불가, HAVING: 집계 함수 조건 사용 가능)

## 이 선지가 시험하는 개념 관계

- 집계 결과를 필터링하는 것은 [[HAVING]]의 역할이며, [[WHERE]]는 집계 함수 조건을 사용할 수 없다.

## Option Text

WHERE는 집계결과를 필터링한다.

## Contextual Proposition

WHERE절은 집계 결과를 필터링한다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. WHERE와 HAVING 각각이 어떤 대상을 필터링하는지 원본에서 확인한다.
2. WHERE는 "집계 함수 조건 사용 불가"로 명시되어 있음을 확인한다.
3. 집계 결과 필터링은 HAVING의 역할임을 비교한다.
4. 따라서 이 선지는 옳지 않다고 판단한다.

## 올바른 명제

집계 결과를 필터링하는 것은 HAVING의 역할이며, WHERE는 개별 행을 필터링한다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q31-O1]]: 둘 다 GROUP BY 이후라는 주장도 틀린 오답이다.
- [[M01-Q31-O3]]: HAVING이 집계 함수 조건을 사용한다는 설명이 옳아 공식 정답이다.
- [[M01-Q31-O4]]: HAVING이 개별 행 조건을 지정한다는 주장도 틀린 오답이다.
- 이 선지는 WHERE와 HAVING의 역할을 서로 바꿔 서술한 오답이다.
