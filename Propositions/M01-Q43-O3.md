# M01-Q43-O3 — EXISTS는 존재 여부만 판단

## 문제 맥락

[[M01-Q43]]은 서브쿼리 관련 옳은 문장을 고르는 문제다.

## 기존 마인드맵 연결

- 원본에 서브쿼리 자체에 대한 서술이 없음

## 이 선지가 시험하는 개념 관계

- [[서브쿼리]] EXISTS는 서브쿼리 결과가 존재하는지 여부만 판단하므로, 서브쿼리의 SELECT 목록에 무엇을 적는지는 중요하지 않다.

## Option Text

EXISTS는 서브쿼리의 결과값 존재여부를 판단하므로 SELECT는 중요하지 않다.

## Contextual Proposition

EXISTS는 서브쿼리의 결과값 존재 여부를 판단하므로 SELECT 목록은 중요하지 않다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ③)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. EXISTS의 동작 방식(행이 존재하는지만 확인)을 확인한다(원본에 없어 일반 SQL 지식으로 판단).
2. SELECT 목록의 실제 값이 EXISTS의 판단에 영향을 주지 않음을 확인한다(흔히 SELECT 1 등으로 대체 가능).
3. 이 선지가 이 특성을 정확히 서술함을 비교한다.
4. 따라서 이 선지가 정답이라고 판단한다.

## 올바른 명제

EXISTS는 서브쿼리 결과의 존재 여부만 판단하며 SELECT 목록의 내용은 결과에 영향을 주지 않는다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q43-O1]]: 다중행 서브쿼리가 =연산자를 사용한다는 주장은 틀린 오답이다.
- [[M01-Q43-O2]]: 서브쿼리가 SELECT절에서만 가능하다는 주장도 틀린 오답이다.
- [[M01-Q43-O4]]: 결과가 여러 행이면 오류가 안 난다는 주장도 틀린 오답이다.
- 이 선지만 EXISTS의 실제 동작 원리를 정확히 서술한다.
