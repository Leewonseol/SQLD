# M01-Q49-O1 — 분모 계산 오류로 인한 오답(20)

## 문제 맥락

[[M01-Q49]]는 TBL(VAL: 10,20,30,NULL)에서 SELECT SUM(VAL)/COUNT(*) FROM TBL;의 결과를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#7. GROUP BY]] → SUM(열): NULL 제외, COUNT(*): NULL 포함

## 이 선지가 시험하는 개념 관계

- [[집계 함수]] SUM(VAL)은 NULL을 제외해 60이 되고, [[COUNT]](*)는 NULL을 포함해 4가 되어 60/4=15가 되어야 하는데, 이 선지(20)는 이 계산과 다르다.

## Option Text

20

## Contextual Proposition

SELECT SUM(VAL)/COUNT(*) FROM TBL;의 실행 결과는 20이다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. SUM(VAL)이 NULL을 제외해 10+20+30=60임을 계산한다.
2. COUNT(*)가 NULL을 포함해 전체 행수 4임을 계산한다.
3. 60/4=15가 되어야 하는데 이 선지는 20임을 비교한다.
4. 따라서 이 선지는 계산이 틀린 오답이라고 판단한다.

## 올바른 명제

SUM(VAL)/COUNT(*)는 60/4=15이며 20이 아니다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q49-O2]]: 15가 SUM과 COUNT(*)를 정확히 결합한 공식 정답이다.
- [[M01-Q49-O3]]: 10은 COUNT(*) 대신 NULL 제외 행수(3)로 나눈 오답으로 보인다.
- [[M01-Q49-O4]]: NULL은 SUM이 NULL 때문에 계산 자체가 불가능하다고 잘못 가정한 오답이다.
- 이 선지는 정확한 계산 근거가 뚜렷하지 않은 단순 오답이다.
