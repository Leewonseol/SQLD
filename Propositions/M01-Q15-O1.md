# M01-Q15-O1 — 잘못된 정렬 순서(B,C,D,A)

## 문제 맥락

[[M01-Q15]]는 문자형 COL2를 기준으로 ORDER BY DESC 정렬했을 때 COL1의 출력 순서를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#8. ORDER BY]] → 정렬 방향(DESC), [[자료형]] → 문자열 사전식 비교 규칙은 명시되어 있지 않음

## 이 선지가 시험하는 개념 관계

- [[ORDER BY]] DESC 정렬은 문자열([[자료형]]) 기준으로 사전식 비교되어야 하며, 이 선지의 순서(B,C,D,A)는 이 비교 규칙과 맞지 않는다.

## Option Text

B,C,D,A

## Contextual Proposition

COL2 기준 내림차순 정렬 시 COL1의 출력 순서는 B,C,D,A다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. 각 COL1의 COL2 값(A=100, B=99, C=900, D=1000)을 확인한다.
2. COL2가 문자형이므로 숫자 크기가 아니라 문자열 사전식 비교가 적용됨을 확인한다(원본에 이 규칙 없음).
3. 사전식 내림차순 정렬 시 '99' > '900' > '1000' > '100' 순서가 됨을 계산한다(D,C,A,B).
4. 이 선지의 순서(B,C,D,A)가 이와 일치하지 않으므로 오답이라고 판단한다.

## 올바른 명제

COL2 기준 내림차순 사전식 정렬 결과 COL1의 순서는 D,C,A,B다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q15-O2]]: D,C,A,B가 사전식 비교를 정확히 적용한 공식 정답이다.
- [[M01-Q15-O3]]: B,A,C,D는 숫자 크기 기준(오름차순 혼동 등) 다른 오해에서 비롯된 오답이다.
- [[M01-Q15-O4]]: D,C,B,A는 숫자 크기 기준 내림차순으로 계산한 오답으로 보인다.
- 이 선지는 정렬 방향과 기준값 조합을 모두 잘못 적용한 오답이다.
