# M01-Q36-O2 — 순서번호를 이용한 ORDER BY(공통 결과)

## 문제 맥락

[[M01-Q36]]은 네 가지 ORDER BY 작성 방식 중 결과가 다른 하나를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#8. ORDER BY]] → 사용할 수 있는 정렬 기준(SELECT 열 순서 번호 사용 가능)

## 이 선지가 시험하는 개념 관계

- [[ORDER BY]]는 SELECT 목록의 순서 번호(1,2)를 정렬 기준으로 사용할 수 있으며, 1 DESC, 2(ASC 기본값)는 ENAME DESC, SAL ASC와 동일한 정렬이다.

## Option Text

SELECT ENAME AS EMP_NAME,SAL FROM EMP ORDER BY 1 DESC,2

## Contextual Proposition

이 쿼리의 정렬 결과는 나머지 세 쿼리와 다르다.

## Judgment

- 공식 정답 선지 여부: 아니오
- 문맥 명제의 참·거짓: 거짓

## 판별 과정

1. ORDER BY가 SELECT 순서 번호를 사용할 수 있는지 확인한다(원본에 명시됨).
2. 1번 열(ENAME/EMP_NAME) DESC, 2번 열(SAL) ASC(기본값)임을 확인한다.
3. O1·O3과 동일한 정렬 기준임을 비교한다.
4. 따라서 이 쿼리는 "결과가 다른 것"에 해당하지 않는다고 판단한다.

## 올바른 명제

이 쿼리는 ENAME 내림차순, SAL 오름차순으로 정렬되며 O1·O3과 결과가 같다.

## 같은 문제의 다른 선지와 비교

- [[M01-Q36-O1]]: 별칭(EMP_NAME DESC,SAL)을 사용해도 같은 정렬 기준이라 결과가 같다.
- [[M01-Q36-O3]]: 열 이름(ENAME DESC,SAL)을 직접 사용해도 결과가 같다.
- [[M01-Q36-O4]]: 순서번호(1,2 DESC)는 정렬 기준 자체가 달라 유일하게 다른 결과이며 공식 정답이다.
- 이 선지는 O1·O3과 함께 "ENAME DESC, SAL ASC" 그룹에 속한다.
