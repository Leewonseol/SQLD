# M01-Q40-O2 — DDL 자동 커밋과 ROLLBACK 범위를 정확히 추적(1행)

## 문제 맥락

[[M01-Q40]]은 INSERT A → INSERT B → DELETE(A) → CREATE TABLE DEPT → INSERT C → ROLLBACK 순서 실행 후 EMP의 행 수를 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 관리 구문#AUTO COMMIT]] → Oracle: DML 자동 커밋 아님, DDL 실행 시 자동 커밋, [[SQL 관리 구문#ROLLBACK]] → 마지막 COMMIT 시점으로 복구

## 이 선지가 시험하는 개념 관계

- [[DDL]](CREATE TABLE)이 [[AUTO COMMIT]]을 유발해 그 이전 [[Transaction]](B 삽입 상태)을 확정시키고, 이후 새로 시작된 트랜잭션(C 삽입)만 [[ROLLBACK]]으로 취소된다.

## Option Text

1

## Contextual Proposition

일련의 SQL 실행 후 EMP 테이블의 행 수는 1이다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ②)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. INSERT A → (A). INSERT B → (A,B). DELETE(A) → (B)를 순서대로 추적한다.
2. CREATE TABLE DEPT(DDL) 실행 시 Oracle에서 자동 COMMIT이 발생해 현재 상태(B만 존재)가 영구 확정됨을 적용한다(원본에 이 실전 절차는 없어 AUTO COMMIT 규칙으로 추론).
3. INSERT C로 새 트랜잭션이 시작되어 (B,C) 상태가 됨을 확인한다.
4. ROLLBACK은 마지막 COMMIT 시점(B만 존재)까지 되돌리므로 C만 취소되고 최종 상태는 (B) 1행이라고 판단한다.

## 올바른 명제

CREATE TABLE(DDL)의 자동 커밋으로 B가 확정되고, 이후 ROLLBACK은 C만 취소해 최종 EMP는 B 1행만 남는다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q40-O1]]: 0은 ROLLBACK이 전체를 되돌린다고 오판한 오답이다.
- [[M01-Q40-O3]]: 2는 A가 삭제되지 않았다고 오판한 오답이다.
- [[M01-Q40-O4]]: 3은 ROLLBACK이 전혀 적용되지 않았다고 오판한 오답이다.
- 이 선지만 DDL 자동 커밋 시점과 ROLLBACK 적용 범위를 모두 정확히 추적한다.
