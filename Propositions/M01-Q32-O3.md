# M01-Q32-O3 — IS NULL이 올바른 비교 방식

## 문제 맥락

[[M01-Q32]]는 SQL에서 NULL 비교가 옳은 방식을 고르는 문제다.

## 기존 마인드맵 연결

- [[SQL 기본#6. WHERE 절]] → NULL 조건(IS NULL/IS NOT NULL)

## 이 선지가 시험하는 개념 관계

- [[NULL]]은 일반 비교 연산자로 비교할 수 없으며, IS NULL이라는 전용 연산자만 사용할 수 있다.

## Option Text

WHERE COL IS NULL

## Contextual Proposition

WHERE COL IS NULL은 NULL을 비교하는 옳은 방식이다.

## Judgment

- 공식 정답 선지 여부: 예(공식 정답 ③)
- 문맥 명제의 참·거짓: 참

## 판별 과정

1. NULL의 비교 규칙(IS NULL/IS NOT NULL만 사용 가능)을 원본에서 확인한다.
2. COL IS NULL이 이 규칙과 정확히 일치함을 확인한다.
3. 나머지 선지(=, !=, ==)가 모두 일반 비교 연산자임을 대조한다.
4. 따라서 이 선지가 정답이라고 판단한다.

## 올바른 명제

NULL 비교는 IS NULL 또는 IS NOT NULL이라는 전용 연산자로만 가능하다(이 선지 자체가 이미 올바른 명제).

## 같은 문제의 다른 선지와 비교

- [[M01-Q32-O1]]: = NULL은 일반 비교 연산자를 잘못 사용한 오답이다.
- [[M01-Q32-O2]]: != NULL도 같은 이유로 틀린 오답이다.
- [[M01-Q32-O4]]: ==NULL은 SQL 문법 자체가 아닌 오답이다.
- 이 선지만 NULL 전용 비교 연산자를 사용한다.
