## 이 보고서가 정한 규칙

1. **원문을 다 읽었다고 가정하지 않는다.** 103페이지 전수조사는 끝나지 않았다.
2. `coverage_matrix.csv`의 `원본 PDF 페이지` 열은 모든 행이 `미확인`이다. 추출본에 페이지 정보가 없어서, 페이지를 추정해 적지 않았다.
3. `근거구분` 열로 출처를 나눈다.
   * `PDF추출본(E-xx)`: 텍스트 추출본에 실제로 있는 내용. `extract_index.md`의 조각 번호(E-01~E-38)와 연결된다.
   * `요구목록(§6/§7)`: 추출본에서 찾지 못했지만 과제 요구사항 §6·§7에 명시된 항목. **PDF에 있는지 확인되지 않았다.**
   * `외부검증`: PDF 서술을 실제 DBMS 실행 결과나 공식 문서와 대조한 결과. PDF 원문과 섞지 않는다.
4. 추출본에 없는 예제 데이터는 모두 `학습용 가상 데이터`로 표시했다.
