# 01 데이터 모델링 — 단원 안내

학습 흐름의 첫 세 단계 **업무 규칙 → 개념적 ERD → 논리적 ERD**를 다룬다.
이 단원은 SELECT로 하는 실습이 아니다. 각 실습에서 업무 규칙을 읽고 엔터티·속성·관계·차수·선택성을 정한다.
그 결정이 **제약조건으로 어디까지 구현되는지**는 작은 DDL과 INSERT로 실행해 확인한다(구현 가능한 것과 불가능한 것을 구분한다).

> **원본 근거 주의**: 텍스트 추출본에서 1과목 앞부분(데이터 모델링 개념, 엔터티·속성·관계·식별자 본문)은 판독되지 않았다(SOURCE_ACCESS_REPORT).
> 추출본에서 확인된 1과목 내용은 E-01(3차 정규화 → 조인), E-02(자기 자신과의 관계·셀프 조인), E-03(자기참조 FK)뿐이다.
> 나머지는 요구목록 §6을 근거로 작성했다. **PDF 원문의 정의·용어와 대조하는 작업은 남아 있다(미완료).**

## 이 단원 전체에서 쓰는 업무 규칙 (학습용 가상 데이터: "동네 도서관")
| 번호 | 업무 규칙 |
|---|---|
| R1 | 회원은 회원번호로 구별하며 이름·전화번호를 가진다. 전화번호는 회원마다 다르다. |
| R2 | 회원은 등급(일반·우수) 중 하나에 속한다. 모든 회원은 반드시 등급이 있다. |
| R3 | 도서(책 제목 단위)는 ISBN으로 구별한다. 도서관은 같은 도서를 여러 권(소장본) 가진다. 소장본은 도서별 일련번호(1, 2, …)로 구별한다. |
| R4 | 회원은 소장본을 대출한다. 한 회원은 여러 번 대출할 수 있고, 한 소장본도 시기를 달리해 여러 번 대출된다. |
| R5 | 대출에는 대출일과 반납일이 있다. 반납일은 대출일보다 빠를 수 없다. 반납 전에는 반납일이 비어 있다. |
| R6 | 한 회원은 동시에 최대 3권까지 대출할 수 있다. |
| R7 | 도서는 여러 저자를 가질 수 있고, 저자도 여러 도서를 쓸 수 있다. |
| R8 | 회원은 다른 회원을 추천인으로 등록할 수 있다(추천인은 0명 또는 1명). |
| R9 | 회원은 회원카드를 최대 1장 가진다. 카드는 반드시 한 회원의 것이다. |
| R10 | 등급은 회원이 한 명도 없어도 존재할 수 있다. 도서는 소장본이 최소 1권 있어야 등록된다. |
