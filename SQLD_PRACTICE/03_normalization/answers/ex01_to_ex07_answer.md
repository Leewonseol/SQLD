# 03 정답 (H)
* G1 함수 종속
  * 완전: (주문번호, 상품코드) → 수량
  * 부분: 주문번호 → 주문일, 고객번호, 고객명, 고객등급, 등급할인율 / 상품코드 → 상품명, 단가
  * 이행: 주문번호 → 고객번호 → 고객명, 고객등급 / 고객번호 → 고객등급 → 등급할인율
* G2 삽입: 주문 없는 신규 고객·신규 상품을 등록할 수 없다. 갱신: 상품 단가를 바꿀 때 일부 행만 바뀌면 모순이 생긴다. 삭제: 고객의 유일한 주문을 지우면 고객 정보도 사라진다.
* G3 3NF: 등급(고객등급 PK, 할인율) / 고객(고객번호 PK, 고객명, 고객등급 FK) / 상품(상품코드 PK, 상품명, 단가) / 주문(주문번호 PK, 주문일, 고객번호 FK) / 주문상세(주문번호 FK + 상품코드 FK = PK, 수량)
* G4 실행 검증: `ex04_order_ledger_answer_oracle.sql`, `…_sqlserver.sql`(lab_check)
* G5 상품 ↔ 공급업체가 1:1이면 상품 → 공급업체, 공급업체 → 상품이 서로 결정자이자 후보키라 BCNF 위반이 없다. 공급업체가 여러 상품을 납품하고 상품도 여러 업체에서 받는다면(M:N) 별도 교차 테이블이 된다.
* G6 트리거(ex07), 같은 트랜잭션에서 상세와 총액을 함께 갱신하는 프로시저, 야간 배치 재계산 + 불일치 점검 쿼리(ex07 Q1).
