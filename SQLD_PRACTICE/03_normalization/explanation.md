# 03 정규화 — 단원 안내

학습 흐름: **논리적 ERD → 식별자·관계·정규화 → 물리적 테이블**.
정규화는 함수 종속을 따라 테이블을 나눠 **이상 현상(삽입·갱신·삭제)** 을 없애는 과정이다. 나눈 테이블은 JOIN으로 원래 정보를 **손실 없이** 복원할 수 있어야 한다(PDF E-01: "3정규형으로 분리된 후에는 […] 조인을 사용해야 한다").

> 근거: PDF 추출본에서 확인된 정규화 내용은 E-01(3차 정규화 사원→사원+부서, 조인 키 = 외래 키)뿐이다. 1NF·2NF·BCNF·이상 현상·반정규화 정의는 요구목록 §6을 근거로 작성했다(PDF 원문 대조 미완료).

## 정규형 요약
| 정규형 | 조건 | 위반 예 → 해결 |
|---|---|---|
| 1NF | 모든 값이 원자값(반복 그룹·다중값 없음) | '취미 = SQL,독서' → (학번, 취미) 행으로 분리 |
| 2NF | 1NF + 기본키의 **일부**에만 종속된 속성이 없다(완전 함수 종속) | (학번, 과목코드) 키에서 학번 → 학생명 → 학생 테이블로 분리 |
| 3NF | 2NF + 키가 아닌 속성이 다른 키가 아닌 속성에 종속되지 않는다(이행 종속 없음) | 학번 → 학과 → 학과장 → 학과 테이블로 분리 |
| BCNF | 모든 결정자가 후보키 | 교수 → 과목인데 교수가 후보키가 아님 → (교수, 과목) 분리 |
| 4NF | 다치 종속 제거 | (이론만, 실행 실습 없음) |
| 5NF | 조인 종속 제거 | (이론만, 실행 실습 없음) |
