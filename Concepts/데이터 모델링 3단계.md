# 데이터 모델링 3단계

## 한 줄 정의

데이터 모델링은 추상화 수준과 목적이 다른 개념적·논리적·물리적 3단계로 진행된다.

## 핵심 규칙

- 개념적 데이터 모델링: 업무 중심, 사용자 관점에서 전체 데이터 구조와 엔터티 간 관계를 표현. [[ERD]] 작성. DBMS에 독립적.
- 논리적 데이터 모델링: 속성 입력, [[식별자]] 설정, [[관계]] 설정, [[정규화]] 수행, [[제약조건]] 반영.
- 물리적 데이터 모델링: 테이블·컬럼 생성, 자료형·길이 결정, 인덱스·파티셔닝 등 성능 고려.
