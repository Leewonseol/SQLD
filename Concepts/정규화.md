# 정규화

## 한 줄 정의

데이터 이상 현상을 방지하기 위해 엔터티를 분리하는 과정이다.

## 핵심 규칙

- 이상 현상: 삽입 이상 / 갱신 이상 / 삭제 이상
- 정규화 단계: 1NF → 2NF → 3NF → BCNF → 4NF → 5NF, 실무 중요 범위는 보통 3NF까지
- 각 단계에서 구체적으로 무엇을 제거·유지하는지(예: 부분 함수 종속 제거=2NF, 이행 종속 제거=3NF)는 원본에 명시되어 있지 않아 보강이 필요하다.
- [[함수적 종속]] 분석 결과가 정규형 판단과 엔터티 분리 여부 결정의 근거로 사용된다.
