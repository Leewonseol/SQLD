# M01-Q37 — NVL·ROUND·LENGTH·MAX 함수 설명

## Question

SQL의 함수 사용에 대한 설명으로 옳지 않은 것은?

## 핵심 판별 기준

ROUND의 반올림 자릿수 규칙, LENGTH의 공백 처리, NVL·MAX의 NULL 처리 규칙을 정확히 적용해야 한다.

## 관련 개념 경로

- [[NULL]] → NVL, MAX
- [[숫자형 함수]] → ROUND
- [[문자형 함수]] → LENGTH
