# M01-Q25 — REGEXP_SUBSTR의 패턴 추출

## Question

SELECT REGEXP_SUBSTR('abc123xyz','[0-9]+') FROM DUAL; 의 실행 결과는?

## 핵심 판별 기준

[0-9]+ 패턴이 숫자 1개 이상이 연속되는 부분을 매칭한다는 규칙을 적용해야 하나, 원본 마인드맵에는 정규표현식 함수 자체가 없다.
