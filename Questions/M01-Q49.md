# M01-Q49 — SUM/COUNT(*)와 NULL을 이용한 평균 계산

## Question

TBL(VAL: 10,20,30,NULL)에서 SELECT SUM(VAL)/COUNT(*) FROM TBL; 의 실행 결과는?

## 핵심 판별 기준

SUM은 NULL을 제외한 합계(60)를, COUNT(*)는 NULL을 포함한 전체 행수(4)를 계산해 60/4=15가 된다는 것을 결합해 적용해야 한다.

## 관련 개념 경로

- [[집계 함수]] → SUM, [[COUNT]](*) → [[NULL]]
