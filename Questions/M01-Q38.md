# M01-Q38 — NVL과 SUM의 결합

## Question

TEST(COL1: 10,NULL,20)에서 SELECT SUM(NVL(COL1,900)) FROM TEST; 의 실행 결과는?

## 핵심 판별 기준

NVL(COL1,900)이 NULL을 900으로 먼저 대체한 뒤, SUM이 대체된 값들을 모두 합산한다는 순서를 적용해야 한다.

## 관련 개념 경로
