# M01-Q15 — 문자형 컬럼의 ORDER BY 정렬

## Question

TAB(COL1 PK VARCHAR2(10), COL2 VARCHAR2(10)) 테이블에 A/100, B/99, C/900, D/1000이 입력되어 있을 때, SELECT COL1 FROM TAB ORDER BY COL2 DESC; 의 결과 COL1 순서는?

## 핵심 판별 기준

COL2가 문자형이므로 숫자처럼 보여도 사전식(문자열) 비교가 적용된다는 것을 알아야 한다.
