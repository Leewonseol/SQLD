# M01-Q16 — Oracle 정규표현식 함수

## Question

Oracle 정규표현식 함수 사용에 대한 설명으로 옳지 않은 것은?

## 핵심 판별 기준

REGEXP_LIKE/REPLACE/INSTR/COUNT 각 함수의 기능과 Oracle 지원 여부를 알아야 하나, 원본 마인드맵에는 이 함수군 자체가 없다.
