# M01-Q13 — NVL과 NULL 대체

## Question

[EMP] 테이블(ENAME, SAL: A/5000, B/NULL, C/1000)에서 SELECT NVL(SAL,0) FROM EMP WHERE ENAME='B'; 의 실행 결과는?

## 핵심 판별 기준

NVL(값1, 값2)은 값1이 NULL이면 값2를 반환한다는 규칙을 적용해야 한다.

## 관련 개념 경로

- [[NULL]] → NVL
