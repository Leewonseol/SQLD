# M01-Q28 — CONNECT BY를 이용한 계층 전개

## Question

EMP(ENAME, MGR: A/NULL, B/A, C/B)에서 SELECT ENAME FROM EMP START WITH MGR IS NULL CONNECT BY PRIOR ENAME=MGR; 의 실행 결과는?

## 핵심 판별 기준

MGR이 NULL인 행(A)부터 시작해 PRIOR ENAME=MGR 조건으로 하위 계층을 재귀적으로 전개해야 하나, 원본 마인드맵에는 계층형 질의 자체가 없다.
