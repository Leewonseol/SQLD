# M01-Q24 — TOP WITH TIES와 동점 처리

## Question

TB_SCORE(STUDENT_ID, SCORE: S001/90, S002/85, S003/85, S004/80, S005/75)에서 SELECT TOP(2) WITH TIES STUDENT_ID FROM TB_SCORE ORDER BY SCORE DESC; 의 실행 결과는?
