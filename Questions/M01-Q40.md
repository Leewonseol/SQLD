# M01-Q40 — DDL 자동 커밋과 ROLLBACK 흐름 추적

## Question

EMP 테이블(초기 0행)에서 INSERT A → INSERT B → DELETE(A) → CREATE TABLE DEPT → INSERT C → ROLLBACK 순으로 실행한 뒤 SELECT COUNT(*) FROM EMP;의 결과는?

## 핵심 판별 기준

CREATE TABLE(DDL)이 Oracle에서 자동 COMMIT을 유발해 그 이전 DML(B 삽입)까지 확정시키고, 이후 ROLLBACK은 그 다음에 시작된 트랜잭션(C 삽입)만 취소한다는 흐름을 추적해야 한다.

## 관련 개념 경로

- [[DDL]] → [[AUTO COMMIT]] → [[ROLLBACK]] → [[Transaction]]
