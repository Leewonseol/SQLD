# M01-Q11 — GROUP BY 없는 SUM과 NULL

## Question

[TB_SALE] 테이블(CUST_ID, AMOUNT: A/100, B/NULL, C/200)에서 SELECT SUM(AMOUNT) FROM TB_SALE; 의 실행 결과로 가장 알맞은 것은?

## 핵심 판별 기준

GROUP BY 없이 집계 함수를 쓰면 테이블 전체를 하나의 그룹으로 보며, SUM은 NULL을 무시하고 합산한다.
