# M01-Q17 — SQL 명령어 분류(DCL)

## Question

다음 SQL 명령어 중 DCL에 해당하는 것은?

## 핵심 판별 기준

SELECT/COMMIT/GRANT/CREATE가 각각 어느 분류(DML·TCL·DCL·DDL)에 속하는지 구분해야 하나, 원본 마인드맵에는 DCL 섹션 자체가 없다.
