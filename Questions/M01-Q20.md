# M01-Q20 — WHERE절의 집계 함수 사용 오류

## Question

SELECT DEPTNO, SUM(SAL) FROM EMP WHERE SUM(SAL)>1000 GROUP BY DEPTNO; 실행 시 오류가 발생하는 이유는?

## 핵심 판별 기준

집계 함수는 WHERE절에서 사용할 수 없으며, 집계 결과에 조건을 걸려면 HAVING을 사용해야 한다는 규칙을 적용해야 한다.
