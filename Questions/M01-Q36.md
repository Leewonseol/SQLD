# M01-Q36 — ORDER BY 별칭·순서번호 혼용

## Question

EMP(ENAME,SAL,DEPTNO)에서 실행 시 결과가 나머지와 다른 하나는?

## 핵심 판별 기준

ORDER BY는 열 이름, 별칭, SELECT 순서 번호를 혼용할 수 있으며, 각 열마다 ASC/DESC를 다르게 지정할 수 있다는 점을 정확히 대응시켜야 한다.
