# 03. 분석 기법별 Olist 적용 — 실행 가능 여부 판정

`olist_customers_dataset.csv` 하나만 존재하는 이 저장소 상태에서, 요청받은 분석 기법
목록을 하나씩 다음 네 가지 중 하나로 분류했다.

1. **가능** — 고객 파일만으로 실제로 수행(가짜 변수 없이)
2. **부분 가능** — 요청의 일부(재구매 여부 등 실제 도출 가능한 변수)만 실데이터로 수행,
   나머지(주문액·배송기간 등)는 이름을 명시하고 보류
3. **불가능** — 대체 불가능, 필요한 Olist 테이블 이름을 명시하고 골격만 작성
4. **보너스** — 요청의 문자 그대로는 아니지만, 완전히 실데이터인 다른 분석 단위(주 단위
   집계)로 같은 기법을 연습

절대 하지 않은 것: `customer_id`/`customer_zip_code_prefix`를 연속형 변수로 사용, 주문액·
배송기간·평점 등 없는 변수를 임의 생성, 구현 개수를 채우기 위한 억지 변형.

## 폴더 안내

- `_shared/` — 모든 실데이터 모듈이 공유하는 파생 테이블(`customer_repeat_features`) 준비
- `A-가설검정/` — ANOVA(주별 `n_orders`), 카이제곱(주×재구매)
- `B-로지스틱회귀-재구매예측/` — 재구매 여부를 주 더미로 예측
- `C-분류모델비교-교차검증-성능지표/` — RF·SVM·KNN 비교, 5-fold 교차검증, 성능지표
- `D-지역프로파일-PCA-Kmeans-보너스/` — 주 단위 집계 PCA·K-means (개별 고객 아님, 완전 실데이터)
- `스켈레톤-불가능기법/` — 연관규칙·시계열/ARIMA·주문 관련 기술통계/결측치/이상치·
  배송지연/저평점 예측·고객단위 PCA — 지금은 실행 불가, 파일 추가 시 사용할 골격

## 공통 결론

행동·거래 데이터(주문·결제·배송·리뷰·상품)가 전혀 없는 고객 마스터 파일만으로는, 지역
(state/city) 이외의 예측 신호를 만들 수 없다. `B`, `C`에서 실제로 확인했듯 지역 기반
모델의 예측력은 무작위 수준(ROC-AUC ≈ 0.5, McFadden R² ≈ 0.0005)에 그친다. 이는 구현이
부족해서가 아니라 **입력 데이터의 근본적 한계**이며, 이 결론 자체가 정직한 데이터 분석
실습의 결과물이다.
