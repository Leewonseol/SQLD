# SQLD 시험 직전 압축 복습

## 목적

- SQLD 2과목 핵심 개념을 짧게 복습한다.
- 명령어 분류부터 NULL까지 한 흐름으로 연결한다.
- 시험에서 자주 혼동하는 개념을 대비 중심으로 정리한다.
- 기존 상세 학습 자료로 이동할 수 있는 진입점을 제공한다.

> 이 폴더는 기존 상세 학습 자료를 대체하지 않는다. 기존 폴더는 상세 학습·실습·DBMS
> 비교·계산 검증을 맡고, 이 폴더는 시험 직전 1분 복습·함정 정리·개념 분기표만 맡는다.

```text
→ NULL 비교와 3값 논리
→ 집계함수와 NULL
→ 최종 1분 압축
```
