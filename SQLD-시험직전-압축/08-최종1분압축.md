# 최종 1분 압축

## SQL 명령어 분류

| 분류 | 기억어 |
|---|---|
| DDL | 구조 |
| DML | 데이터 |
| DCL | 권한 |
| TCL | 트랜잭션 |

## 핵심 함정

- `ALTER` = 구조 변경
- `UPDATE` = 데이터 값 변경
- `REVOKE` = DCL
- `COMMIT` = TCL
- `WHERE` = 행 조건
- `HAVING` = 그룹 조건
- 집계 함수 조건은 HAVING
- NULL 비교는 `IS NULL`, `IS NOT NULL`
- NULL과 일반 비교는 UNKNOWN
- 집계함수는 NULL 제외
- 산술식에 NULL이 포함되면 결과 NULL

## 논리적 실행 순서

```text
FROM
→ WHERE
→ GROUP BY
→ HAVING
→ SELECT
→ ORDER BY
```

## 최종 분기

```text
누가 할 수 있는가?       → DCL
구조를 바꾸는가?         → DDL
데이터를 다루는가?       → DML
작업을 확정·취소하는가?  → TCL
행을 거르는가?           → WHERE
그룹을 거르는가?         → HAVING
값이 없는가?             → IS NULL
```
