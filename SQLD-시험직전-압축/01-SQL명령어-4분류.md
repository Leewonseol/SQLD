# SQL 명령어 4분류

## 핵심 질문

> SQL로 무엇을 하려는가?

## 분기표

```text
SQL로 무엇을 하려는가?
│
├─ 누가 무엇을 할 수 있는지 통제한다
│  └─ DCL
│     ├─ GRANT  : 권한 부여
│     ├─ REVOKE : 권한 회수
│     └─ ROLE   : 여러 권한을 묶어 관리
│
├─ 구조·객체를 만들거나 바꾼다
│  └─ DDL
│     ├─ CREATE
│     ├─ ALTER
│     ├─ DROP
│     ├─ RENAME
│     └─ TRUNCATE
│
├─ 테이블 안의 데이터를 다룬다
│  └─ DML
│     ├─ SELECT
│     ├─ INSERT
│     ├─ UPDATE
│     ├─ DELETE
│     └─ MERGE
│
└─ 데이터 변경 작업 묶음을 통제한다
   └─ TCL
      ├─ COMMIT
      ├─ ROLLBACK
      └─ SAVEPOINT
```

> ROLE은 `GRANT`/`REVOKE`처럼 한 번에 실행되는 단일 동작 명령이 아니라, 여러 권한을
> 묶어서 사용자에게 한 번에 부여·회수하기 위한 **권한 집합**이다.

## 핵심 개념 표

| 분류 | 핵심 질문 |
|---|---|
| DCL | 누가 무엇을 할 수 있는가? |
| DDL | 구조·객체를 바꾸는가? |
| DML | 데이터를 다루는가? |
| TCL | 작업을 확정·취소하는가? |

## 최소 SQL 예시

```sql
-- DCL
GRANT SELECT ON EMP TO USER1;
REVOKE SELECT ON EMP FROM USER1;

-- DDL
CREATE TABLE EMP (EMPNO NUMBER PRIMARY KEY);
ALTER TABLE EMP ADD SAL NUMBER;

-- DML
INSERT INTO EMP (EMPNO) VALUES (1);
UPDATE EMP SET SAL = 3000 WHERE EMPNO = 1;

-- TCL
COMMIT;
ROLLBACK;
```

## 시험 함정

- `REVOKE`는 DCL.
- `COMMIT`은 TCL.
- `ALTER`는 구조 변경이므로 DDL.
- `UPDATE`는 데이터 값 변경이므로 DML.
- 교재에 따라 `SELECT`를 DML에 포함하거나 DQL로 따로 분류하기도 한다.
- 이 압축 문서는 SQLD 강의 자료 기준에 맞춰 `SELECT`를 DML에 포함한다.
