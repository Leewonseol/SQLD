## 출제 형식

각 보기에는 `[Oracle · 공통 문법]`, `[SQL Server · 전용 문법]`처럼 **평가할 DBMS와 문법 구분**을 표시했습니다. 한 문항에서 두 DBMS 선지의 위치와 개수는 고정되지 않습니다. `공통 문법`은 양쪽에서 대체로 동일하게 작성하는 SQL을 뜻하며, 정확한지 여부는 별도로 판단해야 합니다.

### 목차

| 영역 | 절 | 문제 |
|---|---|---|
| SQL 기본 | 관계형 DB 개요, SELECT 문, 함수, WHERE, GROUP BY/HAVING, ORDER BY, 조인, 표준 조인 | 01–24 |
| SQL 활용 | 서브쿼리, 집합 연산자, 그룹 함수, 윈도우 함수, Top N, 계층형 질의·셀프 조인, PIVOT/UNPIVOT, 정규 표현식 | 25–48 |
| 관리 구문 | DML, TCL, DDL, DCL | 49–60 |

## 실습 및 검증 한계

1. **주의:** 실습 데이터 스크립트는 동명 테이블을 `DROP TABLE`로 삭제합니다. 반드시 독립된 학습용 스키마/데이터베이스에서만 실행하세요.
2. 변경형 SQL 문제(DML, TCL, DDL, DCL)는 상태와 권한에 따라 결과가 바뀔 수 있으므로 초기화한 환경에서 하나씩 실행합니다.
3. 문제/정답 수와 20개 절 포함 여부, 문항 내 두 DBMS 배치를 정적으로 점검했습니다. **Oracle과 SQL Server 서버에서 240개 보기를 모두 실행한 것은 아니므로, 정답의 실행 검증이 완료된 문제집은 아닙니다.**
4. 첨부 1과목의 모델링·키·무결성 관련 PDF는 배경 참고이며 **1과목 51개 문장별 출제는 포함하지 않습니다.**

기존 저장소 문서와 구분하기 위해 독립 폴더로 추가했습니다.
