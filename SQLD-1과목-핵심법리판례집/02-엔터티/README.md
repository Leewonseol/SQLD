# 02 엔터티

기본 학습은 아래 비교표와 결정 트리로 진행한다. 상세 근거와 기출 해설이 필요할 때만 하단 "상세 기출 해설" 링크를 연다.

## 1. 핵심 개념 비교표

### 엔터티 vs 속성 vs 인스턴스 vs 배경 서술

| 구분 | 엔터티 | 속성 | 인스턴스 | 배경 서술 |
| --- | --- | --- | --- | --- |
| 의미 | 독립적으로 관리하는 대상 | 대상을 설명하는 정보 항목 | 엔터티의 개별 사례 | 저장하지 않는 배경 설명 |
| 사례 | 회원, 상품, 주문 | 회원ID, 상품명 | 특정 회원 1명 | "다양한 음료를 판매한다" |
| 판정 질문 | 그 자체를 계속 관리하는가 | 다른 대상을 설명하는가 | 집합의 한 사례인가 | 저장할 필요가 있는가 |

### 엔터티 성립요건

| 요건 | 판단 |
| --- | --- |
| 업무상 관리 필요 | 필수 |
| 인스턴스 2개 이상 가능 | 필수 |
| 속성 1개 이상 | 필수 |
| 다른 엔터티와 관계 1개 이상 | 원칙(통계성·코드성 엔터티는 예외적으로 관계 없이도 성립) |

### 엔터티 분류(두 개의 독립축)

| 축 | 분류 | 판단 기준 |
| --- | --- | --- |
| 발생시점 | 기본(키)엔터티 → 중심엔터티 → 행위엔터티 | 독립생성 가능 여부, 파생 여부, 관계 속 발생·변경 빈도 |
| 유무형 | 유형엔터티 / 개념엔터티 / 사건(Event)엔터티 | 물리적 형태 유무, 개념적 정보 여부, 업무 수행으로 발생하는 사건 여부 |

⚠️ 발생시점 축의 "행위(Event)엔터티"와 유무형 축의 "사건(Event)엔터티"는 이름이 같은 "Event"지만 서로 다른 축의 별개 개념이다.

## 2. 판정 순서

```text
그 명사가 독립적으로 관리되는가?
├─ 예 → 엔터티 후보
│  ├─ 인스턴스 2개 이상 가능한가?
│  ├─ 속성이 1개 이상 존재하는가?
│  └─ 다른 엔터티와 관계가 있는가? (없으면 통계성·코드성 예외 검토)
└─ 아니오
   ├─ 다른 대상을 설명하는 세부 항목인가? → 예: 속성
   └─ 저장 대상 자체가 아닌가? → 예: 배경 서술
```

```text
무엇을 기준으로 분류하는가?
├─ 유무형 → 유형 / 개념 / 사건(Event)
└─ 발생시점 → 기본(키) → 중심 → 행위(Event)
   ⚠️ 같은 "Event"라도 축이 다르면 다른 개념
```

## 3. 유사 사례 비교

| 사례 | 결정적 사실 | 적용 개념 | 결론 |
| --- | --- | --- | --- |
| 회원, 상품, 구매 | 독립적으로 저장·관리되는 대상 | 엔터티 성립요건 | 엔터티 |
| 회원ID, 상품명 | 다른 대상(회원, 상품)을 설명하는 값 | 엔터티 vs 속성 구분 | 속성 |
| "다양한 음료와 푸드를 판매한다" | 관리 대상이 아니라 요구사항의 배경 설명 | 엔터티 성립요건 | 배경 서술(엔터티 아님) |
| 회원(기본엔터티) vs 구매(중심엔터티) vs 구매이력(행위엔터티) | 독립생성 가능 여부와 파생 순서 | 발생시점 분류 | 서로 다른 3단계 |
| 개념엔터티 vs 행위(Event)엔터티 | 유무형 축인가 발생시점 축인가 | 엔터티 분류 두 축 구분 | 서로 다른 축의 별개 개념 |

## 4. 반복 오답

| 선지 표현 | O/X | 틀린 이유 | 올바르게 고치면 |
| --- | :-: | --- | --- |
| 다른 엔터티와 반드시 2개 이상 관계를 가져야 한다 | X | 최소 요건은 1개 이상(범위 과장, D4) | 관계는 최소 1개 이상이면 되고, 통계성·코드성 엔터티는 없어도 된다 |
| 회원ID, 상품명처럼 세부 항목도 엔터티로 분류한다 | X | 다른 대상을 설명하는 속성을 엔터티로 잘못 분류(정의 바꿔치기, D1) | 회원ID, 상품명은 속성이다 |
| "개념엔터티"는 발생시점 기준(기본/중심/행위) 분류에 속한다 | X | 개념엔터티는 유무형 기준 분류(단계·분류축 혼동, D5) | 개념엔터티는 유무형 기준 분류다 |
| 기본엔터티는 독립적으로 생성될 수 없다 | X | 기본엔터티는 독립적으로 생성 가능(반대 개념 적용, D2) | 기본엔터티는 독립적으로 생성 가능하며 다른 엔터티의 부모 역할을 한다 |
| 이력엔터티는 기본엔터티로 분류된다 | X | 이력엔터티는 행위엔터티(정의 바꿔치기, D1) | 이력엔터티는 행위(Event)엔터티로 분류된다 |

## 5. 문제 풀이 규칙

```text
각 선지를 먼저 O/X 판정
→ 문제가 O를 묻는지 X를 묻는지 확인
→ 정답 선택
```

"모두 고르시오" 조합선지형은 각 진술(ㄱㄴㄷ)을 먼저 O/X 판정한 뒤, X가 포함된 조합을 소거하고 O만 포함된 조합을 선택한다.
