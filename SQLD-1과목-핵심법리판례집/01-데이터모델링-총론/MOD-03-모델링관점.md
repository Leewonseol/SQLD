# [MOD-03] 데이터 모델링의 세 가지 관점(데이터/프로세스/상관 관점)

> [!IMPORTANT]
> **핵심 법리:**
> 데이터 모델링은 데이터 관점(무엇을 저장할 것인가), 프로세스 관점(어떻게 처리할 것인가), 상관 관점(업무 흐름에 따라 데이터가 어떻게 조작되는가)이라는 세 가지 관점으로 접근한다. 정규화·반정규화 같은 모델링 "기법"은 이 세 관점에 속하지 않는다.
>
> [!TIP]
> **정답을 가르는 사실:**
> 선지가 "업무 흐름에 따라 데이터가 생성·조회·변경·삭제되는 방식"을 서술하면 상관 관점, "업무 처리 절차 자체"면 프로세스 관점, "엔터티·속성·관계 등 저장 대상 자체"면 데이터 관점이다. "정규화 관점"처럼 기법이 관점 목록에 등장하면 함정이다.
>
> [!WARNING]
> **반복 오답:**
> 정규화·반정규화 같은 모델링 기법을 세 가지 관점 중 하나인 것처럼 선지에 섞어 넣는 함정, 상관 관점의 정의를 프로세스 관점의 정의(단순 업무 처리 절차)와 뒤바꿔 서술하는 함정.

## 1. 판시사항

- 데이터 모델링의 세 가지 관점(데이터/프로세스/상관 관점)은 각각 무엇을 바라보는 관점인가?
- "모델링 관점이 아닌 것"을 고를 때 정규화와 같은 모델링 기법을 관점과 어떻게 구별하는가?

## 2. 핵심 법리

> 데이터 모델링은 데이터 관점(엔터티·속성·관계 등 저장 대상 자체를 보는 관점), 프로세스 관점(업무 처리 절차와 흐름 자체를 보는 관점), 상관 관점(업무 흐름에 따라 데이터가 어떻게 생성·조회·변경·삭제되는지, 즉 데이터와 프로세스가 서로 어떤 영향을 주고받는지를 보는 관점)이라는 세 가지로 접근한다. 정규화·반정규화·인덱스 설계 등은 논리적·물리적 모델링 단계에서 수행하는 "기법"이지 "관점"이 아니므로, 모델링 관점을 나열하는 선지에 이런 기법이 등장하면 관점 목록에서 제외해야 한다.

## 3. 법리 적용 분기

```text
선지가 설명하는 것은?
│
├─ 엔터티·속성·관계 등 "무엇을 저장하는가"
│  └─ 데이터 관점
│
├─ 업무 처리 절차·흐름 자체("어떻게 처리하는가")
│  └─ 프로세스 관점
│
├─ 업무 흐름에 따라 데이터가 생성·조회·변경·삭제되는 방식
│  ("데이터가 프로세스에 의해 어떤 영향을 받는가")
│  └─ 상관 관점 (데이터와 프로세스의 상관관계)
│
└─ 정규화·반정규화·인덱스 등 모델링 "기법"이 관점처럼 제시됨
   └─ 관점이 아님(오답 함정)
```

## 4. 이 문제들이 유사한 이유

| 기준 | 내용 |
| --- | --- |
| 공통 핵심 법리 | 데이터/프로세스/상관 관점 3가지의 정의를 구분하고, 정규화 같은 "기법"과 "관점"을 혼동하지 않는 동일한 판단 규칙 |
| 공통 결정 사실 | 선지가 "무엇을 저장"하는지, "어떻게 처리"하는지, "데이터가 프로세스에 의해 어떻게 영향받는지"를 서술하는지, 아니면 관점이 아닌 기법을 관점처럼 제시하는지 |
| 반복되는 오답 구조 | 정규화 같은 모델링 기법을 관점 목록에 섞어 정답 후보처럼 제시(D1 정의 바꿔치기), 상관 관점과 프로세스 관점의 정의를 맞바꿈 |
| 정답이 달라지는 조건 | 선지가 "관점"(데이터를 바라보는 틀)을 서술하는지 "기법"(모델을 조정하는 수행 방법)을 서술하는지 |

### 사실관계

"모델링의 세 가지 관점 중 업무 처리 방식에 따라 데이터가 어떻게 영향을 받는지를 모델링하는 방법은?"이라는 질문에 4개 선지가 제시된다.

### 쟁점

"업무 처리 방식에 따라 데이터가 어떻게 영향을 받는지"라는 서술이 데이터 관점, 프로세스 관점, 상관 관점 중 어디에 해당하는지가 쟁점이다.

### 적용 법리

데이터와 프로세스가 서로 어떤 영향을 주고받는지, 즉 업무 흐름에 따라 데이터가 어떻게 조작되는지를 보는 것은 상관 관점이다. 이는 데이터 자체만 보는 데이터 관점이나, 처리 절차만 보는 프로세스 관점과는 다르다.

### 주문

**정답: ③**

### 판결이유

```text
문제의 결정적 사실: "업무 처리 방식에 따라 데이터가 어떻게 영향을 받는지"를 모델링하는 방법을 물음
→ 적용되는 핵심 법리: 데이터와 프로세스가 서로 어떤 영향을 주고받는지를 보는 것은 상관 관점이다
→ 정답 선지: ③(데이터와 프로세스의 상관 관점)
```
