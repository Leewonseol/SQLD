# [MOD-02] 개념·논리·물리 데이터 모델링 단계 구분

> [!IMPORTANT]
> **핵심 법리:**
> 개념적 모델링은 추상적·전사적 수준에서 사용자 관점의 전체 구조를 표현하고, 논리적 모델링은 Key·속성·관계를 구체적으로 표현하며 재사용성이 높고, 물리적 모델링은 실제 DB에 반영되도록 성능·저장구조까지 설계한다. 반정규화·인덱스·저장구조는 물리적 모델링의 영역이다.
>
> [!TIP]
> **정답을 가르는 사실:**
> "추상적/전사적/사용자 관점"이면 개념적, "Key·속성·관계를 정확히 표현/재사용성"이면 논리적, "성능/저장구조/반정규화/인덱스"면 물리적이다.
>
> [!WARNING]
> **반복 오답:**
> 개념 모델링에 물리적 특성(저장구조·인덱스)을 섞어 넣기, 논리 모델링 단계에서 반정규화를 수행한다고 서술하기, 3단계 순서를 뒤바꾸기.

## 1. 판시사항

- 개념적·논리적·물리적 데이터 모델링은 각각 어떤 특징을 가지며, 어느 단계에서 반정규화·성능 설계를 수행하는가?
- 데이터 모델링 3단계의 올바른 진행 순서는 무엇인가?

## 2. 핵심 법리

> 데이터 모델링은 **개념적(추상화 수준 높음, 전사적, 사용자 관점) → 논리적(Key·속성·관계를 구체적으로 표현, 재사용성 높음) → 물리적(성능·저장구조 반영, 반정규화 수행)** 순서로 진행된다. 반정규화는 논리 모델링이 아니라 물리 모델링 단계에서 수행한다는 것이 가장 자주 출제되는 함정이다.

## 3. 법리 적용 분기

```text
선지가 설명하는 특징은?
│
├─ 추상적, 전사적, 사용자 관점, 물리 구조 미포함
│  └─ 개념적 데이터 모델링
│
├─ Key/속성/관계를 구체적으로 표현, 재사용성 높음, DBMS 독립적
│  └─ 논리적 데이터 모델링
│
└─ 인덱스/저장구조/반정규화 등 성능 요소 반영
   └─ 물리적 데이터 모델링
```

## 4. 이 문제들이 유사한 이유

| 기준 | 내용 |
| --- | --- |
| 공통 핵심 법리 | 3단계 모델링의 특징을 구분하는 동일한 판단 규칙(추상화 수준, DBMS 종속 여부, 반정규화 수행 시점) |
| 공통 결정 사실 | 선지에 등장하는 키워드가 "추상적/전사적"인지 "Key·속성·정규화"인지 "저장구조·인덱스·반정규화"인지 |
| 반복되는 오답 구조 | 물리적 특성을 개념적 모델링 설명에 끼워 넣거나, 반정규화 수행 시점을 논리 모델링으로 잘못 서술(D5 단계 혼동) |
| 정답이 달라지는 조건 | "반정규화를 수행한다"는 문장이 어느 단계에 붙어 있는지에 따라 참/거짓이 갈린다 |

## 5. 대표 판례

### 사건 MOD-02-01

- 출처: 이기적 단원별 기출문제, SECTION01 데이터 모델의 이해
- PDF 페이지: page_02 (교재 p.32)
- 원문 문제번호: 08
- 핵심 법리 ID: MOD-02
- 보조 법리 ID: PERF-01

### 사실관계

"논리적/물리적 모델링 비교 설명 중 옳지 않은 것은?"이라는 질문에 4개 선지가 제시되며, 그중 하나는 "논리적 모델링 단계에서 반정규화를 수행한다"이다.

### 쟁점

반정규화가 논리적 모델링과 물리적 모델링 중 어느 단계에서 이뤄지는지 구별하는 것이 이 문제의 핵심이다.

### 적용 법리

반정규화는 성능을 위해 저장구조를 조정하는 작업이므로 물리적 모델링 단계에 속한다. 논리적 모델링 단계는 아직 물리적 구현을 고려하지 않고 Key·속성·관계·정규화까지만 다룬다.

### 주문

**정답: ③**

### 판결이유

```text
문제의 결정적 사실: 선지가 "논리적 모델링 단계에서 반정규화를 수행한다"고 서술함
→ 적용되는 핵심 법리: 반정규화는 물리적 모델링 단계의 성능 설계 작업이다
→ 정답 선지: ③(단계를 뒤바꾼 서술이므로 옳지 않은 설명)
```

| --- | --- | --- | --- | --- | --- |

| ② | 오답(옳은 설명) | 물리모델은 실제 저장구조를 다룸 | 물리적 모델링의 정의 그대로 옳은 설명 | 해당 없음 | 그대로 |
| ③ | 정답 | 논리적 모델링 단계에서 반정규화를 수행한다 | 반정규화는 물리적 모델링 단계에서 수행하므로 틀린 설명 | D5 단계 혼동 | "물리적 모델링 단계에서 반정규화를 수행한다"로 고치면 참 |
| ④ | 오답(옳은 설명) | 물리모델은 성능을 고려해 설계 | 물리적 모델링의 정의 그대로 옳은 설명 | 해당 없음 | 그대로 |

## 9. 출제자가 바꾸는 사실

- 반정규화·인덱스 등 물리적 특성을 개념/논리 모델링 설명에 끼워 넣기
- 3단계 순서를 뒤바꾸기
- "DBMS에 독립적"이라는 논리 모델링 특징을 물리 모델링 설명으로 위장

## 10. 시험용 한 줄 법리

> 반정규화·인덱스·저장구조가 보이면 물리, Key·속성·관계·정규화가 보이면 논리, 추상적·전사적 서술만 있으면 개념.
