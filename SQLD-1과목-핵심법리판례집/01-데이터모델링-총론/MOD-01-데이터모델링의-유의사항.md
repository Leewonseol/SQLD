# [MOD-01] 데이터 모델링의 유의사항과 품질 저하 요소

> [!IMPORTANT]
> **핵심 법리:**
> 데이터 모델링은 중복(Duplication)·비유연성(Inflexibility)·비일관성(Inconsistency) 세 가지를 지양해야 하며, 이 셋은 서로 다른 원인에서 발생하는 독립된 위험이다.
>
> [!TIP]
> **정답을 가르는 사실:**
> 선지가 "무엇 때문에 어떤 문제가 생기는가"를 묻는지 확인한다 — 중복=같은 데이터가 여러 곳에 저장, 비유연성=애플리케이션과 데이터의 연계성이 높아 사소한 변경에도 모델이 흔들림, 비일관성=연관관계를 명확히 정의하지 않아 일부 데이터만 변경되는 경우.
>
> [!WARNING]
> **반복 오답:**
> "애플리케이션과 데이터 간 연계성을 높인다"를 장점처럼 서술하는 함정(실제로는 비유연성의 원인), 세 가지 유의사항의 정의를 서로 바꿔치기하는 함정.

## 1. 판시사항

- 데이터 모델링을 할 때 지양해야 할 세 가지 유의사항은 무엇이며, 각각 어떤 상황에서 발생하는가?
- "데이터 품질을 저하시키는 요소가 아닌 것"을 고를 때, 물리설계 단계의 제약조건 설정과 모델링 유의사항을 어떻게 구별하는가?

## 2. 핵심 법리

> 데이터 모델링의 유의사항은 **중복(Duplication)** — 같은 데이터가 여러 엔터티에 중복 저장되는 현상, **비유연성(Inflexibility)** — 애플리케이션과 데이터 모델의 연계성이 높아 사소한 변경에도 모델이 수시로 바뀌어야 하는 현상, **비일관성(Inconsistency)** — 데이터 간 연관 관계를 명확히 정의하지 않아 일부 데이터만 변경되어 데이터 간 정합성이 깨지는 현상, 세 가지로 구분된다. 이 세 가지는 원인이 서로 다르므로 사례가 어떤 원인에서 비롯됐는지로 구분해야 한다.

## 3. 법리 적용 분기

```text
데이터 모델링 문제 상황인가?
│
├─ 같은 데이터가 여러 엔터티/컬럼에 반복 저장됨
│  └─ 중복(Duplication)
│
├─ 개발자가 연관 데이터를 고려하지 못하고 일부만 변경
│  └─ 비일관성(Inconsistency)
│
└─ 애플리케이션 요구사항이 바뀔 때마다 데이터 모델도 따라 바뀜
   (연계성이 높아서 발생)
   └─ 비유연성(Inflexibility)
```

## 4. 이 문제들이 유사한 이유

| 기준 | 내용 |
| --- | --- |
| 공통 핵심 법리 | 데이터 모델링 유의사항 3가지(중복/비유연성/비일관성)의 정의와 발생 원인을 구분해서 아는가 |
| 공통 결정 사실 | 지문에 "연계성", "일부만 변경", "같은 데이터가 여러 군데" 중 어떤 키워드가 있는지 |
| 반복되는 오답 구조 | 세 유의사항의 정의를 서로 뒤바꿔 서술(D1 정의 바꿔치기), 연계성을 높이는 것을 장점처럼 서술(D6 방향 역전) |
| 정답이 달라지는 조건 | 지문의 원인 서술이 "연관관계 미정의"인지 "연계성 강화"인지에 따라 비일관성/비유연성이 갈린다 |

## 5. 대표 판례

### 사건 MOD-01-01

- 원문 문제번호: 06
- 핵심 법리 ID: MOD-01
- 보조 법리 ID: 없음

### 사실관계

"데이터 품질을 저하시키는 요소로 볼 수 없는 것은?"이라는 질문에 4개 선지가 제시되며, 그중 하나는 "특정 컬럼에 NOT NULL 제약조건을 지정하지 않음"이다.

### 쟁점

NOT NULL 미지정은 물리설계 단계의 제약조건 설정 문제이지, 데이터 모델링 유의사항(중복/비유연성/비일관성)이 다루는 논리적 품질 저하 요소가 아니다. 출제자는 "품질 저하"라는 큰 범주 안에서 서로 다른 단계(논리 모델링 vs 물리 제약조건)의 개념을 섞어 놓았다.

### 적용 법리

나머지 선지들이 중복·비유연성·비일관성에 해당하는 서술이라면, NOT NULL 미지정처럼 물리적 제약조건 설정에 관한 선지는 "데이터 모델링 유의사항" 범주 밖의 것으로 판단해 정답(품질 저하 요소가 아닌 것)으로 고른다.

### 주문

**정답: ④**

### 판결이유

```text
문제의 결정적 사실: 선지 ④는 물리설계 단계의 제약조건(NOT NULL) 설정에 관한 내용이다
→ 적용되는 핵심 법리: 데이터 모델링 유의사항(중복/비유연성/비일관성)은 논리적 모델링 단계의 개념이다
→ 정답 선지: ④(단계가 다른 개념이므로 "품질 저하 요소"로 볼 수 없음)
```

## 9. 출제자가 바꾸는 사실

- 중복/비유연성/비일관성 세 정의를 서로 뒤바꿔 서술
- "연계성을 높인다"를 장점처럼 포장(실제로는 비유연성의 원인)
- 물리설계 단계 개념(제약조건, 인덱스)을 유의사항 목록에 섞어 넣기

## 10. 시험용 한 줄 법리

> 중복은 "같은 데이터가 여러 곳에", 비유연성은 "연계성이 높아서 잦은 변경", 비일관성은 "일부만 고쳐서 어긋남" — 원인 키워드로 구분한다.
