# [SQL-01] 관계형 모델의 조인 목적, 계층형·상호배타 모델

> [!IMPORTANT]
> **핵심 법리:**
> 관계형 데이터모델은 정규화 원칙에 따라 데이터를 여러 엔터티(테이블)로 분산 저장하므로, 필요한 정보를 한 번에 조회하려면 조인이 필요하다. 조인의 목적은 "여러 엔터티에서 데이터를 한 번에 가져오는 것"이지, 중복을 허용해 성능을 높이는 것(반정규화의 목적)이 아니다. 계층형 모델은 Self Join으로 자기 자신과 관계를 맺어 상위-하위 구조를 표현하고, 상호배타 모델은 하나의 관계가 여러 후보 엔터티 중 정확히 하나와만 대응되어 데이터 중복이 원천적으로 없다.
>
> [!TIP]
> **정답을 가르는 사실:**
> "중복을 허용해 품질/성능을 높인다"는 서술이 "조인의 목적"으로 등장하면 함정(그건 반정규화의 목적). "자기 자신과 관계를 맺는다"면 계층형 모델(Self Join). "UNION과 UNION ALL의 결과가 같다"면 상호배타 모델(중복 없음)의 특징이다.
>
> [!WARNING]
> **반복 오답:**
> 조인의 목적을 반정규화의 목적(중복 허용, 데이터 중복을 통한 조회 성능 향상)과 뒤바꿔 서술, 상호배타 모델에서 중복이 발생한다고(UNION과 UNION ALL 결과가 다르다고) 서술, 계층형 모델을 일반적인 다른 엔터티와의 관계로 서술.

## 1. 판시사항

- 관계형 데이터모델에서 조인이 필요한 이유는 무엇이며, 이는 반정규화의 목적과 어떻게 다른가?
- 계층형 데이터모델(Self Join)과 상호배타적 데이터모델은 각각 어떤 구조적 특징을 가지는가?

## 2. 핵심 법리

> 관계형 데이터모델은 정규화를 통해 데이터를 중복 없이 여러 엔터티로 나누어 저장하므로, 두 개 이상의 엔터티에 흩어진 정보를 한 번에 가져오려면 조인이 필요하다. 조인의 목적은 어디까지나 "나뉜 데이터를 다시 결합해 조회하는 것"이며, 데이터 품질 향상을 위해 중복을 허용하는 것은 조인이 아니라 반정규화(PERF-01)의 목적이다. 계층형 데이터모델은 하나의 엔터티가 자기 자신과 관계를 맺는 Self Join 구조로, 조직도·메뉴 구조처럼 상위-하위 관계를 표현한다. 상호배타적 데이터모델은 하나의 관계(예: 대출자)가 여러 후보 엔터티(학생 또는 교수) 중 정확히 하나에만 대응되는 구조이므로 데이터가 중복 저장되지 않으며, 그 결과 중복을 제거하는 UNION과 중복을 포함하는 UNION ALL의 결과 건수가 동일하다.

## 3. 법리 적용 분기

```text
선지가 설명하는 대상은?
│
├─ "여러 엔터티에서 데이터를 한 번에 가져옴" / "정규화로 나뉜 테이블을 다시 결합"
│  └─ 조인의 목적
│
├─ "중복을 허용해 조회 성능/품질을 높임"이 조인의 목적으로 서술됨
│  └─ 오답 함정 — 이는 반정규화(PERF-01)의 목적
│
├─ "하나의 엔터티가 자기 자신과 관계를 맺음"
│  └─ 계층형 데이터모델(Self Join)
│
└─ "관계가 여러 후보 엔터티 중 정확히 하나에만 대응"
   └─ 상호배타적 데이터모델
      → 데이터 중복이 원천적으로 없음 → UNION 결과 = UNION ALL 결과
```

### 사실관계

"상호배타적 데이터모델에 대한 설명으로 적절하지 않은 것은?"이라는 질문에 4개 선지가 제시되며, 그중 하나는 "UNION과 UNION ALL의 결과 개수가 다르다"이다.

### 쟁점

상호배타적 관계에서는 하나의 자식 인스턴스가 여러 부모 후보 중 정확히 하나에만 대응하므로 데이터 중복이 원천적으로 발생하지 않는다는 사실을 이해하는지가 쟁점이다.

### 적용 법리

UNION은 중복을 제거하고 UNION ALL은 중복을 포함해 합치는 연산이다. 그런데 상호배타 모델은 애초에 중복 데이터가 존재하지 않으므로, 두 연산의 결과 건수는 같아야 한다. 따라서 "결과 개수가 다르다"는 서술은 상호배타 모델의 성질(중복 없음)을 거꾸로 서술한 것이다.

### 주문

**정답: ③**


## 9. 출제자가 바꾸는 사실

- 조인의 목적을 반정규화의 목적(중복 허용)으로 뒤바꿔 서술
- 상호배타 모델에서 중복이 발생한다고(UNION ≠ UNION ALL) 서술
- 계층형 모델을 자기 참조가 아닌 다른 엔터티와의 일반 관계로 서술
- 관계형모델에서 엔터티 간 관계가 한 개만 가능하다고 범위를 과장

## 10. 시험용 한 줄 법리

> 조인은 나뉜 데이터를 다시 합치기 위함, 반정규화는 애초에 합쳐서 저장하기 위함 — 목적이 정반대다. 상호배타 모델은 중복이 없어 UNION=UNION ALL이다.
