# 오답 선지 유형 코드

모든 판례 파일의 "선지별 판단" 표에서 오답 선지의 오답 유형을 아래 코드로 표기한다. 동일한 유형에 새 코드를 중복 생성하지 않는다.

| 코드 | 오답 구조 | 설명 |
| --- | --- | --- |
| D1 | 정의 바꿔치기 | 한 개념의 정의를 다른 개념에 적용해서 서술 |
| D2 | 반대 개념 적용 | 식별·비식별, 존재·행위 등 반대 개념을 교환해서 서술 |
| D3 | 조건 누락 | 복합키, 완전 함수 종속 등 필수 조건을 생략하고 서술 |
| D4 | 범위 과장 | 항상·반드시·전부 등으로 원칙을 과장 |
| D5 | 단계 혼동 | 개념·논리·물리 모델링 단계, 또는 정규화 단계를 서로 교환 |
| D6 | 방향 역전 | 부모·자식, 결정자·종속자 등의 방향을 반대로 서술 |
| D7 | 기호 오독 | ERD의 원·선·까치발 등 표기 기호의 의미나 위치를 잘못 서술 |
| D8 | 행·열 혼동 | 행 집계와 열 집계, `COUNT(*)`와 `COUNT(컬럼)`을 혼동 |
| D9 | 값·상태 혼동 | NULL을 0, 공백, 빈 문자열과 동일시 |
| D10 | 원칙·예외 혼동 | 특정 DBMS의 예외적 동작을 전체 원칙처럼 서술 |
| D11 | 목적·수단 혼동 | 정규화·반정규화의 목적과 실행 방법(수단)을 혼동해서 서술 |
| D12 | 필요·충분조건 혼동 | 일부 요건만 충족하면 전체가 성립하는 것처럼 확대 서술 |

## 코드 사용 원칙

- 오답 선지 하나에 여러 유형이 겹치면 가장 핵심적인 유형 하나만 표기한다.
- 표에 없는 새로운 오답 패턴을 발견하면, 기존 코드로 흡수할 수 있는지 먼저 검토한 뒤에만 새 코드(D13 이상)를 추가한다.
- "정답 선지"의 판정 칸에는 오답 유형 코드 대신 `해당 없음`을 적는다.
