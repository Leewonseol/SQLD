# 08 NULL

기본 학습은 아래 비교표와 결정 트리로 진행한다. 상세 근거와 기출 해설이 필요할 때만 하단 "상세 법리 파일" 링크를 연다.

## 1. 핵심 개념 비교표

### NULL 연산 결과 요약

| 표현 | 결과 |
| --- | --- |
| `NULL = NULL` | UNKNOWN |
| `COL = NULL` | UNKNOWN(0건 반환, `IS NULL`과 다름) |
| `COL IS NULL` | TRUE 또는 FALSE(정상 판정) |
| `100 + NULL` | NULL(전파) |
| `COUNT(COL)` | NULL 제외 |
| `COUNT(*)` | 전체 행 집계(NULL 무관, 유일한 예외) |
| `SUM(A+B)` | 행별 산술 결과가 NULL인 행은 집계에서 제외 |
| `SUM(A)+SUM(B)` | 각 열에서 NULL을 각각 제외한 뒤 합산(SUM(A+B)와 값이 다를 수 있음) |

### NULL·0·공백·빈 문자열 비교

| 구분 | NULL | 0 | 공백 | 빈 문자열 |
| --- | --- | --- | --- | --- |
| 의미 | 값 없음·알 수 없음 | 숫자값 | 문자값 | 길이 0 문자열 |
| Oracle | NULL | 0 | 공백 | NULL처럼 처리(예외) |
| 일반 DBMS 원칙 | NULL | 0 | 공백 | NULL과 구분되는 값 |

### 3값 논리

| 결과 | WHERE 통과 여부 |
| --- | :-: |
| TRUE | O |
| FALSE | X |
| UNKNOWN | X |

### ERD 표기법별 NULL 허용 표시

| 표기법 | NULL 허용 표시 |
| --- | --- |
| Barker | 속성 앞 o(허용)/*(비허용) |
| IE | 표시 관례 없음 |

## 2. 판정용 결정 트리

```text
NULL이 어디에 사용됐는가?
├─ 일반 비교(=, <>, > 등) → UNKNOWN
├─ IS NULL / IS NOT NULL → TRUE/FALSE
├─ 산술(+, -, *, /) → 결과 NULL(전파)
└─ 집계함수
   ├─ COUNT(*) → 행 전체(NULL 무관)
   └─ COUNT(col), SUM, AVG, MAX, MIN → NULL 제외
```

**사례형 문제 풀이 규칙:**

```text
표·계산형: 원본 표 재작성 → 행별 산술(1단계, NULL 전파 여부) → 집계 계산(2단계, NULL 제외 여부, COUNT(*) 예외) → 선지별 결과 비교
```

산술연산(NULL 전파)과 집계함수(NULL 제외)는 서로 반대되는 처리 방식이므로 반드시 단계를 나눠서 계산한다.

## 3. 유사 사례 비교 — 행별 계산 예시

SAMPLE 테이블: COL1(10, NULL, 30), COL2(NULL, 15, 25)

| 행 | COL1 | COL2 | `COL1+COL2` | 이유 |
| --: | --: | --: | --: | --- |
| 1 | 10 | NULL | NULL | COL2가 NULL |
| 2 | NULL | 15 | NULL | COL1이 NULL |
| 3 | 30 | 25 | 55 | 둘 다 존재 |

| 표현 | 계산 과정 | 결과 |
| --- | --- | --: |
| `COUNT(COL1)*10` | NULL 제외 개수(2)×10 | 20 |
| `SUM(COL1+COL2)/4` | 행별 결과 중 NULL 제외 합계(55)/4 | 13.75 |
| `SUM(COL2)/2` | NULL 제외 합계(40)/2 | 20 |
| `AVG(COL1)` | NULL 제외 합계(40)/개수(2) | 20 |

| `COL = NULL`의 결과는 FALSE다 | X | 정확히는 UNKNOWN(원칙·예외 혼동, D10) | `COL = NULL`의 결과는 UNKNOWN이다 |

## 5. 자가 점검

표와 결정 트리를 가린 상태에서 답한다. 정답만 쓰지 말고 판정 기준을 한 문장으로 함께 제시할 것.

1. (핵심개념설명형) NULL이란 무엇이며 숫자 0, 공백과 어떻게 다른가?
2. (핵심개념설명형) 3값 논리(TRUE/FALSE/UNKNOWN)란 무엇이며 WHERE 절은 어떤 값일 때만 행을 통과시키는가?
3. (유사개념구별형) `COL = NULL`과 `COL IS NULL`은 결과가 어떻게 다른가?
4. (유사개념구별형) 산술연산에서 NULL이 "전파"되는 것과 집계함수가 NULL을 "제외"하는 것은 어떻게 다른가?
5. (사례판정형) IE 표기법으로만 그려진 ERD를 보고 특정 속성이 NULL을 허용하는지 알 수 있는가? 그 이유는?
6. (사례판정형 — NULL 산술 vs 집계 계산 사례) SAMPLE 테이블 COL1(10, NULL, 30), COL2(NULL, 15, 25)에서 `SUM(COL1+COL2)`와 `SUM(COL1)+SUM(COL2)`를 각각 계산하고 왜 값이 다른지 설명하시오.
7. (사례판정형) 같은 SAMPLE 테이블에서 `COUNT(*)`와 `COUNT(COL1)`의 값을 각각 구하고 그 차이가 나는 이유를 설명하시오.
8. (반복오답교정형) "집계함수는 NULL이 있으면 결과도 NULL이 된다"는 문장의 어디가 틀렸는지 지적하고 올바른 문장으로 고치시오.
9. (결정트리재현형) 아래 빈칸을 채우시오.

```text
NULL이 어디에 사용됐는가?
├─ 일반 비교 → (        )
├─ IS NULL → (        )
├─ 산술 → (        )
└─ 집계
   ├─ COUNT(*) → (        )
   └─ COUNT(col), SUM, AVG → (        )
```

10. (결정트리재현형) 표·계산형 문제 풀이 순서의 빈칸을 채우시오.

```text
원본 표 재작성 → (        , NULL 전파 여부) → (        , NULL 제외 여부·COUNT(*) 예외) → 선지별 결과 비교
```

<details>
<summary>자가 점검 정답</summary>

1. NULL은 값이 존재하지 않거나 아직 정해지지 않은 상태이며, 0(숫자값)·공백(문자값)과 달리 "값 자체가 없다"는 상태를 나타낸다 — 판정 기준: 선지가 NULL을 특정 값으로 치환해 서술하면 값·상태 혼동이다.
2. 3값 논리는 조건식의 결과가 TRUE·FALSE·UNKNOWN 중 하나가 되는 체계이며, WHERE 절은 TRUE인 행만 통과시키므로 UNKNOWN(NULL 관여)과 FALSE는 결과에서 함께 제외된다 — 판정 기준: "UNKNOWN=FALSE"라고 단정하면 서로 다른 값을 같다고 뭉뚱그린 것이므로, "WHERE 통과 여부는 같지만 값 자체는 다르다"는 점을 구분해야 한다.
3. `COL = NULL`은 일반 비교연산이라 결과가 항상 UNKNOWN(0건)이고, `COL IS NULL`은 NULL 상태를 정상적으로 판별하는 전용 연산자다 — 판정 기준: NULL 여부 판단에는 반드시 `IS NULL`을 써야 한다.
4. 산술연산은 NULL이 하나라도 섞이면 결과 전체가 NULL로 오염되는 전파형이고, 집계함수는 NULL을 계산 대상에서 빼고 나머지 값만으로 계산하는 배제형이다 — 판정 기준: 같은 컬럼이라도 연산 종류(산술 vs 집계)에 따라 처리 방식이 정반대다.
5. 알 수 없다 — IE 표기법은 애초에 NULL 허용 여부를 표기하는 관례가 없기 때문이다(Barker만 o/*로 표시) — 판정 기준: "IE로도 NULL 여부를 확인할 수 있다"는 서술은 표기법 혼동이다.
6. `SUM(COL1+COL2)`는 행별로 먼저 더한 뒤(1행 NULL, 2행 NULL, 3행 55) NULL인 행을 제외하고 합산해 55다. `SUM(COL1)+SUM(COL2)`는 각 열에서 NULL을 각각 제외한 뒤(SUM(COL1)=40, SUM(COL2)=40) 합산해 80이다 — 판정 기준: 행별 산술을 먼저 하느냐, 열별 집계를 먼저 하느냐에 따라 NULL이 제외되는 시점이 달라 값이 달라진다.
7. `COUNT(*)`는 NULL과 무관하게 행 자체를 세므로 3이고, `COUNT(COL1)`은 COL1이 NULL인 2행을 제외하므로 2다 — 판정 기준: `COUNT(*)`는 행의 존재, `COUNT(컬럼)`은 해당 컬럼이 NULL이 아닌 행의 개수를 센다.
8. "집계함수는 NULL이 있으면 결과도 NULL이 된다"는 산술연산의 전파 규칙을 집계함수에 잘못 적용한 것이다 — 올바른 문장: "집계함수는 NULL을 제외하고 나머지 값만으로 계산한다." 판정 기준: NULL이 있는 컬럼에 집계함수를 적용해도 결과 자체가 NULL이 되지는 않는다.
9. 빈칸 정답(위에서부터): UNKNOWN / TRUE 또는 FALSE / 결과 NULL(전파) / 행 전체(NULL 무관) / NULL 제외 — 판정 기준: 비교는 진리값(UNKNOWN 포함), 산술은 값의 전파, 집계는 COUNT(*)만 예외로 NULL 무관.
10. 빈칸 정답: 행별 산술(1단계) / 집계 계산(2단계) — 판정 기준: 산술연산의 NULL 전파 여부를 먼저 따진 뒤, 그 결과를 바탕으로 집계함수의 NULL 제외 여부(COUNT(*) 예외)를 따진다.

</details>

**문제 8 행별 계산표** (SAMPLE 테이블: COL1(10, NULL, 30), COL2(NULL, 15, 25))

| 행 | COL1 | COL2 | `COL1+COL2` |
| --: | --: | --: | --: |
| 1 | 10 | NULL | NULL |
| 2 | NULL | 15 | NULL |
| 3 | 30 | 25 | 55 |

`COUNT(COL1)*10` = 2×10 = 20, `SUM(COL1+COL2)/4` = 55/4 = 13.75, `SUM(COL2)/2` = 40/2 = 20, `AVG(COL1)` = 40/2 = 20 — 행별 산술(1단계)에서 NULL이 포함된 행이 먼저 제외되고, 그 다음 집계(2단계)에서 다시 NULL이 제외되는 두 단계를 거쳐야 정확한 값이 나온다.
