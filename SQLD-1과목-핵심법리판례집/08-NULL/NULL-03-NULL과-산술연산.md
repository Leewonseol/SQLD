# [NULL-03] NULL과 산술연산

> [!IMPORTANT]
> **핵심 법리:**
> NULL이 산술연산(`+`, `-`, `*`, `/`)의 피연산자로 사용되면 결과는 항상 NULL이 된다. 이를 "NULL의 전파(propagation)"라 하며, 다른 피연산자가 어떤 값이든 상관없이 NULL이 하나라도 섞이면 전체 계산 결과가 NULL로 오염된다. NULL을 특정 값으로 치환해 연산에서 제외하고 싶다면 `NVL`(또는 `COALESCE`, `ISNULL` 등)과 같은 NULL 처리 함수를 사용해야 한다.
>
> [!TIP]
> **정답을 가르는 사실:**
> 선지가 "NULL이 포함된 산술식의 결과"를 묻는지 확인한다. NULL과의 산술연산은 0을 더한 것처럼 원래 값이 그대로 나오는 것이 아니라, 결과 전체가 NULL이 된다.
>
> [!WARNING]
> **반복 오답:**
> "NULL은 산술연산에서 0으로 취급된다"는 함정(`100 + NULL`을 100으로 착각), NULL이 포함된 식의 결과를 오류(에러)로 서술하는 함정(실제로는 오류가 아니라 NULL이라는 정상적인 결과), NVL 없이도 NULL이 자동으로 무시된다고 서술하는 함정.

## 1. 판시사항

- NULL이 산술연산의 피연산자로 사용되면 결과는 무엇인가?
- NULL이 섞인 산술연산 결과를 원하는 값으로 제어하려면 어떤 함수를 사용하는가?

## 2. 핵심 법리

> NULL은 "정해지지 않은 값"이므로, 어떤 값에 NULL을 더하거나 빼거나 곱해도 그 결과 역시 "정해지지 않은 값", 즉 NULL이 된다. 이것이 NULL의 전파 원칙이다. 예를 들어 `SELECT 100 + NULL FROM DUAL;`의 결과는 100도 아니고 오류도 아닌 NULL이다. 산술연산에서 NULL을 0 등 특정 값으로 치환해 계산에 포함시키고 싶다면 `NVL(컬럼, 대체값)`과 같은 NULL 처리 함수로 명시적으로 변환해야 한다.

## 3. 법리 적용 분기

```text
NULL이 포함되어 있는가?
│
├─ 일반 산술 연산(+, -, *, /)의 피연산자로 사용됨
│  └─ 결과 NULL(전파)
│
├─ NVL/COALESCE 등으로 사전에 치환됨
│  └─ 치환된 값으로 정상 계산됨(NULL 전파 차단)
│
└─ 비교 연산 / 집계함수의 입력으로 사용됨
   └─ NULL-02(비교연산→UNKNOWN), NULL-04(집계함수→제외) 법리 적용
```

## 4. 이 문제들이 유사한 이유

| 기준 | 내용 |
| --- | --- |
| 공통 핵심 법리 | NULL이 산술연산의 피연산자가 되면 결과 전체가 NULL로 전파된다는 동일한 판단 규칙 |
| 공통 결정 사실 | 선지·SQL에 `+`, `-`, `*`, `/` 같은 산술 연산자가 NULL을 포함한 컬럼/값에 직접 적용되는지 |
| 반복되는 오답 구조 | NULL을 0처럼 취급해 결과를 다른 피연산자의 값으로 서술(D9 값·상태 혼동), NULL 포함 연산을 오류로 서술 |

### 사실관계

`SELECT 100 + NULL FROM DUAL;`을 실행했을 때의 결과값을 묻는 질문에 4개 선지가 제시된다.

### 쟁점

숫자 100과 NULL을 더한 산술연산의 결과가 100인지, 0인지, 오류인지, NULL인지가 쟁점이다.

### 적용 법리

NULL은 산술연산에서 전파되므로, 다른 피연산자가 100이라는 구체적인 값이라도 결과는 NULL이 된다.

### 주문

**정답: ③ (NULL)**

### 판결이유

```text
문제의 결정적 사실: 100이라는 값에 NULL을 더하는 산술연산이 수행됨
→ 적용되는 핵심 법리: NULL이 산술연산에 관여하면 결과는 항상 NULL로 전파된다
→ 정답 선지: ③ NULL(다른 피연산자의 값과 무관하게 결과가 NULL로 오염됨)
```

## 9. 출제자가 바꾸는 사실

- NULL을 산술연산에서 0처럼 취급해 원래 값이 그대로 나온다고 서술
- NULL이 포함된 산술연산의 결과를 "오류(에러)"로 서술
- NVL 등 명시적 치환 없이도 NULL이 자동으로 무시되고 계산된다고 서술
- 산술연산(NULL-03, 결과 NULL)과 집계함수(NULL-04, NULL 제외 후 계산)의 처리 방식을 뒤바꿔 서술

## 10. 시험용 한 줄 법리

> NULL이 산술연산에 하나라도 섞이면 결과는 무조건 NULL — 값을 살리려면 NVL로 먼저 치환한다.
