# [NULL-04] NULL과 집계함수

> [!IMPORTANT]
> **핵심 법리:**
> `SUM`, `AVG`, `MAX`, `MIN`, `COUNT(컬럼)` 같은 집계함수는 계산 대상 컬럼에 NULL이 있으면 그 NULL 값을 제외하고 나머지 값만으로 집계한다. 단 `COUNT(*)`는 예외로, 컬럼 값이 NULL이든 아니든 행 자체가 존재하면 그대로 카운트하므로 NULL의 영향을 받지 않는다.
>
> [!TIP]
> **정답을 가르는 사실:**
> 선지가 `COUNT(*)`를 묻는지 `COUNT(컬럼)`을 묻는지 정확히 구분한다. "NULL이 포함되어도 영향을 받지 않는 집계함수"의 정답은 `COUNT(*)`이며, `COUNT(컬럼)`·`SUM`·`AVG`는 모두 NULL인 행을 제외하고 계산하므로 NULL의 유무에 따라 결과(카운트 수·합계·평균)가 달라진다.
>
> [!WARNING]
> **반복 오답:**
> `COUNT(*)`와 `COUNT(컬럼)`을 서로 바꿔 서술하는 함정(D8 행·열 혼동), "집계함수는 NULL을 0으로 계산한다"는 함정(실제로는 NULL을 계산 대상에서 제외하는 것이지 0으로 치환하는 것이 아니다), "집계함수는 NULL이 있으면 결과도 NULL이 된다"고 산술연산의 전파 규칙을 집계함수에 잘못 적용하는 함정.

## 1. 판시사항

- 집계함수는 NULL 값을 어떻게 처리하는가?
- 여러 집계함수 중 NULL의 존재 여부와 무관하게 항상 같은 결과를 내는 것은 무엇인가?

## 2. 핵심 법리

> `SUM`, `AVG`, `MAX`, `MIN`, `COUNT(컬럼)`은 대상 컬럼 값이 NULL인 행을 집계 계산에서 제외한다 — NULL을 0으로 바꿔 계산하는 것이 아니라, 아예 "없는 값"으로 취급해 빼고 계산한다는 뜻이다. 반면 `COUNT(*)`는 컬럼 값을 보지 않고 행의 존재 여부만 세므로, 어떤 컬럼이 NULL이든 아니든 관계없이 행이 있으면 그대로 카운트된다. 이 때문에 "NULL이 포함되어도 결과가 영향받지 않는 집계함수"를 고르라는 문제의 정답은 항상 `COUNT(*)`이다.

## 3. 법리 적용 분기

```text
NULL이 포함되어 있는가?
│
├─ 일반 산술 연산
│  └─ 결과 NULL(NULL-03 법리)
│
├─ 일반 비교 연산
│  └─ 결과 UNKNOWN(NULL-02 법리)
│
└─ 집계함수의 입력
   ├─ SUM / AVG / MAX / MIN / COUNT(컬럼)
   │  └─ 해당 NULL 값을 제외하고 나머지 값만으로 계산
   └─ COUNT(*)
      └─ 예외적으로 NULL 여부와 무관하게 행 자체를 그대로 카운트
```

## 4. 이 문제들이 유사한 이유

| 기준 | 내용 |
| --- | --- |
| 공통 핵심 법리 | 집계함수는 NULL을 제외하고 계산하되, `COUNT(*)`만은 예외적으로 NULL의 영향을 받지 않는다는 동일한 판단 규칙 |
| 공통 결정 사실 | 문제에 `COUNT(*)`와 `COUNT(컬럼)` 중 어느 것이 쓰였는지, 또는 "NULL이 결과에 영향을 주는가/안 주는가"를 묻는지 |
| 반복되는 오답 구조 | `COUNT(*)`와 `COUNT(컬럼)`을 맞바꿔 서술(D8), NULL을 0으로 치환해서 계산한다고 서술(D9) |
| 정답이 달라지는 조건 | 같은 컬럼이라도 산술연산의 대상(`COL1+COL2`)이면 NULL-03, 집계함수의 대상(`SUM(COL1)`)이면 NULL-04로 법리가 갈린다 — 이 둘은 NULL 처리 방식이 반대이므로 반드시 구별해야 한다 |

### 사실관계

"NULL값이 포함되어 있어도 그 영향을 받지 않는 집계함수는?"이라는 질문에 4개의 집계함수(또는 집계함수 관련 선지)가 제시된다.

### 쟁점

여러 집계함수 중 어느 것이 NULL의 존재 여부와 무관하게 항상 동일한 방식으로 동작하는지가 쟁점이다.

### 적용 법리

`COUNT(*)`는 컬럼 값을 보지 않고 행의 존재만을 세므로 NULL이 있는 행도 그대로 카운트에 포함시킨다. 반면 나머지 집계함수(`COUNT(컬럼)`, `SUM`, `AVG`, `MAX`, `MIN` 등)는 NULL인 값을 계산에서 제외하므로 NULL의 유무에 따라 결과가 달라진다.

### 주문

**정답: ① COUNT(\*)**

### 판결이유

```text
문제의 결정적 사실: 선지들이 서로 다른 집계함수(COUNT(*) 포함)를 제시함
→ 적용되는 핵심 법리: 집계함수는 NULL을 제외하고 계산하지만, COUNT(*)만은 행의 존재 자체를 세므로 예외다
→ 정답 선지: ① COUNT(*)(NULL 유무와 무관하게 항상 같은 방식으로 행을 카운트)
```

## 8. 구별 판례

| 구별 요소 | 이 사건(NULL-04) | 비교 사건 | 답이 달라지는 이유 |
| --- | --- | --- | --- |
| NULL 처리 방식 | 집계함수 — NULL 값을 계산 대상에서 제외하고 나머지 값만으로 결과를 냄(`COUNT(*)`는 예외) | [NULL-03 NULL과 산술연산](./NULL-03-NULL과-산술연산.md) — 산술연산은 NULL이 하나라도 있으면 결과 전체가 NULL로 전파됨 | 집계함수는 "NULL을 빼고 계산을 진행하는" 배제형 처리이고, 산술연산은 "NULL이 섞이면 결과 자체가 오염되는" 전파형 처리로 정반대다. 예를 들어 `COL1`에 NULL이 있어도 `SUM(COL1)`은 정상적으로 값을 반환하지만, `COL1+COL2`는 그 행에서 NULL로 오염된다 |
| 행 vs 값 | `COUNT(*)`는 행의 존재 자체를 세는 것(값을 보지 않음) | `COUNT(컬럼)`은 해당 컬럼 값이 NULL이 아닌 행만 세는 것 | 같은 COUNT 함수라도 `*`인지 컬럼명인지에 따라 NULL 처리 결과가 달라진다(D8 행·열 혼동의 근원) |

## 9. 출제자가 바꾸는 사실

- `COUNT(*)`와 `COUNT(컬럼)`을 맞바꿔 서술(NULL 영향 여부가 뒤바뀜)
- "집계함수는 NULL을 0으로 치환해서 계산한다"고 서술(실제로는 제외이지 치환이 아님)
- "집계함수도 NULL이 있으면 결과가 NULL이 된다"고 산술연산(NULL-03)의 전파 규칙을 집계함수에 잘못 적용
- SUM/AVG처럼 NULL을 제외하고 계산하는 함수를 마치 COUNT(*)처럼 "NULL 영향 없음"으로 서술

## 10. 시험용 한 줄 법리

> 집계함수는 NULL을 빼고 계산한다 — 예외는 딱 하나, `COUNT(*)`만 NULL이 있어도 행을 그대로 센다.
