## 공부 방법

```text
핵심 개념 비교표 확인(단원 README)
→ 짧은 결정 트리로 판정 순서 익히기
→ 유사 사례 비교로 결론이 갈리는 조건 확인
→ 반복 오답 표로 함정 패턴 확인
→ 필요할 때만 상세 기출 링크에서 대표 판례·선지별 해설 확인
```

## 추천 반복 순서

1. 단원 폴더(01~08)의 `README.md`를 순서대로 열어 "핵심 개념 비교표"만 먼저 훑는다.
2. 같은 README의 "판정 순서"(짧은 결정 트리)로 실제 문제에서 무엇을 먼저 확인하는지 익힌다.
3. "유사 사례 비교"와 "반복 오답" 표를 반복해서 본다.
4. 근거가 더 필요한 개념만 README 하단 "상세 기출 해설" 링크로 이동해 대표 판례·선지별 해설을 확인한다.
5. [99-모의고사-역색인/](./99-모의고사-역색인/)에서 문제번호 대신 법리 ID를 먼저 떠올리는 방식으로 무작위 복습한다.

## 핵심 원칙

> 문제번호가 아니라 핵심 법리를 기억한다.
> 같은 법리가 적용되는 문제는 함께 보고, 답을 바꾸는 결정적 사실만 구별한다.
> 오답은 "틀렸다"가 아니라 무엇을 무엇으로 바꿨는지 설명한다.

## 저작권 처리 원칙

이 판례집은 원본 문제집의 복제본이 아니다. 문제 지문은 판단에 필요한 사실관계만 요약했고, 선지는 핵심 주장만 간결하게 재서술했다. 표·ERD는 구조만 텍스트로 설명했으며, 해설은 이 판례집에서 새로 작성했다. 모든 판례에는 출처·PDF 페이지·원문 문제번호를 표기했다.
