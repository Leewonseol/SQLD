# SQLD 1과목 핵심 법리 판례집

`1과목 기출 모음.pdf`(이기적 단원별 기출문제, 이기적 모의고사 1회, 유선배 적중예상문제, 유선배 기출변형 모의고사 1회, 총 159문항)를 분석해서 만든 학습용 파생 자료다. 문제집 순서가 아니라, 정답을 결정하는 핵심 법리 단위로 문제를 재분류하고 역색인했다.

## 공부 방법

```text
핵심 법리 확인
→ 대표 판례 읽기
→ 선지별 오답 이유 확인
→ 유사 판례 비교
→ 구별 판례 확인
→ 모의고사에서 법리 ID 회상
```

## 추천 반복 순서

1. [00-핵심법리-전체색인.md](./00-핵심법리-전체색인.md)의 "핵심 법리 카드"만 먼저 반복해서 읽는다.
2. 단원 폴더(01~08)를 순서대로 열어 각 법리 파일의 "판시사항"과 "핵심 법리"만 훑는다.
3. 대표 판례의 "주문"과 "판결이유"를 읽고, 결정적 사실 → 법리 → 정답의 흐름을 확인한다.
4. "선지별 판단" 표에서 정답을 가리고 스스로 각 선지를 판정해본 뒤 표와 비교한다.
5. [99-모의고사-역색인/](./99-모의고사-역색인/)에서 문제번호 대신 법리 ID를 먼저 떠올리는 방식으로 무작위 복습한다.

## 핵심 원칙

> 문제번호가 아니라 핵심 법리를 기억한다.
> 같은 법리가 적용되는 문제는 함께 보고, 답을 바꾸는 결정적 사실만 구별한다.
> 오답은 "틀렸다"가 아니라 무엇을 무엇으로 바꿨는지 설명한다.

## 저작권 처리 원칙

이 판례집은 원본 문제집의 복제본이 아니다. 문제 지문은 판단에 필요한 사실관계만 요약했고, 선지는 핵심 주장만 간결하게 재서술했다. 표·ERD는 구조만 텍스트로 설명했으며, 해설은 이 판례집에서 새로 작성했다. 모든 판례에는 출처·PDF 페이지·원문 문제번호를 표기했다.
