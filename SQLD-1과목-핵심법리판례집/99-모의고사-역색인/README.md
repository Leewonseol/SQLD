# SQLD 1과목 혼합 회독

이 문서는 단원별 학습이 끝난 뒤, 문제번호가 아니라 법리 ID를 먼저 떠올리는 훈련을 위한 혼합 세트다. 법리 ID는 `<details>`로 가려져 있으니, 먼저 결정적 사실만 보고 법리 ID와 판정을 떠올린 뒤 펼쳐서 확인한다.

## 사용 방법

1. 표의 "결정적 사실" 칸만 먼저 읽고, 어떤 법리 ID(예: NORM-03, ERD-01)에 해당하는 문제인지 먼저 떠올린다.
2. 문제유형(옳은 것 / 옳지 않은 것 / 조합선지형 / 정답형)을 함께 고려해 O·X 또는 정답 극성을 판정해본다.
3. `<details>`를 펼쳐 정답·주 법리 ID(및 보조 법리 ID)·간단한 판정 근거를 확인한다.
4. 틀렸거나 헷갈렸다면 판례 파일 링크로 이동해 해당 단원 README의 "반복오답" 표와 결정트리를 다시 확인한다.
5. 같은 세트를 하루 이상 지난 뒤 `<details>`를 펼치지 않고 다시 풀어, 법리 ID 회상 속도가 개선됐는지 확인한다.

## 세트 구성 메모

- 8개 세트, 세트당 10문항, 총 80문항(159문항 중 중복 없이 선별).
- 세트마다 01(총론)~08(NULL) 8개 단원을 모두 걸치도록 구성했고, 정규화(06)·ERD/관계(04)·NULL(08) 단원은 세트마다 3개 모두 포함된다.
- 세트 내 동일 법리 ID는 최대 2회로 제한했다(예: 세트1의 ID-02, 세트8의 ERD-01·REL-01).
- 조합선지형(보조 법리 ID 존재) 문항을 세트마다 2~3개씩 배치해 단일 개념 판별과 복합 판별을 모두 훈련하도록 했다.
