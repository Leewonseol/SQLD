# [NORM-02] 제1정규형(도메인 원자성, 반복그룹 제거)

> [!IMPORTANT]
> **핵심 법리:**
> 제1정규형(1NF)은 테이블의 모든 속성이 더 이상 나눌 수 없는 단일 값(원자값)만 가져야 한다는 도메인 원자성 조건이며, 번호가 붙어 반복되는 컬럼이나 한 속성에 여러 값이 들어있는 다중값 속성은 1NF 위반으로 별도 엔터티로 분리해야 한다.
>
> [!TIP]
> **정답을 가르는 사실:**
> "속성1, 속성2, 속성3"처럼 같은 의미의 컬럼이 번호를 붙여 반복되거나, 한 칸에 여러 값이 동시에 들어있는지를 확인한다. 반복그룹이 있으면 별도 엔터티로 분리해 1:M 관계로 연결해야 1NF를 만족한다.
>
> [!WARNING]
> **반복 오답:**
> 반복그룹 제거를 2차·3차 정규화 작업으로 서술하는 함정(D5 단계혼동), 컬럼 개수만 줄이면 해결된다는 식으로 별도 엔터티 분리 없이 처리하는 조건 누락(D3), 도메인 원자성 확보를 후보키 도출 기준과 혼동하는 함정.

## 1. 판시사항

- 제1정규형이 되기 위한 조건은 무엇인가?
- 반복되는 컬럼(속성1, 속성2, 속성3)이 존재하는 테이블을 1NF로 만들려면 어떻게 분해해야 하는가?

## 2. 핵심 법리

> 제1정규형(1NF)은 테이블의 모든 속성이 더 이상 나눌 수 없는 단일 값(원자값)만 가져야 한다는 도메인 원자성 조건을 말한다. 한 속성에 여러 값이 들어있거나(다중값 속성), 같은 성격의 값을 담기 위해 속성을 번호 붙여 반복시킨 컬럼(연락처1/연락처2, 배송지1/배송지2/배송지3 등)은 모두 1NF 위반이다. 이를 해소하려면 반복되는 속성을 별도의 엔터티로 분리하고, 원래 엔터티와 1:M 관계(주로 식별관계)로 연결하여 반복 횟수에 제한 없이 값을 저장할 수 있게 해야 한다.

## 3. 법리 적용 분기

```text
1NF 위반 여부 판별
│
├─ 한 속성(칸)에 여러 값이 동시에 들어있는가?
│  └─ 다중값 속성 → 1NF 위반
│
├─ 같은 의미의 컬럼이 번호를 붙여 반복되는가(연락처1,2 / 배송지1,2,3)?
│  └─ 반복그룹 → 1NF 위반
│
└─ 위 두 경우 모두 아니고 모든 속성이 원자값인가?
   └─ 1NF 충족 → 2NF 단계(부분함수종속 여부) 검토로 진행
```

## 4. 이 문제들이 유사한 이유

| 기준 | 내용 |
| --- | --- |
| 공통 핵심 법리 | 반복그룹/다중값 속성을 원자값 단위로 분해해 별도 엔터티로 만드는 동일한 판단 규칙 |
| 공통 결정 사실 | 지문에 "속성1, 속성2, 속성3" 같은 번호매김 반복 컬럼이나 "여러 값이 한 칸에" 라는 서술이 있는지 |
| 반복되는 오답 구조 | 반복그룹 제거를 2차·3차 정규화 작업으로 서술(D5), 엔터티 분리 없이 컬럼만 줄이는 조건 누락(D3) |
| 정답이 달라지는 조건 | 문제되는 종속관계가 "반복그룹의 존재"인지 "주식별자 일부에 대한 종속"인지에 따라 1NF와 2NF 문제가 갈린다 |

### 사실관계

회원 테이블 안에 배송지1, 배송지2, 배송지3처럼 번호가 붙은 반복 컬럼이 존재하는 데이터모델이 제시되고, 이를 정규화한 결과로 가장 바람직한 것을 고르는 문제다. 정답 선지는 회원 엔터티와 배송지 엔터티를 1:M 관계로 분리하고, 배송지 엔터티의 주식별자를 배송지순번+회원번호(FK)로 구성한 식별관계(실선)로 표현한 것이다.

### 쟁점

번호 붙은 반복 컬럼(배송지1,2,3)을 어떻게 원자값 구조로 재설계해야 도메인 원자성을 만족하는지가 쟁점이다.

### 적용 법리

반복그룹은 별도 엔터티로 분리하고, 원래 엔터티(회원)와 1:M 관계로 연결해야 배송지 개수에 제한 없이 저장할 수 있다. 분리된 배송지 엔터티는 회원 없이 독립적으로 존재할 이유가 없으므로 회원번호를 포함한 식별관계로 설계하는 것이 타당하다.

### 주문

**정답: ③**

### 판결이유

```text
문제의 결정적 사실: 회원 테이블에 배송지1,배송지2,배송지3처럼 번호 붙은 반복 컬럼이 존재함
→ 적용되는 핵심 법리: 반복그룹은 별도 엔터티로 분리해 1:M 관계로 연결해야 도메인 원자성(1NF)을 만족한다
→ 정답 선지: ③(배송지 엔터티를 분리하고 배송지순번+회원번호로 식별관계 구성)
```
