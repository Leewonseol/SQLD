# [ERD-02] ERD 작성 순서

> [!IMPORTANT]
> **핵심 법리:**
> ERD는 "엔터티 도출 → 엔터티 배치 → 관계선 연결 → 관계명 작성 → 관계차수(카디널리티) 표현 → 관계선택성(참여도) 표시"의 순서로 작성한다. 무엇이 있는지를 먼저 정하고, 점차 관계를 구체화해 나가는 순서다.
>
> [!TIP]
> **정답을 가르는 사실:**
> 선지가 제시하는 순서에서 "엔터티 도출"이 맨 앞에 있는지, "관계선택성(필수/선택) 표시"가 맨 뒤에 있는지 확인한다. 관계명 작성은 관계선을 그은 뒤, 차수·선택성 표시보다 앞선다.
>
> [!WARNING]
> **반복 오답:**
> 6단계의 순서를 임의로 뒤섞어 제시하는 함정, 엔터티 배치 단계를 건너뛰고 도출 다음 바로 관계선 연결로 넘어가는 것처럼 서술하는 함정.

## 1. 판시사항

- ERD를 작성할 때 엔터티 도출부터 관계선택성 표시까지는 어떤 순서로 진행되는가?

## 2. 핵심 법리

> ERD 작성은 "① 엔터티 도출(무엇이 있는가) → ② 엔터티 배치(어디에 둘 것인가) → ③ 관계선 연결(엔터티끼리 어떻게 이어지는가) → ④ 관계명 작성(그 관계를 뭐라고 부르는가) → ⑤ 관계차수 표현(몇 대 몇인가: 1:1/1:N/M:N) → ⑥ 관계선택성 표시(필수참여인가 선택참여인가)"의 순서로 진행된다. 존재(엔터티)를 먼저 정하고 관계를 점점 구체화해 나가는 흐름이다.

## 3. 법리 적용 분기

```text
ERD 작성 단계의 순서를 묻는 문제인가?
│
1. 엔터티 도출 (무엇이 있는가)
2. 엔터티 배치 (어디에 둘 것인가)
3. 관계선 연결 (엔터티끼리 어떻게 이어지는가)
4. 관계명 작성 (그 관계를 뭐라고 부르는가)
5. 관계차수(카디널리티) 표현 (몇 대 몇인가: 1:1/1:N/M:N)
6. 관계선택성(참여도) 표시 (필수참여인가 선택참여인가)
│
└─ 위 순서가 뒤바뀌어 제시된 선지 → 오답
```

## 4. 이 문제들이 유사한 이유

| 기준 | 내용 |
| --- | --- |
| 공통 핵심 법리 | ERD는 "엔터티 → 배치 → 관계선 → 관계명 → 차수 → 선택성"의 6단계로 상세화되며, 이 순서 자체가 판단 규칙이다 |
| 공통 결정 사실 | 지문에 제시된 기호(ㄱㄴㄷ 등) 나열 순서가 실제로 "엔터티 도출이 가장 먼저, 선택성 표시가 가장 나중"인 순서와 일치하는지 |
| 반복되는 오답 구조 | 6단계 순서를 임의로 뒤섞어 제시(D5 단계 혼동 — 모델링·정규화 단계뿐 아니라 작업 절차의 순서 교환에도 동일하게 적용) |
| 정답이 달라지는 조건 | 같은 6개 단계라도 나열 순서(기호 배열)가 다르면 오답이 되므로, 각 선지의 기호 배열을 실제 순서와 하나씩 대조해야 한다 |

### 사실관계

"ERD 작성 순서로 올바른 것은?"이라는 질문에 4개 선지가 제시되며, 각 선지는 "엔터티 도출, 엔터티 배치, 관계선 연결, 관계명 작성, 관계차수 표현, 관계선택성 표시"라는 6개 작업을 기호(ㄱ~ㅂ)로 표시해 서로 다른 순서로 나열한 것이다.

### 쟁점

6개 작업이 실제로 어떤 순서로 진행되어야 하는지가 쟁점이다.

### 적용 법리

ERD는 "무엇이 있는가(엔터티)"를 먼저 정하고, 이를 지면에 배치한 뒤 관계선으로 연결하고, 그 관계에 이름을 붙이고, 마지막으로 관계의 정량적 성격(차수)과 정성적 성격(선택성)을 표시하는 순서로 상세화된다.

### 주문

**정답: ③**

### 판결이유

```text
문제의 결정적 사실: 선지 ③이 "엔터티 도출 → 배치 → 관계선 연결 → 관계명 작성 → 관계차수 표현 → 관계선택성 표시" 순서(ㄹ→ㄷ→ㄱ→ㅂ→ㄴ→ㅁ)를 제시함
→ 적용되는 핵심 법리: ERD는 엔터티(존재)를 먼저 정하고 관계를 점차 구체화(선 → 이름 → 차수 → 선택성)하는 순서로 작성한다
→ 정답 선지: ③(6단계 배열이 실제 작성 순서와 일치)
```
