SQLD 1과목 NULL 계산훈련 문제

인쇄 권장: A4 · 배율 100% · 머리글/바닥글 끄기

NULL은 개념 설명이 아니라 직접 계산해봐야 몸에 붙습니다 — 표를 보고 실제 결과값을 계산한 뒤 선지를 고르세요

문항 1~9는 표준 SQL의 일반적인 NULL 규칙을 전제로 한다. 문항 10은 Oracle의 NVL 함수를 사용한다. 해설은 행별 연산 → WHERE 판정 → 집계 순서로 확인한다.

쿼리: SELECT 부서코드, COUNT(*) FROM 사원 GROUP BY 부서코드

위 쿼리의 결과로 옳은 것은?

  1. ①D01 그룹만 나오고, 부서코드가 NULL인 두 행은 결과에서 완전히 빠진다.
  2. ②D01 그룹(2건)과 NULL 그룹(2건), 총 2개 그룹
  3. ③NULL인 행은 각각 별개의 그룹으로 나뉘어 두 개의 NULL 그룹이 나온다.
  4. ④NULL이 하나라도 있으면 GROUP BY 자체가 오류를 낸다.
  5. ⑤D01, NULL, NULL, NULL 네 그룹으로 나뉜다.
문항 10NVL/치환
보기
행보너스
1100
2NULL

쿼리: SELECT SUM(NVL(보너스, 0)) FROM 급여

Oracle에서 위 쿼리를 실행했을 때 결과값으로 옳은 것은?

  1. ①NULL — NVL을 써도 원래 NULL이었던 값은 집계에 반영되지 않는다.
  2. ②100
  3. ③0 — NVL을 쓰면 전체 결과가 0으로 초기화된다.
  4. ④200 — NVL이 NULL을 100으로 자동 대체한다.
  5. ⑤오류 — NVL은 집계함수 안에서 사용할 수 없다.
