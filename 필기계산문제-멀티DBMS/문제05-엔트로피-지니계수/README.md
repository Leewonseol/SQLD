# 문제 05. 엔트로피 · 지니계수 (의사결정나무 분할기준)

## 필기 예상문제 (재현)

> 어떤 노드에 속한 10개 데이터의 클래스 분포가 Yes 8개, No 2개다. 이 노드의
> **엔트로피**와 **지니계수**를 구하시오.

## 손계산

- `p_yes = 0.8`, `p_no = 0.2`
- 엔트로피 `Entropy = -Σ pᵢ log₂ pᵢ = -(0.8×log₂0.8 + 0.2×log₂0.2)`
  - `log₂0.8 ≈ -0.32193`, `log₂0.2 ≈ -2.32193`
  - `Entropy = -(0.8×(-0.32193) + 0.2×(-2.32193)) = -(-0.25754 - 0.46439) = 0.72193`
- 지니계수 `Gini = 1 - Σ pᵢ² = 1 - (0.8² + 0.2²) = 1 - 0.68 = 0.32`

## 4-DBMS 문법 비교: `LOG` 함수가 가장 위험한 함정 중 하나

인수 1개짜리 `LOG(x)`가 **몇 진 로그인지**가 DBMS마다 다르다 — 이 저장소에서 실제로
실행해 확인했다.

| 표현 | Oracle | SQL Server | MySQL/MariaDB | DuckDB | SQLite |
|---|---|---|---|---|---|
| `LOG(x)` (인수 1개) | 없음(`LOG(b,x)`만 지원) | 자연로그(ln) | **자연로그(ln)** | **상용로그(log₁₀)** | **상용로그(log₁₀)** |
| 밑을 지정한 로그 | `LOG(b, x)` (밑이 먼저) | `LOG(x, b)` (**숫자가 먼저, 밑이 나중** — 순서 반대!) | `LOG(b, x)` (밑이 먼저) | `LOG(b, x)` 또는 `log2(x)` | `LOG(b, x)` (3.38+, 밑이 먼저) |

실측 결과(이 세션에서 직접 실행):
- SQLite `LOG(0.8)` → `-0.0969...`(log₁₀), `LOG(2, 0.8)` → `-0.32193`(log₂)
- DuckDB `log(0.8)` → `-0.0969...`(log₁₀), `log2(0.8)` → `-0.32193`
- MariaDB `LOG(0.8)` → `-0.2231...`(**자연로그** — SQLite/DuckDB와 다른 값!),
  `LOG2(0.8)` → `-0.32193`

**결론**: 엔트로피 공식처럼 밑이 2로 고정된 계산에서는 인수 1개짜리 `LOG(x)`를 그대로
쓰면 안 된다. `LOG2(x)`(MySQL 계열) 또는 `LOG(2, x)`(SQLite/DuckDB/Oracle — 단,
SQL Server는 인수 순서가 반대이므로 `LOG(x, 2)`)처럼 밑을 명시해야 한다.
