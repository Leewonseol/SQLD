# 문제 06. 표준화(Z-score) · 정규화(Min-Max)

## 필기 예상문제 (재현)

> [문제01]의 5개 매장 매출액(12, 15, 11, 18, 14)을 각각 (1) Z-score로 표준화하고,
> (2) Min-Max 방법으로 0~1 사이 값으로 정규화하시오.

## 손계산

- [문제01]에서 `x̄=14`, 모표준편차 `σ≈2.449`
- Z-score: `z = (x - x̄) / σ`
  - A(12): `(12-14)/2.449 ≈ -0.816`
  - D(18): `(18-14)/2.449 ≈ 1.633`
  - E(14): `(14-14)/2.449 = 0`
- Min-Max: `x' = (x - min) / (max - min)`, `min=11`, `max=18`
  - A(12): `(12-11)/7 ≈ 0.143`
  - D(18): `(18-11)/7 = 1.0`(최댓값은 항상 1)
  - C(11): `(11-11)/7 = 0`(최솟값은 항상 0)

## SQL 구현 방식: 윈도우 함수로 "표 전체를 한 번에" 변환

이 문제는 그룹 집계가 아니라 **행 단위 변환**이므로 `GROUP BY`가 아니라
`AVG(x) OVER ()`, `MIN(x) OVER ()`, `MAX(x) OVER ()`처럼 **파티션 없는 윈도우 함수**로
"전체 평균/최소/최대를 모든 행에 동일하게 broadcast"하는 방식을 쓴다. 이 저장소의
[[윈도우 함수]] 개념 노트와 같은 원리다.

| 항목 | Oracle | SQL Server | MySQL/MariaDB | DuckDB | SQLite |
|---|---|---|---|---|---|
| 윈도우 함수 자체 | 지원 | 지원 | 지원(10.2+) | 지원 | 지원(3.25+) |
| `STDDEV_POP(x) OVER()`처럼 통계함수를 윈도우로 사용 | 가능 | 가능 | **가능**(직접 확인) | **가능**(직접 확인) | **불가**(내장 STDDEV 자체가 없음 → `01-PCA`처럼 수식을 윈도우로 직접 전개) |
