# 문제 03. 단순선형회귀 계수(정규방정식)

## 필기 예상문제 (재현)

> [문제02]와 같은 자료(광고비 X, 매출액 Y, n=5)를 이용해 회귀직선 `Y = β0 + β1X`의
> 계수 `β0`(절편), `β1`(기울기)을 최소제곱법으로 구하시오. 광고비가 6일 때 매출액을
> 예측하시오.

## 손계산

- 최소제곱 정규방정식: `β1 = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)²`, `β0 = ȳ - β1·x̄`
- [문제02]에서 `Σ(x-x̄)(y-ȳ)/n = 1.2`(공분산), `Σ(x-x̄)²/n = 2`(x의 분산) 이미 계산함
  → 두 값 모두 `/n`이 붙어 있으므로 비율을 취하면 `n`이 상쇄된다.
- `β1 = 1.2 / 2 = 0.6`
- `β0 = 4 - 0.6 × 3 = 2.2`
- 회귀식: `Ŷ = 2.2 + 0.6X`
- `X=6` 예측: `Ŷ = 2.2 + 0.6×6 = 5.8`

## 4-DBMS 문법 비교

| 항목 | Oracle | SQL Server | MySQL/MariaDB | DuckDB | SQLite |
|---|---|---|---|---|---|
| 회귀계수 내장함수 | `REGR_SLOPE(y,x)`, `REGR_INTERCEPT(y,x)` | 없음(직접 계산) | **없음**(직접 계산) | `REGR_SLOPE(y,x)`, `REGR_INTERCEPT(y,x)` | 없음(직접 계산) |
| 결정계수 | `REGR_R2(y,x)` | 없음 | 없음 | `REGR_R2(y,x)` | 없음 |

**함정 포인트**: `REGR_*` 계열 집계함수는 Oracle과 DuckDB에만 있다. 이 두 엔진에서는
회귀분석 문제를 SQL 한 줄로 풀 수 있지만, SQL Server·MySQL 계열·SQLite에서는 필기에서
외운 정규방정식 공식을 그대로 SQL로 옮겨야 한다 — 이는 "SQL로 회귀를 돌린다"는 말이
DBMS에 따라 완전히 다른 난이도의 작업임을 보여준다(그리고 `분석기법/05-회귀분석`에서
다중회귀를 Python에 맡긴 이유이기도 하다: 변수가 여러 개로 늘어나면 이 수식 전개 방식은
급격히 복잡해진다).
