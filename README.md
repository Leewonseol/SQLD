# SQLD

SQL개발자(SQLD)·빅데이터분석기사 시험 대비용 개념·기출·오답 노트 및 통합 실습 저장소.

## 최종 목표

> 빅데이터분석기사 필기의 계산형 예상문제를 SQL로 재현하고, Oracle·SQL Server·MySQL·
> DuckDB의 문법과 결과 차이를 체험하며, Olist 고객 데이터를 중심으로 SQL 전처리·집계·
> 분석 테이블을 구축한 뒤, 실기 범위의 통계·머신러닝 기법을 Python/R로 실행하고
> 그 결과를 다시 SQL로 검산하는 통합 학습 환경을 구축한다.

이 목표를 아래 세 실습 폴더가 나눠서 담당한다.

- `Concepts/` — SQL 개념 노트 (Zettelkasten 스타일)
- `Questions/` `Propositions/` — 모의고사 문항·선지 해설
- `_원본 자료/` — 원본 마인드맵·정리 자료
- [`필기계산문제-멀티DBMS/`](./필기계산문제-멀티DBMS/README.md) — 필기 계산형 예상문제를
  SQL로 재현하고, SQLite·DuckDB·MariaDB(MySQL 호환) 세 엔진에 **실제로 실행**해 결과와
  문법 차이를 확인한다. Oracle·SQL Server는 이 샌드박스에서 실행할 수 없어 문법만
  문헌 기준으로 비교한다(실행한 것처럼 꾸미지 않음).
- [`Olist-고객데이터/`](./Olist-고객데이터/README.md) — `olist_customers_dataset.csv` 하나만
  사용하는 실데이터 실습. 데이터 사전 작성, 기본 SQL 전처리·집계, 다른 Olist 파일 존재 여부
  조사, 분석기법별 실행 가능 여부 판정(가능/부분가능/불가능/보너스)까지 가짜 변수 없이
  정직하게 다룬다.
- [`분석기법/`](./분석기법/README.md) — 빅데이터분석기사 실기 연계 분석기법 실습.
  SQL로 데이터를 준비하고 Python으로 학습한 뒤 다시 SQL로 검산하는 흐름으로
  PCA·회귀·분류·군집·시계열·연관규칙 등 20개 기법을 다룬다(공통 데이터는 재현 가능한 합성 데이터).

세 폴더는 서로 다른 데이터(손계산용 소량 데이터 / Olist 실데이터 / 재현 가능한 합성
데이터)를 쓰지만, "SQL 준비 → Python/R 실행 또는 다중 DBMS 실행 → SQL 검산"이라는
동일한 절차를 공유한다.
